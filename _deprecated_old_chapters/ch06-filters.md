# 第 6 章 · 业界常用滤波器：降噪、边缘与形态学

- 会自己写通用卷积函数，并实现高斯核
- 知道均值/高斯/中值/双边四种降噪滤波器各杀什么噪声

## 6.1 滤波是什么

**滤波（filtering）** = 根据像素周围的邻居们，重新计算这个像素的值。

类比：给照片磨皮。皮肤上的噪点（单个特别亮/暗的点）不该存在，磨皮就是用"周围皮肤的平均状态"把它抹平。所有滤波器都在做同一件事：**用一个邻域规则，把每个像素换成更合理的值**。

分两类：

- **点运算**：只跟自己有关。第 3 章的亮度+50、反色、阈值化都是。
- **邻域运算**：跟周围有关。本章全是。

## 6.2 卷积：一切滤波器的底层机制

### 滑窗加权求和

卷积需要一个**卷积核（kernel）**：一个 3×3（或更大）的小矩阵，存着 9 个权重。工作方式：

```text
核在图像上从左到右、从上到下逐像素滑动
每滑到一个位置：核的 9 个数 × 图像对应 9 个像素 → 求和 → 写回中心像素
```

拿最朴素的**均值滤波**来手算。核是 9 个 1/9（让权重和为 1，保证整体亮度不变）：

```text
图像块：           核：             计算中心(星号)位置：
 1   2   3        1/9 1/9 1/9
 4  [5]  6   ×    1/9 1/9 1/9   =   (1+2+3+4+5+6+7+8+9) × 1/9
 7   8   9        1/9 1/9 1/9     =   45/9 = 5
```

均值滤波的结果：中心像素从 5 变成 5——如果中间突然冒出一个 255 的噪点，它会被拉回到邻居们的平均水平。这就是"降噪"的本质。

再算一个能看出效果的：把 9 换成 200（模拟一个亮噪点）：

```text
 1    2    3
 4  [200]  6   ×  均值核  =  (1+2+3+4+200+6+7+8+9)/9 = 240/9 ≈ 26.7
 7    8    9
```

200 的噪点被压到 27——噪声被杀死了，代价是周围的细节也被抹平了一点。**所有降噪滤波器都在"杀噪声"和"保细节"之间走钢丝**，不同的核就是不同的走法。

### 自己写一个通用卷积函数

```rust
use image::{GrayImage, Luma};

/// 3×3 卷积。kernel 按行优先排列（左上、上、右上、左、中、右、左下、下、右下）
/// 输入输出都是灰度图；边界像素直接复制，不处理（简单起见）
fn convolve3x3(img: &GrayImage, kernel: &[f32; 9]) -> GrayImage {
    let (w, h) = img.dimensions();
    let mut out = img.clone();
    for y in 1..h - 1 {
        for x in 1..w - 1 {
            let mut sum = 0.0f32;
            let mut ki = 0;
            // 遍历中心像素周围的 3×3 邻域
            for dy in -1i64..=1 {
                for dx in -1i64..=1 {
                    let p = img.get_pixel((x as i64 + dx) as u32, (y as i64 + dy) as u32);
                    sum += p[0] as f32 * kernel[ki];
                    ki += 1;
                }
            }
            out.put_pixel(x, y, Luma([sum.round().clamp(0.0, 255.0) as u8]));
        }
    }
    out
}

fn main() -> anyhow::Result<()> {
    let img = image::open("test.jpg")?.to_luma8();
    // 均值滤波核
    let blur = [1.0/9.0; 9];
    let smoothed = convolve3x3(&img, &blur);
    smoothed.save("smoothed.png")?;
    Ok(())
}
```

看完这段代码你应该明白：所谓"设计一个滤波器"，**就是设计那 9 个数字**。接下来整章都是"不同的数字产生不同的效果"。

### 边界处理

上面的代码跳过了最外圈像素（`1..w-1`）。真实工程里边界不能丢，常见策略：

| 策略 | 做法 | 特点 |
| --- | --- | --- |
| 忽略 | 不处理边界 | 简单，边缘信息丢一圈 |
| 填充 0 | 越界当 0 | 边界变暗 |
| 复制边缘 | 越界用最近的边缘像素 | 最常用，视觉自然 |

image crate 的 `imageops::filter3x3` 已内置这些，自己写时知道有这回事即可。

## 6.3 降噪滤波器逐个讲

### 均值滤波：最朴素的模糊

核就是 `[1/9; 9]`。特点：所有邻居一视同仁。**副作用明显**：边缘也被一起抹糊了（边缘正是"和邻居不同"的地方，而均值最怕与众不同）。适合快速预览，不适合保细节的场合。

### 高斯滤波：工业界默认的平滑

均值核的缺陷是"中心的邻居和角落的邻居权重一样"——这不合直觉：正旁边的像素显然比斜对角更相关。高斯核按**钟形曲线**分配权重，中心大、四周小：

```text
常用 3×3 高斯核（σ≈0.85）：      5×5 高斯核（σ=1.4）：

 1  2  1                      2   4   5   4   2
 2  4  2          ÷ 16        4   9  12   9   4
 1  2  1                      5  12  15  12   5
                             4   9  12   9   4
                             2   4   5   4   2
                                          ÷ 159
```

**σ（西格玛）控制钟形的胖瘦**：σ 越大，远处邻居权重越高，模糊越强。高斯模糊是几乎所有视觉流水线的第一步——它模拟了"物理世界的平滑"，噪声是高频率的杂乱信号，高斯低通正好压掉它。Canny（6.4）的第一步就是它。

手写一个核生成函数（以后想换 σ 就不用查表了）：

```rust
/// 生成 size×size 的高斯核（size 为奇数），已归一化（元素和为 1）
fn gaussian_kernel(size: usize, sigma: f32) -> Vec<f32> {
    let mut k = vec![0.0f32; size * size];
    let center = size as f32 / 2.0;
    let mut sum = 0.0;
    for y in 0..size {
        for x in 0..size {
            let dx = x as f32 - center + 0.5;
            let dy = y as f32 - center + 0.5;
            let v = (-(dx * dx + dy * dy) / (2.0 * sigma * sigma)).exp();
            k[y * size + x] = v;
            sum += v;
        }
    }
    k.iter().map(|v| v / sum).collect()   // 归一化，保持亮度
}
```

### 中值滤波：椒盐噪声的克星

**椒盐噪声**：图上随机撒的纯黑、纯白小点（老照片上的霉点、传感器坏点）。

均值/高斯对它是无能为力的——把 255 的白点跟邻居平均，还是把周围"污染"了。中值滤波的思路釜底抽薪：把 9 个邻居**排序，取中间那个**。白点 255 和中点有多大偏差都排在队尾，中位数根本不受影响：

```text
邻域 9 个像素排序后：[3, 5, 7, 8, 9, 9, 10, 12, 255]
中值 = 9  ← 255 被自动踢出去了
```

中值滤波是非线性的（没有固定核矩阵），天然**保边缘**（边缘两侧的中值还是各归各），是去除孤立噪点而不糊图的首选。代价：排序比乘加慢。

```rust
// 3×3 中值滤波
fn median3x3(img: &GrayImage) -> GrayImage {
    let (w, h) = img.dimensions();
    let mut out = img.clone();
    for y in 1..h - 1 {
        for x in 1..w - 1 {
            let mut vals: Vec<u8> = (0..9).map(|i| {
                img.get_pixel(x - 1 + i % 3, y - 1 + i / 3)[0]
            }).collect();
            vals.sort();
            out.put_pixel(x, y, Luma([vals[4]]));   // 第 5 个 = 中位数
        }
    }
    out
}
```

### 双边滤波：磨皮不磨五官

高斯滤波只看"空间距离"：离得近就权重大。问题是像素隔着一条边缘也"近"——边缘两边互相污染，脸被磨平了、眼睛也糊了。

双边滤波加了一个维度：**像素值差**。空间近 + 颜色近，两个权重相乘。边缘两侧颜色差别大，权重被压到接近 0——**边缘被保护了**；平坦区域颜色相近，正常平滑。

效果：磨皮（皮肤平滑）但眼睛眉毛的轮廓依然锐利——就是美颜相机的核心技术。代价是计算量大（每个像素要遍历邻域两次）。在工业上，它也常用于光照不均背景的均化。

### 四种降噪对比表

| 滤波器 | 线性？ | 保边缘 | 杀什么噪声 | 速度 | 典型场景 |
| --- | --- | --- | --- | --- | --- |
| 均值 | 是 | 差 | 高斯噪声 | 快 | 快速预览 |
| 高斯 | 是 | 中 | 高斯噪声 | 快 | 通用平滑、Canny 前置 |
| 中值 | 否 | 好 | **椒盐噪声** | 中 | 坏点、扫描件去斑 |
| 双边 | 否 | **最好** | 保边平滑 | 慢 | 美颜、光照均化 |

## 6.4 边缘检测

### 边缘 = 亮度突变 = 梯度大的地方

**梯度**衡量"变化快慢"。类比山坡：平地梯度 0（没变化），悬崖梯度大（剧烈变化）。图像里，物体轮廓处亮度跳变剧烈——**梯度大的地方就是边缘**。

### Sobel：两个方向的探针

Sobel 用两个卷积核分别探测水平变化和垂直变化：

```text
Gx（检测纵向边缘）：        Gy（检测横向边缘）：

-1  0  1                   -1  -2  -1
-2  0  2                    0   0   0
-1  0  1                    1   2   1
```

手算中心像素（左边暗 10、右边亮 100）的 Gx：

```text
 10  10  10            -1  0  1
 10  10  100    ×      -2  0  2   =  (10×-1 + 10×0 + 10×1
 10  10  100           -1  0  1       +10×-2 + 10×0 + 100×2
 = (-10 + 10) + (-20 + 200) + (-10 + 100)          +10×-1 + 10×0 + 100×1)
 = 270                                          = 270
```

Gx=270 说明左右差异巨大——这里有一条竖边。左右一样亮的话，正负项相消，Gx≈0。

总梯度幅值：

$$G = \sqrt{G_x^2 + G_y^2} \quad \text{（工程上常用近似 } |G_x| + |G_y|\text{）}$$

Scharr 是 Sobel 的加强版（系数更大，对小边缘更敏感），核换成：

```text
-3  0  3            -3  -10  -3
-10 0  10            0   0    0
-3  0  3            3   10   3
```

### Laplacian：再找一次"变化"

一阶导数（Sobel）找坡，二阶导数（Laplacian）找"坡的坡"——对细线、孤立点更敏感，但**对噪声同样敏感**，必须放在高斯后面用（这就是经典的 LOG：Laplacian of Gaussian）。

### Canny：业界标准的边缘提取

实际项目里说"提边缘"，九成指 Canny。它把前面所有思想串成一条五步流水线：

```text
① 高斯降噪      先去噪，不让假边缘混进来
② Sobel 算梯度  每个像素得到幅值 G 和方向 θ（朝哪边变化最快）
③ 非极大值抑制  只保留"局部最陡"的点，把宽边缘压细成 1 像素线
④ 双阈值分类    强边缘(>maxVal) / 弱边缘(between) / 非边缘(<minVal)
⑤ 滞后连接      弱边缘如果和强边缘连着→晋升保留；孤立的→丢弃
```

第 ③ 步的直觉：一条悬崖的轮廓，Sobel 算出来可能是 3 像素宽的"坡"，真正的边缘只有中间最陡的那 1 像素。非极大值抑制沿梯度方向检查"我是不是最陡的"，不是就归零——边缘从"一片"变"一根"。

第 ⑤ 步的直觉：强边缘一定是真边缘；弱边缘可能是真边缘的延伸（轮廓被噪点打断了一截），也可能是噪声。看它"抱的谁的大腿"——连着强边缘就保留。这个设计让 Canny 既能连上断续的真实轮廓，又不放过孤立噪声。

实战（用 imageproc）：

```rust
use imageproc::edges::canny;

let img = image::open("test.jpg")?.to_luma8();
// canny(图, 低阈值, 高阈值) —— 经验比值约 1:2 或 1:3
let edges = canny(&img, 50.0, 150.0);
edges.save("edges.png")?;
```

阈值怎么调？低阈值管"边缘能多密"，高阈值管"边缘能多重"。都调高→边缘稀疏但可靠；都调低→密密麻麻全是线。这是项目里要对着样图调参的地方。

## 6.5 形态学操作：二值图的整形医生

第 3.3 节我们把灰度图阈值化成了黑白两色。形态学（morphology）就是对这些黑白图的"整形手术"：去毛刺、填小洞、分离粘连。

核心工具是**结构元**（类比：印章的形状，通常 3×3 十字或方块），两个基本操作：

### 腐蚀：橡皮擦

**腐蚀**：结构元扫过图像，只有当结构元下的像素**全为白**时，中心才保留白；否则变黑。效果：白色区域从边界往内缩一圈。

类比：拿橡皮擦沿物体边缘描一圈——**细小的白毛刺被擦掉了，细小的黑洞没变**。物体整体变细。

### 膨胀：记号笔

**膨胀**：结构元下**只要有白**，中心就变白。效果：白色区域向外扩张一圈。

类比：拿粗记号笔描轮廓——**小黑洞被填上了，毛刺也变大了**。物体整体变粗。

### 开运算与闭运算：组合技

```text
开运算 = 先腐蚀，后膨胀   → 去小白点（毛刺），保大形状
闭运算 = 先膨胀，后腐蚀   → 填小黑洞，保大形状
```

直觉：腐蚀先消灭小亮点，膨胀再恢复主体——小人先擦掉再放大，还原的是"干净的主体"。闭运算反过来：膨胀先填坑，腐蚀再还原主体。实际项目里"开运算去噪"几乎和"二值化"绑定出现。

imageproc 调用：

```rust
use imageproc::morphology::{erode, dilate, open, close};
use imageproc::distance_transform::Norm::L1;

let out = open(&binary, L1, &imageproc::morphology::Mask::boxed(3));
```

## 6.6 趣味核：锐化与浮雕

理解了"滤波器 = 设计核里的数字"，你可以手工玩出很多效果：

```text
锐化核（强调与邻居的差异）：           浮雕核（一个方向打光）：

 0  -1   0                            -2  -1   0
-1   5  -1                            -1   1   1
 0  -1   0                             0   1   2
```

锐化的思想很有意思：原图 = 原图 + 边缘×强度。这正是"USM（unsharp masking）"的核形式——**先模糊、再用原图减去模糊得到细节层、最后把细节层加回去**。这套思路在图像增强和 AI 超分里反复出现。

## 6.7 频域滤波：一口鲜

本章所有滤波器都在"空间域"操作（直接对像素）。还有一条平行的路线：**频域**。

直觉：任何一段音乐都能拆成不同频率音符的叠加（高音低音），任何一张图也能拆成一堆"波纹"的叠加——**低频 = 平缓的大块明暗（天空、墙面），高频 = 剧烈的细节（边缘、噪点、纹理）**。

于是：

- **低通滤波** = 只留下平缓的波纹 → 模糊、降噪
- **高通滤波** = 只留下剧烈的变化 → 边缘

傅里叶变换（FFT）就是"图 ↔ 波纹集合"的转换器。空间域的卷积，等价于频域的乘法——有些操作用频域算会快几个数量级（模糊一个大核时）。

这一节你只需要有"图可以拆成频率"的直觉，不必会算。但如果以后遇到"频域滤波""傅里叶""相位"，你知道它们在说什么。

## 6.8 实战小项目：印刷品瑕疵检测

体会一下传统算法"每一步都看得见"的爽感。任务：找出印刷纸上的脏点/缺印。流水线：

```text
原图 → 灰度 → 高斯平滑 → 与完美模板差分 → 阈值 → 开运算去噪 → 数连通域
```

```rust
use image::{open, imageops, GrayImage, Luma};

fn absdiff(a: &GrayImage, b: &GrayImage) -> GrayImage {
    let (w, h) = a.dimensions();
    let mut out = GrayImage::new(w, h);
    for y in 0..h {
        for x in 0..w {
            let d = (a.get_pixel(x, y)[0] as i32 - b.get_pixel(x, y)[0] as i32).abs();
            out.put_pixel(x, y, Luma([d as u8]));
        }
    }
    out
}

fn main() -> anyhow::Result<()> {
    let sample = open("sample.jpg")?.to_luma8();    // 待检
    let perfect  = open("perfect.jpg")?.to_luma8();   // 标准模板
    let blurred  = imageops::blur(&sample, 2.0);      // ① 高斯平滑

    let diff = absdiff(&blurred, &perfect);           // ② 差分：差异大的地方亮

    // ③ 阈值：差异 > 40 判为瑕疵
    let mut bin = diff.clone();
    for p in bin.pixels_mut() {
        p.0[0] = if p.0[0] > 40 { 255 } else { 0 };
    }

    // ④ 开运算去小噪点
    let clean = imageproc::morphology::open(
        &bin, imageproc::distance_transform::Norm::L1,
        &imageproc::morphology::Mask::boxed(3),
    );

    // ⑤ 连通域统计：数瑕疵个数和面积
    let n = imageproc::connected_components::connected_components(
        &clean, imageproc::connected_components::Connectivity::Four,
    );
    println!("发现 {} 个疑似瑕疵区域", n);
    clean.save("defects.png")?;
    Ok(())
}
```

这个项目里，每个中间结果都能存成图片肉眼检查——这是传统算法的巨大工程优势：出了问题，逐帧排查，不用对着神经网络黑盒抓瞎。

## 6.9 小结

- 滤波 = 邻域运算；卷积 = 滑窗加权求和；设计滤波器就是设计核里的数字。
- 降噪四天王：均值（快而糊）、高斯（默认平滑）、中值（杀椒盐）、双边（保边磨皮）。
- 边缘 = 梯度大；Sobel 算梯度，Canny 靠"非极大值抑制 + 双阈值 + 滞后连接"成为业界标准。
- 形态学：腐蚀去毛刺、膨胀填小洞；开=先腐后膨去白点、闭=先膨后腐填黑洞。
- 频域直觉：图 = 波纹叠加；低通模糊、高通边缘。
- 传统算法流水线每一步可视可查，是深度学习的互补而非过时。
