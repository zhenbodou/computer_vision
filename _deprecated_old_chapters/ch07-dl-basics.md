# 第 7 章 · 深度学习速成：神经网络与模型文件

> **本章导读**：前面所有章节都在和"像素"打交道，从本章开始我们接触"模型"——机器视觉的另一半天空。别紧张，本章的目标不是让你会训练神经网络（那是另一个职业的技能树），而是让你**彻底搞懂两件事**：模型内部到底在干什么（看懂它在"加权投票"），模型文件里到底存了什么（一堆数字 + 一张工序单）。搞懂这两件事，你就有底气面对后面三章的转换、推理、后处理了。

**学习目标**：
- 用"加权投票"的直觉解释神经元、权重、激活函数
- 说清"训练"和"推理"的区别，明白我们全书只做推理
- 理解 CNN 三件套（卷积层、池化层、全连接层）各自的角色
- 知道模型文件的两大内容（权重 + 计算图），能对比主流格式
- 认识分类/检测/分割三类任务的输出形态

## 7.1 神经网络：一顿加权投票

### 神经元：一个打分器

神经网络的每个神经元做一件极其简单的事情：

$$\text{输出} = f(w_1x_1 + w_2x_2 + \cdots + w_nx_n + b)$$

翻译成大白话：把每个输入乘以一个自己的权重，全部加起来，加一个偏置，最后过一道激活函数。**它就是一个打分器。**

类比"西瓜鉴定师"：

```text
输入：颜色 x₁=8 分、纹路 x₂=6 分、敲击声 x₃=5 分
权重：颜色重要 → w₁=0.5；纹路一般 → w₂=0.3；声音参考 → w₃=0.2
偏置：b = -5（及格线调高，宁缺毋滥）

打分 = 0.5×8 + 0.3×6 + 0.2×5 - 5 = 4 + 1.8 + 1 - 5 = 1.8
激活函数：sigmoid(1.8) ≈ 0.86 → 86% 的把握是好瓜
```

所谓"训练"，就是调整这些 w 和 b 直到打分总是正确。所谓"模型"，就是训练好的这堆 w 和 b 的集合。

### 激活函数：没有它，多层就废了

如果只有加权求和，会发生一件很悲剧的事：**一百层网络坍缩成一次加权求和**。

验证一下：第一层输出 y = w·x + b，第二层拿 y 再算 z = w'·y + b' = w'(wx+b) + b' = (w'w)x + (w'b + b')——**还是一条直线**。叠多少层都是一条直线，没有任何新能力。

激活函数在加权求和后插入一个**非线性**变换，把直线掰弯：

```text
ReLU：    负数归零，正数原样通过。 类比：一票否决——负分直接出局
Sigmoid： 把任意数压到 0~1。     类比：换算成"百分比把握"
```

有了非线性，多层网络才能表达"猫"这种弯弯绕绕的复杂边界。你不需要记公式，记住"**激活函数让多层有意义**"就够了。

## 7.2 网络是怎么学会的：蒙眼下山

想象你在一座大雾的山上，要走到最低点（误差最小），但看不见路。你只能：伸出脚探一探四周，哪边**下坡最陡**就往哪边迈一步。数学上这叫**梯度下降**——"坡度"就是损失对每个权重的导数。

完整训练循环（三个动作的循环）：

```text
1. 预测：拿当前权重算一遍答案
2. 算损失：和正确答案比，错多少（loss）
3. 梯度下降：把每个权重朝"能减小错误"的方向挪一小步
   （步子大小 = 学习率，太大震荡、太小慢）
循环几万~几百万次
```

**训练 vs 推理**——这是全书最重要的区分：

| | 训练 | 推理 |
| --- | --- | --- |
| 干什么 | 调权重 | 权重冻结，只用 |
| 方向 | 需要正确答案（标注数据） | 只 forward，不回传 |
| 耗时 | 几小时~几周（GPU 集群） | 几毫秒（单设备） |
| 谁做 | 算法工程师（Python） | 你（部署工程师，Rust） |
| 产物 | 权重文件 | 检测结果 |

**我们全书只做推理。** 权重是别人训练好的"现成的经验"，我们的工作是把它部署到设备上跑起来。所以训练里的各种深奥概念（反向传播、学习率调度、分布式训练）你可以完全不理会。

## 7.3 "深度"二字何来：逐层抽象

深度 = 很多层。为什么层数有用？因为**每层在前一层的基础上做更抽象的归纳**：

```text
第 1 层：边缘（横线、竖线、斜线）
   ↓
第 3 层：纹理（格子、条纹、毛发走向）
   ↓
第 5 层：部件（耳朵、眼睛、车轮）
   ↓
第 8 层：整体（猫、狗、汽车）
```

类比学认字：笔画（点横撇捺）→ 偏旁部首（氵木灬）→ 汉字（江湖河海）→ 词语（江湖）→ 句子。低层的笔画本身没有意义，组合起来才能表达"江湖"。

每层神经元数量从多到少（像漏斗），信息被不断压缩提纯，最后浓缩成一个判断："这张图 92% 是猫。"

## 7.4 CNN 三件套

图像用的网络主体是**卷积神经网络**（CNN）。它和第 6 章有直接关系：第 6 章的卷积核是**人手写的**，CNN 的卷积核是**从数据里学出来的**。三件套：

### 卷积层：学出来的滤波器

一层卷积有几十上百个"可学习滤波器"，每个滤波器在整幅图上滑动（就是 6.2 的滑窗），各自寻找一种模式——这个滤波器对"竖边"敏感、那个对"红色圆斑"敏感。卷积层的输出是一张张"响应图"（feature map）：图上越亮的位置，代表该模式出现得越强烈。

### 池化层：做缩略图

**池化（pooling）** 在邻域里取代表（最大池化取最大的，平均池化取平均），把图缩小一半。类比：把 4K 照片缩成 1080p 预览图。作用：

1. 计算量减半（后面层的滑窗都在小图上进行）
2. 位置变得"宽泛"——物体挪了几个像素，池化后特征几乎不变（平移鲁棒性）

### 全连接层：汇总投票

网络尾部把特征图展平成一维数组，过几层"每个神经元连接所有输入"的全连接层——所有特征汇总打分，输出每个类别的分数。

用 ndarray 写一个 toy 卷积层的前向计算（让你看到它真的只是 6.2 的滑窗）：

```rust
use ndarray::{Array2, Array3, s};

/// 单个 3×3 卷积核在单通道图上滑动（无 padding，无激活函数）
/// kernel 有 9 个权重（学来的！），输入输出都是 2D 数组
fn conv2d(input: &Array2<f32>, kernel: &Array2<f32>, bias: f32) -> Array2<f32> {
    let (h, w) = input.dim();
    let (kh, kw) = kernel.dim();
    let mut out = Array2::<f32>::zeros((h - kh + 1, w - kw + 1));
    for y in 0..out.dim().0 {
        for x in 0..out.dim().1 {
            let window = input.slice(s![y..y + kh, x..x + kw]);
            out[[y, x]] = (&window * kernel).sum() + bias;   // 对应相乘求和 + 偏置
        }
    }
    out
}
```

对照 6.2 的 `convolve3x3`——逻辑完全一样，唯一区别是核里的数字来自模型文件而非人工设计。**看懂这段代码，你就看懂了 CNN 的 70%。**

### 感受野：每个神经元看见多大世界

一个 3×3 卷积的输出像素，看见输入的 3×3；再叠一层 3×3，它看见 5×5。层数越深，每个神经元"感受"的原图范围越大——这解释了 7.3 的逐层抽象为什么可能。

## 7.5 模型文件里到底存了什么

一个模型文件 = 两样东西：

1. **权重**：所有 w 和 b 的数值。现代模型动辄上亿个参数，一个 FP32 参数 4 字节——亿级参数就是 400MB，所以第 8 章要量化。
2. **计算图**：先做什么后做什么的"工序单"（节点 = 操作如卷积/ReLU，边 = 张量数据流）。

类比：计算图是菜谱（先切菜、再下锅、后装盘），权重是食材和调味料的配比。

主流格式怎么存这两样：

| 格式 | 权重存哪 | 计算图存哪 | 生态 |
| --- | --- | --- | --- |
| PyTorch `.pt/.pth` | zip 内的二进制 | 和 Python 代码耦合（pickle 序列化） | 训练界王者 |
| `safetensors` | 扁平二进制（安全） | 不含图（需代码定义结构） | HuggingFace 系 |
| **ONNX** `.onnx` | protobuf 的 initializer | protobuf 的 node 列表 | **部署界普通话**（第 8 章主角） |
| TFLite `.tflite` | flatbuffer | flatbuffer 的 operator 列表 | 移动端/嵌入式 |
| NCNN | `.param`（结构文本）+ `.bin`（权重二进制） | param 文件 | 腾讯，手机端 |

注意 PyTorch 的坑：`.pt` 里可能包含**任意 Python 代码**（pickle 反序列化执行），所以"来路不明的 pt 文件"不能随便加载——这是安全常识。

## 7.6 三类任务的输出长什么样

模型输出什么样，取决于它训练时学的是什么任务：

**分类（classification）**：输出一串类别分数。`[0.01, 0.85, 0.02, ...]`——第 2 位（猫）分数最高。后处理 = softmax/argmax（第 10.2 节）。

**检测（detection）**：输出一批"框 + 类别分数"。YOLO 系列是单阶段检测的代表：把图切成网格，每个网格预测几个框。演进史一句话：

```text
YOLOv3：三个尺度上做检测，用"锚框"（预设的框形状）回归修正
YOLOv5：单输出头 + objectness 分数（这行是否像物体）
YOLOv8/v11：无锚框、输出解耦——位置 4 个数 + 每类 1 个分数
```

**分割（segmentation）**：输出每个像素的类别图（语义分割），或"每个物体一张精确掩码"（实例分割）。YOLOv8-seg 的输出 = 检测框 + 掩码系数（第 10.7 节简述）。

## 7.7 必备名词速览

以后和算法工程师/客户对话，这些词的意思要秒懂：

| 名词 | 一句话解释 |
| --- | --- |
| 参数量 | 权重个数，模型大小的直接指标 |
| FLOPs | 每秒浮点运算数，模型计算量的指标 |
| FPS | 每秒处理帧数，部署最关心的性能指标 |
| mAP | 检测精度的综合指标（0~1，越大越好） |
| top-1 / top-5 | 分类准确率：最高票类别正确率 / 前五名包含正确类别率 |
| 过拟合 | 模型死记硬背训练集，没见过的新图表现差 |
| 预训练权重 | 在大数据集上训好的通用权重，下载即用 |
| fine-tune / 迁移学习 | 拿预训练权重在自己的小数据集上继续训 |
| FP32 / FP16 / INT8 | 权重的数值精度：32 位浮点 / 16 位浮点 / 8 位整数（越小越快越小，精度略降） |
| NPU / GPU / CPU 推理 | 分别用神经网络专用芯片 / 显卡 / 中央处理器跑模型 |

## 7.8 小结

- 神经元 = 加权求和 + 偏置 + 激活函数；激活函数给多层网络以灵魂。
- 训练 = 预测→算损失→梯度下降循环；推理 = 冻结权重的单次前向。我们只做推理。
- CNN = 学出来的卷积核 + 池化缩图 + 全连接投票；层越深看得越抽象。
- 模型文件 = 权重 + 计算图；ONNX 是部署界的普通话（下一章详解）。
- 分类/检测/分割的区别在输出形态，后处理也因此不同（第 10 章）。
