# 第 80 章 表面缺陷检测：从成像到量产验收

> **本章导读**
> - 学完你能：用**黄金模板差分 + 形态学去噪 + Blob 分析**这条经典链路，找出产品表面的划痕、斑点，并给出每个缺陷的**位置、面积、数量**。
> - 先记住一句话：**缺陷检测首先是个成像问题**——打光把缺陷照清楚，往往比换个更强的算法更管用。
> - 亲手造一张"良品"纹理图，注入**已知位置/大小**的缺陷，检测后**和真值对账**，并存出标注 PNG。
> - 建立专家心智：**方法怎么选**（模板差分 vs 监督学习 vs 异常检测）、**阈值按成本定**、数据怎么切分、量产该看哪些**指标**。

## 场景：这块面板上有没有划痕？

手机中框要检查有没有划伤、镀锌板要挑出锈点、注塑件要发现缺料和黑点。这类**表面缺陷检测（surface defect detection）**是工业视觉最赚钱的应用之一，而它最朴素的思路一句话就能说清：**和标准良品比一比，差异处就是缺陷。**

但在写算法之前，有个更根本的事得先摆正——

## 原理零：缺陷检测首先是成像问题

一道浅划痕，在平光下可能和背景灰度几乎没差别，你再牛的算法也无中生有不出来；可换成**掠射（暗场）**打光，划痕的棱边会把光打散、亮得刺眼，缺陷与背景的**信噪比**一下拉开——这时候连最简单的阈值都能揪出它。**在缺陷检测里，改善成像常常比改进模型更立竿见影。**

常见打光/成像手段（细节见 [第 82 章 成像方案](ch82-imaging-hardware.md)）：

```text
明场(直射)   暗场(掠射)    同轴          穹顶(无影)     偏振/多角度
   ↓            ↘             ║             ∩            ↓↘
 ▁▁▁▁▁       ▁/▁\▁        ▁▁▁▁▁         ▁▁▁▁▁         去反光/多次曝光
表面反射均匀   棱边发亮     镜面缺陷      漫反射柔和     压反光、增对比
```

> 💡 **提示**：**先把成像"锁死"，再谈算法。** 触发方式、曝光、增益、焦距、工件姿态——这些一旦每次都变，差分图就会满屏乱跳。工业上先把这些固定下来、建立稳定的**基线（baseline）**，算法才有意义。这也是为什么产线宁可花钱上好光源好镜头，也不轻易在算法上死磕。

## 原理一：黄金模板差分

成像稳定后，最经典的方法是**黄金模板差分（golden template）**：准备一张（或多张平均出的）标准良品图，把待测图与它**逐像素相减取绝对值**：

\\[ D(x,y) = \big|\, I_{\text{test}}(x,y) - I_{\text{golden}}(x,y) \,\big| \\]

良品处两图几乎一样、差分接近 0；缺陷处灰度不同、差分很大。**前提是两图必须先对齐**——工件位置差一个像素，边缘处就会差出一圈"假缺陷"。对齐正是上一章的活儿（[第 79 章 视觉定位](ch79-alignment-guidance.md)：先定位、再把待测图配准到良品）。本章为聚焦差分本身，直接用同一套坐标合成，省去配准。

## 原理二：统计阈值——均值加 kσ

拿到差分图 \\( D \\)，怎么定"差多少算缺陷"？写死一个阈值（如 `> 30`）在光照或噪声一变时就崩。稳健的做法是**统计阈值**：算差分图的均值 \\( \mu \\) 和标准差 \\( \sigma \\)，取

\\[ T = \mu + k\sigma \\]

良品的正常波动都落在 \\( \mu \\) 附近的几个 \\( \sigma \\) 内，超过 \\( k\sigma \\)（如 \\( k=4 \\)）的才判为缺陷。这其实就是最朴素的**异常检测（anomaly detection）**思想：把偏离正常分布太远的当异常。

## 原理三：形态学去噪 + Blob 分析

阈值化后的掩码上，除了真缺陷，还会有噪声/灰尘/坏点造成的**零星亮点**。两步收拾干净：

1. **形态学开运算（open）**去噪：先腐蚀再膨胀，孤立的单像素点被腐蚀掉、真缺陷（成片）被保住（[第 17 章 形态学](../p03-classic/ch17-morphology.md)）。
2. **Blob 分析**（连通域）：给每个连通块编号，算它的**面积、质心、包围盒**，用**面积阈值**滤掉残余小点，剩下的就是缺陷，还顺带给出了它们的位置和大小（[第 18 章 连通域与轮廓](../p03-classic/ch18-contours.md)）。

> 📖 **术语**：**Blob 分析（blob analysis）**。工业视觉里对二值图中"连成一团的前景像素（blob，斑块）"做几何统计——数个数、算面积/周长/质心/长宽比/圆度——是缺陷计数、颗粒分析的标准工具。

## 动手写代码：造良品、注缺陷、检出、对账

合成一张"良品"纹理（渐变 + 正弦纹理），注入 **1 道划痕 + 3 个斑点**（位置/大小已知），再叠加**高斯噪声 + 椒盐噪声**模拟真实采集，然后走完整条链路，最后和注入真值对账。

`Cargo.toml` 依赖：

```toml
[dependencies]
image = "0.25"
imageproc = "0.27"
```

完整代码（`examples/ch80_defect.rs`）：

```rust
use image::{GrayImage, Luma, Rgb, RgbImage};
use imageproc::distance_transform::Norm;
use imageproc::drawing::{draw_filled_circle_mut, draw_hollow_rect_mut, draw_line_segment_mut};
use imageproc::morphology::open;
use imageproc::noise::{gaussian_noise, salt_and_pepper_noise};
use imageproc::rect::Rect;
use imageproc::region_labelling::{connected_components, Connectivity};

const W: u32 = 240;
const H: u32 = 200;

/// 合成“黄金良品”：水平渐变 + 温和正弦纹理（确定性、可复现）。
fn make_golden() -> GrayImage {
    GrayImage::from_fn(W, H, |x, y| {
        let base = 90.0 + 40.0 * (x as f64 / W as f64); // 渐变 90..130
        let tex = 12.0 * ((x as f64 * 0.15).sin() + (y as f64 * 0.13).sin());
        Luma([(base + tex).round().clamp(0.0, 255.0) as u8])
    })
}

/// 画一道“粗”划痕（3×3 笔刷扫过，约 3 像素宽，才不会被开运算抹掉）。
fn draw_scratch(img: &mut GrayImage, a: (f32, f32), b: (f32, f32), val: u8) {
    for ox in -1..=1 {
        for oy in -1..=1 {
            draw_line_segment_mut(
                img,
                (a.0 + ox as f32, a.1 + oy as f32),
                (b.0 + ox as f32, b.1 + oy as f32),
                Luma([val]),
            );
        }
    }
}

fn main() {
    let golden = make_golden();
    golden.save("out_ch80_golden.png").ok();

    // —— 注入已知缺陷（真值）——
    let mut test = golden.clone();
    // 1 道划痕（很暗，保证沿全长的差分都稳稳高过阈值，不被开运算截断）
    draw_scratch(&mut test, (55.0, 35.0), (135.0, 120.0), 15);
    // 3 个斑点：(圆心, 半径, 灰度)
    let spots = [((200i32, 60i32), 6i32, 35u8), ((55, 145), 5, 235), ((170, 155), 8, 35)];
    for &((cx, cy), r, v) in &spots {
        draw_filled_circle_mut(&mut test, (cx, cy), r, Luma([v]));
    }
    // 叠加轻微高斯噪声 + 少量椒盐噪声（模拟真实采集：传感器噪声 + 灰尘/坏点）
    let test = gaussian_noise(&test, 0.0, 3.0, 20260827);
    let test = salt_and_pepper_noise(&test, 0.004, 12345);
    test.save("out_ch80_test.png").ok();

    // 注入真值一览（用于自验证）
    println!("注入缺陷真值（共 4 个）：");
    println!("  划痕: 中点≈(95, 78)");
    for (i, &((cx, cy), r, _)) in spots.iter().enumerate() {
        println!("  斑点{}: 圆心=({cx},{cy}) 半径={r} 面积≈{:.0}", i + 1, std::f64::consts::PI * (r * r) as f64);
    }

    // —— 黄金模板差分：逐像素 |test - golden| ——
    let diff = GrayImage::from_fn(W, H, |x, y| {
        let d = (test.get_pixel(x, y)[0] as i32 - golden.get_pixel(x, y)[0] as i32).abs();
        Luma([d.min(255) as u8])
    });
    diff.save("out_ch80_diff.png").ok();

    // —— 统计阈值：均值 + kσ（对光照/噪声的整体波动自适应）——
    let vals: Vec<f64> = diff.as_raw().iter().map(|&v| v as f64).collect();
    let mean = vals.iter().sum::<f64>() / vals.len() as f64;
    let std = (vals.iter().map(|v| (v - mean).powi(2)).sum::<f64>() / vals.len() as f64).sqrt();
    let k = 4.0;
    let thr = mean + k * std;
    println!("\n差分统计：均值={mean:.2}，σ={std:.2}，阈值(均值+{k}σ)={thr:.2}");

    let mask = GrayImage::from_fn(W, H, |x, y| {
        if diff.get_pixel(x, y)[0] as f64 > thr { Luma([255]) } else { Luma([0]) }
    });

    // —— 形态学开运算去掉零星噪点（引第 17 章）——
    let clean = open(&mask, Norm::LInf, 1);
    clean.save("out_ch80_mask.png").ok();
    let raw_on = mask.as_raw().iter().filter(|&&v| v > 0).count();
    let clean_on = clean.as_raw().iter().filter(|&&v| v > 0).count();
    // 对比：不去噪时连通域会炸出一大堆假缺陷
    let comp = |img: &GrayImage| {
        connected_components(img, Connectivity::Eight, Luma([0u8]))
            .as_raw().iter().copied().max().unwrap_or(0)
    };
    println!("阈值后前景像素={raw_on}，开运算去噪后={clean_on}");
    println!("阈值后连通域数={}（含噪点），开运算后={}", comp(&mask), comp(&clean));

    // —— 连通域 Blob 分析：数缺陷、算面积/质心/包围盒（引第 18 章）——
    let labels = connected_components(&clean, Connectivity::Eight, Luma([0u8]));
    let n = labels.as_raw().iter().copied().max().unwrap_or(0) as usize;
    let mut area = vec![0u32; n + 1];
    let (mut sx, mut sy) = (vec![0u64; n + 1], vec![0u64; n + 1]);
    let (mut mnx, mut mny) = (vec![u32::MAX; n + 1], vec![u32::MAX; n + 1]);
    let (mut mxx, mut mxy) = (vec![0u32; n + 1], vec![0u32; n + 1]);
    for (x, y, p) in labels.enumerate_pixels() {
        let l = p[0] as usize;
        if l == 0 { continue; }
        area[l] += 1;
        sx[l] += x as u64; sy[l] += y as u64;
        mnx[l] = mnx[l].min(x); mny[l] = mny[l].min(y);
        mxx[l] = mxx[l].max(x); mxy[l] = mxy[l].max(y);
    }

    let min_area = 20u32; // 小于它的当残余噪点丢弃
    let mut vis: RgbImage = image::DynamicImage::ImageLuma8(test.clone()).to_rgb8();
    let mut found = 0;
    println!("\n检出缺陷（面积 ≥ {min_area}）：");
    for l in 1..=n {
        if area[l] < min_area { continue; }
        found += 1;
        let (cx, cy) = ((sx[l] / area[l] as u64) as i32, (sy[l] / area[l] as u64) as i32);
        let (bx, by, bw, bh) = (mnx[l], mny[l], mxx[l] - mnx[l] + 1, mxy[l] - mny[l] + 1);
        println!("  缺陷#{found}: 面积={:>4} 质心=({cx},{cy}) 包围盒=({bx},{by},{bw}x{bh})", area[l]);
        draw_hollow_rect_mut(&mut vis, Rect::at(bx as i32, by as i32).of_size(bw, bh), Rgb([255, 0, 0]));
    }
    vis.save("out_ch80_defects.png").ok();
    println!("\n检出缺陷数 = {found} / 注入 4");
    println!("已保存：out_ch80_diff.png / out_ch80_mask.png / out_ch80_defects.png");
}
```

运行 `cargo run --example ch80_defect`，终端打印（数字真实可复现）：

```text

  斑点1: 圆心=(200,60) 半径=6 面积≈113
  斑点2: 圆心=(55,145) 半径=5 面积≈79
  斑点3: 圆心=(170,155) 半径=8 面积≈201

差分统计：均值=4.57，σ=14.87，阈值(均值+4σ)=64.04
阈值后前景像素=1041，开运算去噪后=872
阈值后连通域数=172（含噪点），开运算后=4

检出缺陷（面积 ≥ 20）：
  缺陷#1: 面积= 425 质心=(94,77) 包围盒=(54,34,83x88)
  缺陷#2: 面积= 129 质心=(200,60) 包围盒=(194,54,13x13)
  缺陷#3: 面积=  97 质心=(55,145) 包围盒=(50,140,11x11)

```

和真值对账，条条吻合：

1. **检出 4 / 注入 4**，一个不多一个不少。
2. **位置精准**：缺陷#1 质心 `(94,77)` 对上划痕中点 `(95,78)`；#2 `(200,60)`、#3 `(55,145)`、#4 `(170,155)` 分别精确命中三个斑点的圆心。
3. **形态学立了大功**：阈值化后连通域高达 **172 个**（椒盐噪声/灰尘全被算成"缺陷"），开运算一遍直接降到 **4 个**——**没有这步去噪，你会收获 172 个假报警**。这就是形态学在缺陷检测里的价值。
4. **面积可解释**：斑点面积（129、97、221）与理论 \\( \pi r^2 \\)（113、79、201）接近，略大是因为噪声与抗锯齿边缘让斑点"胖"了一圈——这也提示我们，面积测量本身也需要标定与容差。

打开 `out_ch80_defects.png`，四个缺陷都被红框稳稳框住；`out_ch80_diff.png` 是差分图、`out_ch80_mask.png` 是去噪后的缺陷掩码。

## 方法怎么选：模板差分、监督学习，还是异常检测？

经典模板差分不是万能钥匙。按**结构稳定性**和**数据情况**选方法，才是专家做法：

| 场景 | 推荐方法 |
|---|---|
| 结构高度稳定、可精确配准 | **配准后模板差分 / 频域**（[第 22 章](../p03-classic/ch22-frequency.md)）**/ Blob**——简单、可靠、可解释 |
| 缺陷类型明确、有足够标注数据 | **监督式检测/分割**（YOLO、U-Net 等，第九/十部分） |
| 缺陷稀少、种类开放（没见过的也要抓） | **异常检测**：patch 嵌入、重建误差、教师—学生 |

> ⚠️ **注意**：**异常分数不天然等于"缺陷概率"。** 无论是 \\( \mu+k\sigma \\) 还是深度模型输出的重建误差，得到的都是一个"有多异常"的分数。阈值必须用**真实良品的分数尾部**加上**已知缺陷样本**、按**漏检/过杀的成本**来定，而不是拍脑袋取个数。

> 💡 **提示**：**现代做法更强，但经典依然是首选。** 深度异常检测（自编码器**重建误差**、PatchCore 等）在复杂纹理、开放集缺陷上明显更强；纯 Rust 可用 candle/tract 跑这类模型（前向引用 [第 69 章 自编码器](../p15-generative/ch69-autoencoder.md)、[第 94 章 ONNX 推理](../p19-deploy/ch94-onnx.md)）。但在**结构化、可配准**的工业场景里，模板差分 + Blob 依然是**首选**——简单、快、可解释、不需要训练数据，出了问题好排查。别一上来就上大模型。

## 数据与指标：量产验收看什么

demo 跑通只是起点，能不能上量产是另一回事。两件事必须做对：

- **数据切分要按来源**：训练/验证/测试要按**生产批次、材料、供应商、设备、时间**切开，别让同批次数据既训练又测试（会虚高）。**良品污染**（混进了坏件）、**返修件**、**图像边缘区域**、**周期性纹理**都要**单独审计**——它们最容易骗过算法。
- **指标要成体系**：不能只报一个"准确率"。至少覆盖**件级**的漏检率（miss）与过杀率（overkill）、**缺陷级**的召回、按**面积/尺寸分桶**的检出率、**节拍（takt time）**、以及**人工复判量**（误报太多会拖垮质检工位）。

> 🕳️ **坑**：**漏检与过检是一对冤家。** 阈值调松→漏检少但过杀多（好件被误判、良率虚降）；调紧→过杀少但漏检多（坏件流出、客户投诉）。没有免费午餐，只能按业务成本找平衡点，并持续监控。

## 常见坑与提示

> 🕳️ **坑**：**对齐没做好，差分全是假缺陷。** 模板差分对配准极其敏感，工件偏一两个像素，所有边缘处都会亮成一圈"缺陷"。务必先高质量对齐（[第 79 章](ch79-alignment-guidance.md)），或改用对位移更鲁棒的方法。

> ⚠️ **注意**：**光照不均会假装成缺陷。** 打光不均导致的明暗渐变，会在差分图上留下大片"异常"。要么在成像端用穹顶光/同轴光压平，要么在算法端做背景估计/照度校正后再差分。

> 🕳️ **坑**：**正常纹理波动 vs 真缺陷难分。** 木纹、拉丝金属、织物这类本身就有强纹理，其正常波动可能超过浅缺陷。此时全局 \\( \mu+k\sigma \\) 会失灵，要用**局部**统计、频域滤波，或干脆上异常检测模型。

## 本章小结

- 缺陷检测**首先是成像问题**：打光提升缺陷—背景信噪比，常比换算法更有效；先固定触发/曝光/焦距/姿态建立基线。
- 经典链路：**对齐 → 黄金模板差分 \\( |I_{\text{test}}-I_{\text{golden}}| \\) → 统计阈值 \\( \mu+k\sigma \\) → 形态学开运算去噪 → Blob 分析**数缺陷、算面积/位置。实测检出 4/4，位置精准，形态学把 172 个噪声连通域压到 4 个。
- **方法按场景选**：结构稳→模板差分/Blob；数据足→监督学习；开放集→异常检测。异常分数≠缺陷概率，阈值按**良品尾部 + 已知缺陷 + 成本**定。
- 现代 DL 异常检测（自编码器/PatchCore）更强、纯 Rust 可跑，但结构化场景里经典法仍是**简单可靠的首选**。
- 量产要**按来源切分数据**、**成体系报指标**（件级/缺陷级/分桶/节拍/复判量），并权衡漏检与过检。

### 专家考核

1. **成像 DoE + 算法消融**：对光源类型/角度、曝光、镜头做**实验设计（DoE）**，用数据证明"检出率提升"到底归因于成像还是算法（做消融，别混为一谈）。
2. **冻结测试 + 置信区间**：把方案**冻结**，在**连续多个新批次**上盲测，报告各项指标的**置信区间**，而不是只在开发集上刷一个漂亮数字。
3. **困难桶 + 未知哨兵集**：专门构造**已知困难样本桶**（浅划痕、边缘区、强纹理）和一批**训练时从没见过的缺陷类型**做"哨兵集"，检验对开放集缺陷的泛化。
4. **上线闭环**：方案必须自带**漂移监控**（良品分布/过杀率异动即报警）、**人工复判**通道、**样本回流**（把误报/漏检样本收集回来迭代）与**版本回滚**能力——缺陷检测系统是要长期"活着"演进的。
