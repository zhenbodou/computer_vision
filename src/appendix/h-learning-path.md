## 三、公式不是暗号：用数字读懂三个基础操作

### 1. 求和就是循环，平均就是除以数量

`Σ` 读“求和”。四个灰度值 `[10, 20, 30, 40]` 的平均值是 `(10+20+30+40)/4=25`。在 Rust 中先转成足够宽的类型再加，不能用 `u8` 累积整张图。

方差是每个值离均值的距离平方再平均：`(225+25+25+225)/4=125`，标准差约 `11.18`。这里描述的是这四个数本身；用样本估计总体方差时常用 `n-1` 分母，两者不要混用。亮度很均匀时方差小，黑白相间时方差大，但“方差大”本身不能证明有缺陷。

### 2. 矩阵乘法就是每行和向量做加权和

让 `A=[[2,0],[0,3]]`，点 `p=[4,5]`，则 `Ap=[8,15]`：横坐标放大两倍、纵坐标放大三倍。`2×2` 矩阵乘 `2×1` 向量得到 `2×1`，中间两个维数必须相等。

先平移 `(1,0)` 再放大两倍：`(4,5)→(5,5)→(10,10)`；反过来是 `(4,5)→(8,10)→(9,10)`。这就是为什么变换次序不能随便交换。图像像素常写 `(x,y)`，数组访问常写 `[y,x]`；把两者画在纸上比背公式可靠。

### 3. 导数告诉你参数稍微变化会怎样

设预测为 `wx`，目标为 `y`，损失 `L=(wx-y)²`。只训练一个权重 `w`，取 `x=2,y=6,w=1`，预测为 2，损失为 16。

沿计算链看：残差 `r=wx-y` 对 `w` 的变化率为 `x`，平方对残差的变化率为 `2r`，相乘得梯度 `2rx=-16`。这就是链式法则。学习率 `0.1` 时，新权重 `1-0.1×(-16)=2.6`，新损失 `(5.2-6)²=0.64`。

可以独立核对手推梯度：分别计算 `w+ε` 与 `w-ε` 的损失，用差除以 `2ε`，取 `ε=0.0001` 时应接近 `-16`。这叫有限差分。它很慢，但适合检查小网络的反向传播。不要在 ReLU 的拐点上要求两种导数严格一致。

**热身题**：把学习率改为 1，手算新权重与损失；解释为什么“沿负梯度走”也会失败。

<details><summary>核对</summary>

新权重 17，预测 34，损失 784，比 16 大很多。方向有局部意义，步长过大仍会越过低谷。回到 [第 36 章](../p07-dl-basics/ch36-neural-nets.md) 时，先检查小批量损失是否能下降，再训练完整数据。

</details>

## 四、学到高级能力需要哪些不同的证据

| 层次 | 应能完成 | 不能用什么替代 |
|---|---|---|
| 入门 | 解释输入输出，独立改动和运行示例 | 只复制终端输出 |
| 独立开发 | 自己组织数据、实现模块、处理边界、完成一个端到端任务 | 只在合成图上拿高分 |
| 高级工程能力 | 对一个方向做选型与误差归因，在未见数据和资源约束下交付、恢复、复盘 | 只读论文、刷题、拿开源 star |

不设“几周必成高级”的时间承诺。以 [附录 I](i-guided-labs.md) 的训练完成度和 [附录 J](j-capstone.md) 的评审证据推进；查文档是正常工作能力，不把默写 API 的速度当成高级工程师标准。
