# 附录 F：从这里到真正的专家（学习路线图）

> **本附录导读**
> - 全书覆盖 21 个部分，不代表每个方向已经达到同样深度。
> - 用可复核的项目证据判断能力，再选择一个方向长期深入。

## 一、按成果盘点，不按页数盘点

读完后，把各章标成“能解释”“能运行”“能独立修改”“通过真实任务验收”四种状态。同一章可以只完成前两级；这比把全部章节统一打勾更能指导下一步学习。

基础阶段先用 [附录 H](h-learning-path.md) 找先修缺口，用 [附录 I](i-guided-labs.md) 核对计算与实现。计算框坐标还经常出错，就先补预处理；训练集和测试集还混在一起，就先补评估。不要用更大的模型绕开这些问题。

## 二、从独立开发到高级交付

| 阶段 | 行动 | 能力证据 |
|---|---|---|
| 基础复现 | 从干净目录运行示例，改动输入并解释结果 | 运行命令、图像、边界测试；入口见附录 K |
| 独立实现 | 把一个算法写成清晰的模块，定义输入输出与失败条件 | 用独立手算或参考实现对拍，说明数值容差 |
| 真实任务 | 将第 97–107 章之一换成真实数据，比较低成本基线 | 分组划分、每样本预测、切片指标、失败归因 |
| 工程交付 | 完成模型契约、资源预算、故障恢复和回滚 | 通过附录 J 的公共关卡与独立评审 |
| 方向专精 | 对同一方向的多种方法做受控复现，研究新工况 | 可重算的比较、局限、选型与后续实验 |

高级工程师需要跨模块判断能力：精度下降可能来自光源、标签、预处理、模型或时间戳。面对一个问题能提出不同假设，再用成本可控的实验排除原因，比记住某个 API 更有价值。

## 三、选择一个专业方向深入

检测/分割方向深入匹配、损失、样本不平衡、边界质量与部署契约；视频方向深入身份关联、时间语义、背压和事件评价；三维与工业测量方向深入可观测性、标定、误差传播与成像；生成与多模态方向深入训练目标、数据覆盖、检索或生成评价。

每个方向都做三件事：复现一个基线，构造一个它必然失败的场景，验证一个改进是否在固定预算下有效。读论文时写出问题、关键假设、相对基线的变化、实验协议与失败范围；不要只抄网络结构图。资源入口见 [附录 E](e-resources.md)。

## 四、持续维护也是能力的一部分

维护一套固定输入的回归实验，依赖升级时先跑它；保存模型、配置、数据和运行环境的版本。生产数据变化后先抽检，再判断是漂移、标注变化还是链路错误，不自动覆盖旧模型。

参与源码阅读、提交问题或修复可以帮助积累协作经验，但 PR 被合并、star 数量或是否发过论文，都不能单独证明高级工程能力。应展示你负责了什么问题、做了哪些取舍、结果在什么条件下仍成立。

本书的长期目标是让你能独立设计、验证和交付视觉系统。以 [附录 G](g-expert-standard.md) 的证据链和 [附录 J](j-capstone.md) 的真实评审判断进展；尚未验证的设备、场景和负载继续留在待办里，不用“已经精通”覆盖未知。
