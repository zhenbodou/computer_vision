# 第 17 章 形态学操作（腐蚀、膨胀、开闭运算）

> **本章导读**
> - 学完你能：对**二值图**做腐蚀、膨胀、开运算、闭运算，把上一章二值化出来的"毛糙掩膜"修整干净。
> - 建立四个核心直觉：**腐蚀啃小**（去毛刺、断细连）、**膨胀长大**（填缝、连断裂）、**开运算去噪点**、**闭运算填小洞**。
> - 搞懂 imageproc 里 `(Norm, k)` 这套"结构元素"是怎么描述邻域形状的。
> - 一条贯穿全章的铁律：**形态学里前景必须是白色 255**。

## 场景：二值化之后，掩膜为什么还是"毛糙"的

上一章 [第 16 章 阈值分割](ch16-threshold.md) 我们学会了把灰度图变成非黑即白的二值图。但真实图像二值化出来的掩膜（mask）几乎从不"干净"：

- 物体边缘参差不齐，还挂着几根"毛刺"；
- 背景上散落着零星的白色**噪点**（椒盐噪声、反光小亮斑）；
- 物体内部莫名其妙有几个小**黑洞**（局部反光被判成了背景）；
- 本该连成一体的笔画或裂缝，断成了好几截。

这些"毛糙"会让后面数物体、量尺寸的步骤全乱套。**形态学（morphology）**就是专门用来"整形"二值图形状的一套工具——你可以把它想象成给剪影做修描：用橡皮擦掉边缘毛刺和背景碎点，用铅笔把内部小洞和断裂补上。

> 📖 **术语**：**形态学（mathematical morphology）**。一套基于"形状"而非"数值"的图像处理理论，核心是用一个叫**结构元素（structuring element）**的小探针，在图像上滑动、比对，从而腐蚀或膨胀前景形状。它最经典的用武之地就是二值图，也可推广到灰度图。

## 前景是白：一条必须先立的规矩

动手之前先把最容易翻车的规矩立好：**在 imageproc 里，形态学把「非零像素」当作前景**。所以本书统一约定——

**前景（我们关心的物体）= 白色 255，背景 = 黑色 0。**

如果你的图是"白纸黑字"（物体是黑的），直接做腐蚀，啃掉的会是那一大片白背景，结果和你想的南辕北辙。遇到这种情况，先在二值化时用 `ThresholdType::BinaryInverted` 把物体翻成白色，或把图整体取反。这一步不确认，后面全白搭。

## 结构元素：`(Norm, k)` 描述的"探针"

腐蚀和膨胀要回答一个问题："以某个像素为中心，**看多大一圈邻居**？"这一圈邻居的形状，就是结构元素。imageproc 用两个参数描述它：

- `k`：**距离半径**（单位是像素）。注意它不是 OpenCV 那种"核的边长"，而是"离中心多远以内算邻居"。
- `Norm`：用哪种**距离**度量。不同度量给出不同形状的邻域：

```text
   Norm::L1 (曼哈顿, 菱形)   Norm::LInf (切比雪夫, 方形)   Norm::L2 (欧氏, 近似圆)
        .  X  .                  X  X  X                     .  X  .
        X  O  X                  X  O  X                     X  O  X
        .  X  .                  X  X  X                     .  X  .
   (O=中心像素, X=k=1 时纳入邻域的像素)
```

- `Norm::L1`：上下左右四邻域，形状是**菱形/十字**。
- `Norm::LInf`：连对角一起算，`k=1` 时正好是经典的 **3×3 方形**。
- `Norm::L2`：欧氏距离，大 `k` 时近似**圆**（imageproc 对距离取上取整，所以 `k ≤ 2` 时结果和 L1 相同）。

## 腐蚀与膨胀：一啃一长

有了结构元素，两个基本操作可以用"距离"讲得非常直白（这也正是 imageproc 内部基于距离变换的实现方式）：

- **膨胀（dilation）**：凡是**到最近前景像素的距离 ≤ k** 的像素，统统设为前景。→ 前景**长大**，缝隙被填、断裂被连、小洞被堵。
- **腐蚀（erosion）**：凡是**到最近背景像素的距离 ≤ k** 的前景像素，统统设为背景。→ 前景**被啃小**，毛刺被削、细连接被断、小噪点被抹掉。

写成经典的集合语言，记结构元素为 \\( B \\)、前景区域为 \\( A \\)，则膨胀记作 \\( A \oplus B \\)、腐蚀记作 \\( A \ominus B \\)。不用背符号，记住"**膨胀长大、腐蚀啃小**"这八个字就够用一辈子。

> ⚠️ **注意**：腐蚀和膨胀是**一对反操作，但不互逆**。腐蚀啃掉的细节，膨胀补不回来（补回来的是"胖了一圈"的近似形状，而非原样）。这一点是理解开、闭运算的关键。

## 开运算与闭运算：先后顺序决定效果

把腐蚀和膨胀按不同顺序组合，就得到两个极其常用的复合操作：

- **开运算（opening）= 先腐蚀，后膨胀**。腐蚀先把比结构元素还小的噪点、毛刺、细连接**统统抹掉**；再膨胀把幸存的主体**大小基本还原**。净效果：**去掉背景上的小白点/毛刺，主体形状基本不变**。
- **闭运算（closing）= 先膨胀，后腐蚀**。膨胀先把小黑洞、细裂缝**填平连上**；再腐蚀把主体**大小基本还原**。净效果：**填上物体内部的小黑洞、连接断裂，主体形状基本不变**。

一句口诀记牢：**开去点（去外部小白点），闭填洞（填内部小黑洞）**。

顺带认识三个"衍生款"（简介，用到再深入）：

- **形态学梯度 = 膨胀 − 腐蚀**：一层"胖轮廓"减一层"瘦轮廓"，剩下的正是物体**边缘**。
- **顶帽（top-hat）= 原图 − 开运算**：抠出比结构元素还小的**亮细节**（如不均匀背景上的小亮点）。
- **黑帽（black-hat）= 闭运算 − 原图**：抠出小的**暗细节**。

> 💡 **提示**：以上都是**二值/灰度膨胀腐蚀的组合**。imageproc 对灰度图另有一套 `grayscale_dilate/erode/open/close`，用 `Mask::square(r)`、`Mask::diamond(r)`、`Mask::disk(r)` 指定结构元素形状——本章聚焦二值形态学，灰度版用法类似，知道有这回事即可。

## 动手写代码：四种运算对比 + Otsu 去噪实战

下面这个例子做两件事：① 合成一张"带毛刺 + 小噪点 + 小洞"的二值图，分别做腐蚀/膨胀/开/闭并用白像素个数量化对比；② 一个"先 Otsu 二值化，再开运算去噪点"的小实战。输入全部代码合成，自包含。

`Cargo.toml`：

```toml
[dependencies]
image = "0.25"
imageproc = "0.27"
```

完整代码（`examples/ch17_morphology.rs`）：

```rust
use image::{GrayImage, ImageBuffer, Luma};
use imageproc::contrast::{otsu_level, threshold, ThresholdType};
use imageproc::distance_transform::Norm;
use imageproc::morphology::{close, dilate, erode, open};

/// 统计一张二值图里「白色前景」像素的个数
fn count_white(img: &GrayImage) -> u32 {
    img.as_raw().iter().filter(|&&v| v > 0).count() as u32
}

/// 合成一张「带毛刺 + 小噪点 + 小洞」的二值图，前景为白 255
fn make_binary(w: u32, h: u32) -> GrayImage {
    let mut img: GrayImage = ImageBuffer::new(w, h);
    // 主体：一个大实心矩形（前景白）
    for y in 30..110 {
        for x in 40..160 {
            img.put_pixel(x, y, Luma([255]));
        }
    }
    // 毛刺：矩形顶部伸出的 1 像素宽尖刺（腐蚀/开运算应当把它啃掉）
    for y in 24..30 {
        img.put_pixel(81, y, Luma([255]));
    }
    // 小洞：主体内部挖掉一个 2x2 的小块（变回背景 0）——闭运算应当把它填上
    // （k=1 的结构元素只能填「细小」的洞；洞太大就得加大 k，见正文）
    for y in 63..65 {
        for x in 97..99 {
            img.put_pixel(x, y, Luma([0]));
        }
    }
    // 背景上的椒盐噪点（孤立小白点）——开运算应当把它们清掉
    let dots = [(15, 15), (25, 120), (180, 20), (170, 125), (100, 18)];
    for (x, y) in dots {
        img.put_pixel(x, y, Luma([255]));
    }
    // 一个 2x2 的稍大噪块
    for (x, y) in [(10, 70), (11, 70), (10, 71), (11, 71)] {
        img.put_pixel(x, y, Luma([255]));
    }
    img
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let bin = make_binary(200, 140);

    // 用 L1 距离、k=1 的结构元素（十字形）做四种基本运算
    let n = Norm::L1;
    let eroded = erode(&bin, n, 1);
    let dilated = dilate(&bin, n, 1);
    let opened = open(&bin, n, 1);
    let closed = close(&bin, n, 1);

    println!("== 前景白像素个数（k=1, Norm::L1）==");
    println!("原图   : {}", count_white(&bin));
    println!("腐蚀   : {}  (前景被啃小)", count_white(&eroded));
    println!("膨胀   : {}  (前景长大)", count_white(&dilated));
    println!("开运算 : {}  (去噪点, 主体基本不变)", count_white(&opened));
    println!("闭运算 : {}  (填小洞, 主体基本不变)", count_white(&closed));

    // 验证「开运算去掉了背景噪点」：数左上角 (0,0)-(30,30) 这块的白像素
    let count_region = |img: &GrayImage| -> u32 {
        let mut c = 0;
        for y in 0..30 {
            for x in 0..30 {
                if img.get_pixel(x, y)[0] > 0 {
                    c += 1;
                }
            }
        }
        c
    };
    println!(
        "\n左上角噪点区白像素：开运算前 {} → 开运算后 {}",
        count_region(&bin),
        count_region(&opened)
    );

    // 验证「闭运算填上了小洞」：看洞里的一个点 (98,64)
    println!(
        "小洞内像素 (98,64)：原图 {} → 闭运算后 {}",
        bin.get_pixel(98, 64)[0],
        closed.get_pixel(98, 64)[0]
    );

    // ---- 实战：先 Otsu 二值化，再开运算去噪 ----
    // 合成灰度图：暗背景(30~70 渐变) + 亮物体(180) + 椒盐噪点(255)
    let (gw, gh) = (160u32, 120u32);
    let mut gray: GrayImage = ImageBuffer::from_fn(gw, gh, |x, _| {
        Luma([(30 + x * 40 / (gw - 1)) as u8]) // 背景从左到右 30 → 70
    });
    for y in 30..90 {
        for x in 40..120 {
            gray.put_pixel(x, y, Luma([180])); // 亮物体
        }
    }
    // 确定性地撒一些亮噪点（255）到背景，保证输出可复现
    let mut seed: u32 = 12345;
    let mut rng = || {
        seed = seed.wrapping_mul(1103515245).wrapping_add(12345);
        (seed >> 16) & 0x7fff
    };
    for _ in 0..250 {
        gray.put_pixel(rng() % gw, rng() % gh, Luma([255]));
    }

    let level = otsu_level(&gray);
    // 亮物体 -> 白(前景)，暗背景 -> 黑；前景为白，符合形态学约定
    let bw = threshold(&gray, level, ThresholdType::Binary);
    let bw_open = open(&bw, Norm::LInf, 1); // LInf, k=1 => 3x3 方形结构元素

    println!("\n== Otsu + 开运算去噪 ==");
    println!("Otsu 阈值 = {}", level);
    println!("二值化后前景白像素 = {}", count_white(&bw));
    println!(
        "开运算后前景白像素 = {}  (噪点被清掉，物体主体保留)",
        count_white(&bw_open)
    );
    Ok(())
}
```

运行后终端打印（数字真实可复现）：

```text
== 前景白像素个数（k=1, Norm::L1）==
原图   : 9611
腐蚀   : 9193  (前景被啃小)
膨胀   : 10053  (前景长大)
开运算 : 9593  (去噪点, 主体基本不变)
闭运算 : 9617  (填小洞, 主体基本不变)

左上角噪点区白像素：开运算前 1 → 开运算后 0
小洞内像素 (98,64)：原图 0 → 闭运算后 255

== Otsu + 开运算去噪 ==
Otsu 阈值 = 70
二值化后前景白像素 = 4989
开运算后前景白像素 = 4800  (噪点被清掉，物体主体保留)
```

几个结论一一对上了前面的原理：

1. **腐蚀 9193 < 原图 9611 < 膨胀 10053**——腐蚀把前景啃小、膨胀让它长大，一目了然。
2. **开运算把背景噪点清掉了**：左上角噪点区的白像素从 `1` 变成 `0`，而总量 `9593` 和原图几乎一样——主体没伤着。
3. **闭运算把小洞填上了**：洞里的点 `(98,64)` 从 `0` 变成了 `255`。注意洞必须够小（这里 2×2）才填得上；6×6 的大洞用 `k=1` 是填不满的，得加大 `k`。
4. **实战最漂亮**：Otsu 选出阈值 `70`（正好落在背景渐变 30~70 和物体 180 之间的"山谷"），二值化后混进了噪点（`4989`）；一次开运算后**恰好剩 4800 = 80×60 的物体本体**，噪点被清得干干净净。这就是"二值化 → 形态学去噪"这条经典流水线的威力。

## 常见坑与提示

> 🕳️ **坑**：**前景不是白色，一切都反了。** imageproc 把非零像素当前景。若你的物体是黑的（白纸黑字、深色零件配亮背景），`erode` 啃的是那片白背景、`dilate` 让背景吞掉物体，效果全反。动手前务必确认前景=白 255，否则先取反或改用 `BinaryInverted` 二值化。

> ⚠️ **注意**：**`k` 是"距离半径"，不是"核尺寸"。** 从 OpenCV 迁移过来的读者最容易在这栽跟头：OpenCV 传的是 3×3、5×5 的核大小，而 imageproc 传的是"半径 `k` + 距离度量 `Norm`"。想要经典 3×3 方形结构元素，写 `Norm::LInf, 1`；想要十字形，写 `Norm::L1, 1`。

> 🕳️ **坑**：**开/闭运算有损，不是可逆变换。** `open` 抹掉的噪点、`close` 填掉的洞，都回不去了。它们是"整形"而非"还原"——被啃掉的真实细节（比如物体上一个合法的小尖角）也会一并消失。选 `k` 时要权衡：`k` 越大去噪越狠，但主体细节也丢得越多。

> 💡 **提示**：**去噪点用开、填小洞用闭，顺序不能反。** 记不住就想口诀"开去点、闭填洞"。实战里常常**先开后闭**：先用开抹掉背景碎点，再用闭补上物体内部的小洞，得到一张干净利落的掩膜，为下一章"数物体"做好准备。

## 本章小结

- 形态学处理的是**二值图的形状**；铁律是**前景必须为白色 255**（imageproc 把非零当前景）。
- 结构元素用 `(Norm, k)` 描述：`k` 是距离半径，`Norm::L1` 给菱形/十字、`Norm::LInf` 给方形、`Norm::L2` 给近似圆。
- **腐蚀啃小**（去毛刺、断细连、去小噪点），**膨胀长大**（填缝、连断裂、堵小洞）；两者互为反操作但**不可逆**。
- **开运算 = 先腐蚀后膨胀，去外部小白点**；**闭运算 = 先膨胀后腐蚀，填内部小黑洞**；主体大小都基本保持。口诀："开去点、闭填洞"。
- 形态学梯度（膨胀−腐蚀）出轮廓，顶帽/黑帽抠小亮/小暗细节；灰度形态学用 `Mask` 指定结构元素。
- 经典流水线 **Otsu 二值化 → 开运算去噪**，实测能把混入噪点的掩膜清成干净的物体本体。

## 动手练习

1. **调 k 看力度**：把四种运算的 `k` 从 `1` 改成 `2`、`3`，观察白像素个数怎么变，体会"啃/长"的幅度随 `k` 增大而变强。
2. **故意踩坑**：把 `make_binary` 的前景改成黑色（255 与 0 互换），直接对它 `erode`，看看结果是不是"反了"，亲手验证"前景须白"这条铁律。
3. **连断裂**：合成一条中间断开一小段的斜线（前景白），用 `close(&img, Norm::LInf, 2)` 把它连起来；再想想为什么这里选 `LInf` 比 `L1` 更容易连上对角方向的缺口。
4. **进阶——形态学梯度**：用 `dilate` 减去 `erode`（逐像素相减）得到形态学梯度图，把主体矩形的边缘"描"出来，存成 PNG 看看效果，并和 [第 15 章](ch15-edges.md) 的 Sobel/Canny 边缘对比。
