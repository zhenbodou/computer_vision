# 第 15 章 梯度与边缘检测（Sobel、Canny）

> **本章导读**
> - 学完你能：讲清楚"边缘"在数学上到底是什么，并动手用 **Sobel** 算出一张图的**梯度幅值图**。
> - 理解**梯度**的直觉（就是"变化率"），会把水平、垂直两个方向的梯度合成**幅值**与**方向**。
> - 跑通工业界最常用的边缘检测器 **Canny**，看懂它的**五个步骤**，并亲手实验**高/低阈值**对结果的影响。
> - 记住两条铁律：**先降噪再检测**、**看清 `i16`/`u16` 的类型再可视化**。

## 场景：让程序找出零件的轮廓

设想一条产线：摄像头拍下一个金属垫片，你要量它的外径。第一步，得先让程序把垫片的**边缘**（轮廓）从背景里描出来——有了边缘，才能谈测量、定位、计数。

那"边缘"到底是什么？你盯着一张图看，所谓边缘，就是**颜色/明暗发生剧烈变化的地方**：垫片是亮的、背景是暗的，两者交界的那一圈，像素值"唰"地从 200 掉到 30。**边缘检测的本质，就是找出图像里"变化最剧烈"的那些像素。** 这一章我们就从"怎么衡量变化"讲起，一路做到能勾出干净轮廓的 Canny。

## 原理：从"变化率"到"梯度"

### 一维直觉：导数就是变化率

先把问题降到一维。假设沿着一行像素走，亮度是这样一串数：`… 100 100 100 200 200 200 …`。中间从 100 跳到 200 的地方，就是边缘。怎么用数字抓住它？答案是**求变化率**——也就是高中学过的**导数（derivative）**。

对离散的像素，导数可以用**相邻像素相减**来近似：

\\[ f'(x) \approx \frac{f(x+1) - f(x-1)}{2} \\]

在平坦区域（`100 100 100`），相减得 0；在跳变处（`100 → 200`），相减得一个大值。**所以"一阶导数的绝对值大"就意味着"这里有边缘"。** 这就是全部秘密。

### 二维：梯度是带方向的箭头

图像是二维的，一个像素在**水平方向**和**垂直方向**都可能变化。我们分别求这两个方向的变化率，记作 \\( G_x \\)（横向）和 \\( G_y \\)（纵向），把它们拼成一个向量，就是**梯度（gradient）**：

\\[ \nabla f = (G_x,\ G_y) \\]

梯度是个**箭头**：它的**长度**表示"变化有多剧烈"，方向指向"亮度增长最快的那一侧"。我们最关心两个量——**梯度幅值（magnitude）**和**梯度方向（direction）**：

\\[ |\nabla f| = \sqrt{G_x^2 + G_y^2}, \qquad \theta = \arctan\!\big(G_y / G_x\big) \\]

幅值大的地方就是边缘；方向则告诉你这条边缘是"竖着的"还是"横着的"。一条**竖直的边**（比如垫片的左右两侧），亮度在水平方向剧烈变化、竖直方向几乎不变，所以 \\( G_x \\) 很大、\\( G_y \approx 0 \\)，梯度方向指向水平（0°）。这个结论待会儿代码里会**实测**验证。

### Sobel / Prewitt / Scharr：三兄弟算子

直接用相邻两像素相减太"敏感"——图像里一点噪声就会被当成边缘。实践中我们用一个 3×3 的小窗口（**卷积核**，见 [第 13 章 卷积原理与线性滤波](ch13-convolution.md)）来求导，顺便把上下几行也拉进来平均一下，抗噪更好。最经典的是 **Sobel 算子**：

```text
  横向 Gx（检测竖直边缘）      纵向 Gy（检测水平边缘）
    -1   0  +1                   -1  -2  -1
    -2   0  +2                    0   0   0
    -1   0  +1                   +1  +2  +1
```

看 \\( G_x \\) 这个核：右列是正、左列是负，中间行权重加倍。把它盖在图像上滑一遍，**本质就是"右边像素之和 减 左边像素之和"**——正是水平方向的变化率，而且中间行加权让结果更稳。\\( G_y \\) 只是把它转 90°。

它还有两个亲戚，长得几乎一样，只是权重不同：

- **Prewitt**：三行权重都是 `1`（不给中间行加倍），最朴素。
- **Scharr**：中间行权重用 `10`、上下用 `3`，在**梯度方向的精度**上更好，需要精确角度时（如后面的纹理、SIFT）常用它。

> 📖 **术语**：**算子（operator）** 在这里就是指一个用于卷积的**小矩阵（卷积核 / kernel）**。"Sobel 算子"= 上面那两个 3×3 矩阵。别被"算子"这个词唬住，它就是一小把权重数字。

## 动手写代码：Sobel 梯度图 + Canny 边缘

我们合成一张含几何形状的灰度图（亮矩形 + 暗圆），做三件事：① 用 `sobel_gradients` 直接拿到梯度幅值图；② 用 `horizontal_sobel`/`vertical_sobel` 手动合成幅值与方向，验证"竖直边缘 → 方向 0°"；③ 跑 Canny，实验阈值与降噪的影响。

`Cargo.toml`：

```toml
[dependencies]
image = "0.25"
imageproc = "0.27"
```

完整代码（`examples/ch15_edges.rs`）：

```rust
use image::{GrayImage, ImageBuffer, Luma};
use imageproc::edges::canny;
use imageproc::filter::gaussian_blur_f32;
use imageproc::gradients::{horizontal_sobel, sobel_gradients, vertical_sobel};

/// 极简可复现伪随机数（线性同余），用来加噪声，避免引入 rand 依赖
struct Lcg(u64);
impl Lcg {
    fn next_u8(&mut self) -> u8 {
        self.0 = self.0.wrapping_mul(6364136223846793005).wrapping_add(1442695040888963407);
        (self.0 >> 33) as u8
    }
}

/// 合成灰度场景：中灰背景(100) + 亮矩形(200) + 暗圆(30)
fn make_scene(w: u32, h: u32) -> GrayImage {
    ImageBuffer::from_fn(w, h, |x, y| {
        let (xi, yi) = (x as i32, y as i32);
        if (40..110).contains(&xi) && (40..130).contains(&yi) {
            return Luma([200]); // 亮矩形
        }
        let (cx, cy, rad) = (175, 90, 35);
        if (xi - cx).pow(2) + (yi - cy).pow(2) < rad * rad {
            return Luma([30]); // 暗圆
        }
        Luma([100]) // 背景
    })
}

/// 给灰度图加均匀噪声（范围约 ±amp），结果 clamp 到 [0,255]
fn add_noise(img: &GrayImage, amp: i32, seed: u64) -> GrayImage {
    let mut rng = Lcg(seed);
    ImageBuffer::from_fn(img.width(), img.height(), |x, y| {
        let base = img.get_pixel(x, y)[0] as i32;
        let noise = (rng.next_u8() as i32 % (2 * amp + 1)) - amp;
        Luma([(base + noise).clamp(0, 255) as u8])
    })
}

/// 把 u16 梯度幅值图归一化到 u8 便于可视化（关键：类型转换！）
fn u16_to_u8_normalized(g: &ImageBuffer<Luma<u16>, Vec<u16>>) -> GrayImage {
    let max = g.iter().copied().max().unwrap_or(1).max(1) as f32;
    ImageBuffer::from_fn(g.width(), g.height(), |x, y| {
        let v = g.get_pixel(x, y)[0] as f32;
        Luma([(v / max * 255.0) as u8])
    })
}

/// 统计二值边缘图中值为 255 的像素数
fn count_edges(img: &GrayImage) -> u32 {
    img.iter().filter(|&&p| p == 255).count() as u32
}

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let scene = make_scene(240, 180);

    // ① Sobel 梯度幅值：imageproc 内部已算好 sqrt(Gx^2+Gy^2)，返回 Luma<u16>
    let grad = sobel_gradients(&scene);
    println!("Sobel 梯度幅值最大值 = {}", grad.iter().copied().max().unwrap_or(0));

    // ② 分别取水平/垂直 Sobel（Luma<i16>，带符号！），手动合成幅值与方向
    let gx = horizontal_sobel(&scene);
    let gy = vertical_sobel(&scene);
    let (px, py) = (40u32, 85u32); // 矩形左边缘上一点：一条竖直边缘
    let dx = gx.get_pixel(px, py)[0] as f32;
    let dy = gy.get_pixel(px, py)[0] as f32;
    println!(
        "竖直边缘点(40,85): Gx={}, Gy={}, 幅值={:.1}, 方向={:.1}°",
        dx as i32, dy as i32, (dx * dx + dy * dy).sqrt(), dy.atan2(dx).to_degrees()
    );

    // ③ Canny：同一张含噪图，阈值不同结果天差地别
    let noisy = add_noise(&scene, 25, 12345);
    let e_lo = canny(&noisy, 10.0, 30.0); // 阈值太低：噪声也被当成边缘
    let e_ok = canny(&noisy, 40.0, 80.0); // 阈值合适：干净地勾出形状
    let e_hi = canny(&noisy, 100.0, 200.0); // 阈值太高：弱边缘丢失
    println!(
        "含噪图 Canny：低(10,30)={}, 合适(40,80)={}, 高(100,200)={}",
        count_edges(&e_lo), count_edges(&e_ok), count_edges(&e_hi)
    );

    // ④ "先降噪"的重要性：低阈值下，先高斯降噪能压掉海量噪声边缘
    let denoised = gaussian_blur_f32(&noisy, 2.0);
    println!(
        "低阈值(10,30)下：含噪直接={}, 先降噪再 Canny={}",
        count_edges(&e_lo), count_edges(&canny(&denoised, 10.0, 30.0))
    );

    u16_to_u8_normalized(&grad).save("out_ch15_sobel_mag.png")?;
    e_ok.save("out_ch15_canny_ok.png")?;
    e_lo.save("out_ch15_canny_lowthresh.png")?;
    Ok(())
}
```

运行 `cargo run --example ch15_edges`，终端打印（数字真实可复现）：

```text
Sobel 梯度幅值最大值 = 424
竖直边缘点(40,85): Gx=400, Gy=0, 幅值=400.0, 方向=0.0°
含噪图 Canny：低(10,30)=5385, 合适(40,80)=580, 高(100,200)=320
低阈值(10,30)下：含噪直接=5385, 先降噪再 Canny=621
```

逐条看结论：

1. **竖直边缘点 `Gx=400, Gy=0, 方向=0.0°`**——完美印证前面的推导：矩形左边是一条竖直边，亮度只在水平方向变，所以横向梯度 \\( G_x \\) 拉满、纵向 \\( G_y \\) 为 0，梯度方向水平（0°）。理论上一个 `100→200` 的台阶经 Sobel 得到 \\( 4\times100=400 \\)，实测正好 400。
2. **梯度幅值最大 424**——出现在矩形拐角（横竖两个方向同时变化）。作为参考，Canny 源码给出的最大可能边缘强度约 \\( \sqrt5 \times 2 \times 255 \approx 1140 \\)（对应 0↔255 的满台阶）；我们的台阶只有 100，所以幅值小得多。**这个上限决定了 Canny 阈值该往多大取。**
3. **同一张含噪图，Canny 阈值不同结果天差地别**：低阈值 `(10,30)` 冒出 **5385** 个边缘像素（噪声全被当成了边缘），合适的 `(40,80)` 干净地剩 **580** 个（恰好勾出矩形+圆），过高的 `(100,200)` 只剩 **320**（较弱的圆边缘开始丢失）。
4. **低阈值下先降噪的威力**：同样用 `(10,30)`，含噪图直接检测得 **5385** 个"边缘"（绝大多数是噪声），而先做一次高斯模糊再检测，立刻降到 **621**——噪声被抹平，只剩真正的轮廓。

### Canny 的五个步骤

`canny(&gray, low, high)` 一行就跑完了，但它内部干了五件事，值得记牢（这也是"会用"和"精通"的分界）：

1. **高斯降噪**：先用高斯模糊抹掉噪点（imageproc 内部固定用 \\( \sigma=1.4 \\)），否则噪声会制造无数假边缘。
2. **算梯度**：用 Sobel 求每个像素的梯度幅值和方向。
3. **非极大值抑制（NMS）**：边缘经 Sobel 后是"粗"的一片。NMS 沿梯度方向只保留幅值**最大**的那个像素，把边缘"细化"成一根线。
4. **双阈值（high / low）**：幅值 > `high` 的是"铁定边缘"（强边缘）；`low ~ high` 之间的是"疑似边缘"（弱边缘）；< `low` 的直接丢弃。
5. **滞后连接（hysteresis）**：只有当弱边缘**紧挨着**强边缘时，才把它也认成边缘——这样既保住了连贯的轮廓，又滤掉了孤立的噪声点。

> 💡 **提示**：**双阈值怎么选？** 常用经验是 `high : low ≈ 2:1 或 3:1`。先根据你的边缘强度量级定 `high`（回忆上限约 1140），再取其 1/2~1/3 作 `low`。拿不准就像本章这样，跑几组打印边缘像素数，或直接看输出图挑一组"轮廓连贯又没噪声"的。

## 常见坑与提示

> 🕳️ **坑**：**不降噪直接检测 = 满屏假边缘。** 本章实测：低阈值下含噪图直接跑出 5385 个"边缘"，先降噪只剩 621。Canny 虽然内部已带 \\( \sigma=1.4 \\) 的高斯模糊，但面对**较强噪声**或你**不得不用低阈值**时，这点内建平滑不够，仍需自己先用高斯/中值滤波（见 [第 14 章 非线性滤波](ch14-nonlinear-filter.md)）降噪。**边缘检测前先降噪，是刻进肌肉记忆的第一反应。**

> ⚠️ **注意**：**`i16` 与 `u16` 千万别搞混。** `horizontal_sobel`/`vertical_sobel` 返回 **`Luma<i16>`**——带符号，因为梯度有正负（亮→暗 vs 暗→亮）。而 `sobel_gradients` 返回的是幅值 **`Luma<u16>`**——恒非负。想可视化 `i16` 的方向图，要把 0 映射到中灰 128（`128 + Gx/scale`）；想可视化 `u16` 的幅值图，要**归一化**到 `0~255`（如代码里的 `u16_to_u8_normalized`），否则直接 `as u8` 截断会让强边缘溢出、图全黑或全白。

> 🕳️ **坑**：**梯度方向用 `atan2(Gy, Gx)`，不是 `atan(Gy/Gx)`。** 后者丢掉象限信息（且 \\( G_x=0 \\) 时除零），只有 `atan2` 能给出完整的 `-180°~180°`。Rust 里写 `dy.atan2(dx)`，注意**参数顺序是 (y, x)**。

> 💡 **提示**：**要精确的边缘方向就用 Scharr。** Sobel 在斜方向上的角度略有偏差；`horizontal_scharr`/`vertical_scharr` 的核（`3,10,3`）专门优化了旋转对称性，测角度更准。用法和 Sobel 完全一样。

## 本章小结

- **边缘 = 像素剧烈变化处**；衡量变化靠**导数（变化率）**，离散图像上用相邻像素相减近似。
- **梯度**是二维导数向量 \\( (G_x, G_y) \\)：**幅值** \\( \sqrt{G_x^2+G_y^2} \\) 表示变化剧烈程度，**方向** \\( \arctan(G_y/G_x) \\) 指出边缘朝向。竖直边缘 → \\( G_x \\) 大、方向 0°（本章实测 `Gx=400, 方向 0°`）。
- **Sobel/Prewitt/Scharr** 是三个 3×3 求导算子：Sobel 最常用，Prewitt 最朴素，Scharr 测角度最准。`sobel_gradients` 返回幅值 `Luma<u16>`；`horizontal_sobel`/`vertical_sobel` 返回带符号的 `Luma<i16>`。
- **Canny** 五步：高斯降噪 → 算梯度 → 非极大值抑制 → 双阈值 → 滞后连接，产出**细而连贯**的二值边缘图。
- 三条铁律：**先降噪**（低阈值下 5385 vs 621）、**双阈值按 2:1~3:1 选**、**`i16`/`u16` 要看清再可视化**。

## 动手练习

1. **对比三算子**：把代码里的 `sobel_gradients` 换成 `prewitt_gradients`，再用 `horizontal_scharr`+`vertical_scharr` 手动合成幅值，比较三者梯度幅值最大值有何不同。
2. **画方向图**：把 `horizontal_sobel` 的 `i16` 结果映射到 `u8`（`(v.clamp(-255,255)/2 + 128) as u8`）存成图，观察竖直边缘和水平边缘分别在哪个方向图里最亮。
3. **阈值扫描**：写个循环，对含噪图在 `low` 从 10 到 100（`high = 2*low`）逐个跑 Canny，打印边缘像素数，找到"数目趋于稳定"的那段——那通常就是好阈值区间。
4. **进阶**：给场景加一个和背景对比度很低的浅灰方块（如亮度 120，背景 100），观察它的边缘在什么阈值下才会消失，体会"弱边缘"为什么难抓。
