# 第 54 章 人脸关键点与人脸对齐

## 场景：刷脸之前，先把脸"摆正"

你刷脸解锁手机时，脑袋可能是歪的、离得有远有近。可人脸识别模型偏偏对**姿态、尺度**很敏感——同一个人歪着头和正对镜头，像素差异巨大。工业级人脸系统的通用第一步，就是先**定位人脸关键点**（眼睛、鼻子、嘴），再据此把每张脸**旋转、缩放、平移到一个统一的"标准姿势"**——这叫**人脸对齐（face alignment）**。对齐之后，所有脸都眼睛在同一高度、大小一致，识别模型的日子就好过多了。

这一章我们把这条链路走一遍：**合成人脸 → 回归 5 个关键点 → 求相似变换 → 把脸摆正**。它用到 [第 52 章](ch52-keypoint-basics.md) 的关键点思想和 [第 30 章](../p05-numeric/ch30-nalgebra.md) 的线性代数。

> 📖 **术语**：**人脸关键点 / 人脸地标（facial landmark）**。人脸上有语义的点。工业界常用 **5 点**（左右眼中心、鼻尖、左右嘴角）做对齐，用 **68 点**（勾出脸轮廓、眉、眼、鼻、唇）做更精细的分析（美颜、表情）。本章用最经典的 **5 点**。

## 原理一：直接坐标回归 vs 热图回归——这次反着选

[第 52 章](ch52-keypoint-basics.md) 我们论证过"热图回归比直接坐标回归更稳"。可**这一章我偏偏用直接坐标回归**——不是打脸，而是因为**场景变了**：

- 人脸对齐的输入，通常是**人脸检测器**（[第 56 章](../p12-face/ch56-face-detection.md)）已经**裁好、大致居中的单张人脸**；
- 关键点**数目少（5 个）、拓扑固定**（永远是两眼一鼻两嘴角）；
- 我们要的就是**一组坐标**，后面立刻拿去算变换矩阵。

这种"单目标、已裁剪、少量固定点"的场合，**直接回归又快又简单**——网络最后接一个全连接层，一口气吐出 \\( 2K \\) 个坐标，省掉了热图的解码步骤。这也是很多实用人脸对齐器（尤其移动端）的做法。**取舍很清楚**：位置任意、需要空间鲁棒性、点多或多目标 → 热图（[第 52 章](ch52-keypoint-basics.md)、[第 53 章](ch53-human-pose.md)）；已裁剪的单目标、少量固定点、要极致轻量 → 直接回归。

> 🕳️ **坑（务必记住）**：**直接回归绝对坐标，别用 1×1 卷积头，要用全连接头。** 卷积是**平移等变**的（[第 52 章](ch52-keypoint-basics.md)）——同一个滤波器在全图共享权重，它**天生说不出"绝对位置是 37"**。若你用 1×1 卷积头去回归绝对坐标，损失会**死死卡住**学不动。正确做法是**先把卷积特征展平、再接全连接层**：全连接的权重和展平后的**每个空间位置一一对应**，才能把"眼睛出现在特征图哪个位置"映射成一个绝对坐标（这也是 [第 42 章](../p08-classification/ch42-candle-classify.md) 分类头能work的同理）。实在想用卷积头，就得像检测框那样**显式注入格子坐标**（格中心 + 偏移）。

## 原理二：人脸对齐 = 求一个相似变换

有了 5 个关键点，怎么"摆正"？我们准备一组**标准模板点** \\( q_i \\)（比如"正脸时双眼该在哪、鼻嘴该在哪"），再找一个变换，把**检测到的 5 点** \\( p_i \\) 尽量贴到模板上。这个变换用**相似变换（similarity transform）**：

\\[ q = s R p + t \\]

它由三部分组成：**旋转 \\( R \\)**（把歪的脸转正）、**等比缩放 \\( s \\)**（把远近不同的脸缩到统一大小）、**平移 \\( t \\)**（对齐位置）。关键是它**只有这三样、没有拉伸错切**——所以**不会把脸拉变形**，只是"端正地"把脸摆好。这正是对齐要的：去掉姿态和尺度，**保住五官的相对形状**。

> 📖 **术语**：**为什么是"相似"变换，而不是仿射或透视？** 仿射变换（[第 10 章](../p02-image-basics/ch10-geometry.md)）允许非等比缩放和错切，会把脸压扁拉歪；透视更自由。对齐**只想消除刚性位姿 + 尺度**，保持人脸本身的比例不失真，所以用自由度恰到好处的相似变换（4 个自由度：旋转角、缩放、平移 x/y）。

**怎么求这个最优变换？** 5 个点要满足一个 4 自由度的变换，是**超定**的（点比自由度多），求**最小二乘**解：

\\[ \min_{s, R, t} \sum_{i} \lVert s R p_i + t - q_i \rVert^2 \\]

这有个经典闭式解——**Umeyama 算法**：先各自去中心，算两组点的**协方差矩阵**，对它做 **SVD** 得到旋转（还要处理一下"别求出镜像"），再由奇异值算出缩放，最后回代得平移。SVD 我们在 [第 30 章](../p05-numeric/ch30-nalgebra.md)、[第 66 章](../p14-3d/ch66-epipolar-pnp.md) 都用过，`nalgebra` 直接支持。

### 合成人脸 + 直接回归网络

我们合成 48×48 的卡通脸：一个椭圆脸盘，在随机的**旋转/缩放/位置**下画上双眼（深）、鼻（灰）、嘴（深线），5 个关键点就是这些器官的位置（合成与画脸细节见配套工程）。网络是"卷积骨干 + **全连接头**"，直接回归 10 个归一化坐标：

```rust
struct FaceNet { conv1: Conv2d, conv2: Conv2d, conv3: Conv2d, fc1: Linear, out: Linear }
impl FaceNet {
    fn load(vb: VarBuilder) -> Result<Self> {
        let c = Conv2dConfig { padding: 1, ..Default::default() };
        Ok(Self {
            conv1: conv2d(3, 16, 3, c, vb.pp("conv1"))?,
            conv2: conv2d(16, 32, 3, c, vb.pp("conv2"))?,
            conv3: conv2d(32, 64, 3, c, vb.pp("conv3"))?,
            fc1: linear(64 * 6 * 6, 128, vb.pp("fc1"))?,   // 展平后接全连接：能回归绝对坐标的关键
            out: linear(128, 2 * K, vb.pp("out"))?,         // 输出 2K 个归一化坐标
        })
    }
    fn forward(&self, x: &Tensor) -> Result<Tensor> {
        let x = self.conv1.forward(x)?.relu()?.max_pool2d(2)?;  // 48→24
        let x = self.conv2.forward(&x)?.relu()?.max_pool2d(2)?; // 24→12
        let x = self.conv3.forward(&x)?.relu()?.max_pool2d(2)?; // 12→6
        let x = x.flatten_from(1)?;                             // 展平 → [N, 64*6*6]
        let x = self.fc1.forward(&x)?.relu()?;
        self.out.forward(&x)                                    // [N, 2K]
    }
}
```

训练用 **MSE**（预测归一化坐标 vs 真值归一化坐标），AdamW + lr 衰减、确定性初始化（同前几章）。真实训练输出：

```text
开始训练（AdamW lr=2e-3→3e-4，MSE 坐标回归）...
  epoch         MSE
      1    0.283831
     60    0.001078
    120    0.000161
    240    0.000080
    300    0.000074
```

MSE 从 0.28 一路降到 0.00007（**注意它没有卡住——因为我们用的是全连接头**）。在 64 张全新测试脸上的定位误差：

```text
===== 定位误差（64 张全新测试脸，共 320 个关键点）=====
  平均定位误差 = 1.113 像素
  分关键点(像素)：左眼=1.12  右眼=1.09  鼻=1.02  左嘴角=1.18  右嘴角=1.16
```

**平均定位误差 1.11 像素**，五个关键点误差都在 1 像素上下，很均衡。

### Umeyama 相似变换（nalgebra）

拿到预测的 5 点，用 Umeyama 求把它对齐到模板的相似变换。整段就是 [第 30 章](../p05-numeric/ch30-nalgebra.md) 的线代 + 一次 2×2 SVD：

```rust
use nalgebra::{Matrix2, Vector2};
// 求 (scale, R, t) 使 Σ‖scale·R·src + t − dst‖² 最小
fn umeyama(src: &Lms, dst: &Lms) -> (f32, Matrix2<f32>, Vector2<f32>) {
    let n = K as f32;
    let (mut mu_s, mut mu_d) = (Vector2::zeros(), Vector2::zeros());
    for k in 0..K { mu_s += Vector2::new(src[k][0],src[k][1]); mu_d += Vector2::new(dst[k][0],dst[k][1]); }
    mu_s /= n; mu_d /= n;                            // 两组点各自的质心
    let (mut sigma, mut var_s) = (Matrix2::zeros(), 0f32);
    for k in 0..K {
        let ds = Vector2::new(src[k][0],src[k][1]) - mu_s;
        let dd = Vector2::new(dst[k][0],dst[k][1]) - mu_d;
        sigma += dd * ds.transpose();               // 协方差累加
        var_s += ds.norm_squared();                 // src 的方差（算 scale 用）
    }
    sigma /= n; var_s /= n;
    let svd = sigma.svd(true, true);                 // 2×2 SVD
    let (u, v_t) = (svd.u.unwrap(), svd.v_t.unwrap());
    // 防镜像：若 det(U·Vᵀ)<0，翻转最后一个奇异方向，保证是纯旋转
    let d = (u * v_t).determinant();
    let s_fix = Matrix2::new(1.0, 0.0, 0.0, if d < 0.0 { -1.0 } else { 1.0 });
    let r = u * s_fix * v_t;
    let w = svd.singular_values;
    let scale = (w[0]*s_fix[(0,0)] + w[1]*s_fix[(1,1)]) / var_s;
    let t = mu_d - (r * mu_s) * scale;               // t = μ_d − s·R·μ_s
    (scale, r, t)
}
```

> 🕳️ **坑**：**别忘了"防镜像"那一步。** 纯 SVD 求出的 \\( U V^\top \\) 有可能是**反射**（行列式 -1）而非旋转——那样脸会被镜像翻转。用 `det(U V^T)` 的符号去修正最后一个奇异方向（上面的 `s_fix`），才能保证得到一个**真正的旋转**。这是 Umeyama / Kabsch 类算法的经典细节。

求出 `(scale, R, t)` 后，一方面把预测点代入算**对齐残差**，另一方面手写一个**反向映射 + 双线性采样**把整张脸 warp 到模板坐标系（即把脸摆正）。真实输出：

```text
===== 人脸对齐（相似变换 Umeyama，对齐到 48x48 标准模板）=====
  脸 #0: 旋转  -17.8°  缩放 0.905  对齐后残差 1.015 像素
  脸 #1: 旋转  -18.6°  缩放 1.026  对齐后残差 0.752 像素
  脸 #2: 旋转  -10.0°  缩放 0.877  对齐后残差 0.805 像素
  全测试集对齐后平均残差 = 0.887 像素（64 张脸）
```

**对齐后 5 点与模板的平均残差仅 0.887 像素**——说明相似变换把检测到的脸"严丝合缝"地摆到了标准位置。那个"旋转 -17.8°"就是算法**为了把这张歪 17.8° 的脸转正而反向施加的角度**（残差里剩下的那点，来自 1.1px 的关键点定位误差和人脸本身的形状抖动）。配套工程会存"对齐前/后"PNG：`face_before_N.png` 是**歪着的脸 + 黄叉标出的预测点**，`face_after_N.png` 是**摆正后的脸 + 绿叉标出的模板点**——眼睛被转到同一水平线、大小归一，一眼可见"脸正了"。

## 原理三：为什么对齐是人脸识别的关键前置

对齐这一步看着不起眼，却是 [第 57 章](../p12-face/ch57-face-recognition.md) 人脸识别效果的**隐形地基**：

- 识别模型学的是**人脸的身份特征**（"这是谁"）。如果不对齐，模型还得**顺带对抗姿态、尺度的变化**——同一个人歪头和正脸，输入分布差异巨大，识别难度陡增。
- 对齐把所有脸**标准化到同一姿势和大小**后，模型只需专注学"身份"，同一个人的不同照片在特征空间里挨得更近，不同人分得更开。**这就是为什么几乎所有人脸识别流水线，都先检测关键点、再对齐、才送进识别网络。**

## 常见坑与提示

> 🕳️ **坑**：**直接坐标回归对"没裁好/位置乱跑"的输入很脆。** 它的前提是输入已被人脸检测器裁成大致居中的单张脸。如果直接把整张大图（人脸位置任意）喂给它，全连接头要为所有可能位置死记硬背，会很吃力——这正是 [第 52 章](ch52-keypoint-basics.md) 说的热图更适合"位置任意"的原因。**先检测、裁剪、再回归关键点**，是这条路线的正确用法。

> ⚠️ **注意**：**模板点定义了"标准脸长什么样"，要和下游一致。** 工业界常用 ArcFace 的 112×112 五点模板等既定标准。你**训练识别模型时用的对齐模板，和推理时必须是同一套**——模板一换，对齐后的脸就偏了，识别特征全对不上。本章用了自定义的 48×48 模板，仅为演示。

> 🕳️ **坑**：**相似变换≠仿射变换，选错会把脸拉变形。** 想"端正地摆正、不失真"就用相似（旋转+等比缩放+平移）；用了带非等比缩放/错切的仿射，脸会被压扁拉歪，反而破坏身份特征。自由度要按需求选，别无脑上更自由的变换。

> 💡 **提示**：**遮挡、大角度侧脸时，5 点回归会飘。** 侧脸时一只眼、一个嘴角可能被挡，直接回归只会硬猜一个坐标（它给不出"没看见"）。真实系统要么用带可见性/不确定性的模型、要么对大角度侧脸单独处理。合成正脸无此问题，上真实数据前要留意。

## 本章小结

- **人脸关键点检测 + 人脸对齐**是人脸识别、美颜、换脸的共同前置：先定位眼鼻嘴等关键点，再把脸摆正到标准姿势。
- 关键点检测这次用**直接坐标回归**（卷积骨干 + **全连接头**）：适合"已裁剪的单张脸、少量固定点、要轻量"的场景；与 [第 52 章](ch52-keypoint-basics.md) 热图回归**互补**。**坑**：回归绝对坐标**必须用全连接头**，1×1 卷积头因平移等变会学不动。
- **人脸对齐 = 求相似变换**（旋转 + 等比缩放 + 平移，4 自由度，不失真），用 5 点最小二乘的闭式解 **Umeyama 算法**（协方差 → SVD → 防镜像 → 缩放 → 平移），`nalgebra` 一把梭。
- 实测：5 点回归平均定位误差 **1.11 像素**；Umeyama 对齐后 5 点与模板平均残差 **0.887 像素**，脸被稳稳摆正（旋转角/缩放系数都能实时算出）。
- 对齐**标准化了姿态与尺度**，让识别模型专注学身份——这是人脸识别效果的隐形地基（[第 57 章](../p12-face/ch57-face-recognition.md)）。

## 动手练习

1. **验证"1×1 卷积头学不动"**：把 `FaceNet` 的全连接头换成一个 1×1 卷积 + 全局平均池化去回归绝对坐标，重训，观察 MSE 是不是卡住不降——亲手踩一遍这个坑，理解平移等变为何回归不了绝对坐标。

3. **加大角度**：把合成人脸的旋转范围从 ±28° 扩到 ±60°，重训重测，看定位误差和对齐残差怎么涨——理解大角度侧脸的难处。
