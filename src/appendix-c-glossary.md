# 附录 C · 术语表

> 按类别分组，每条一两句话，括号是详解章节。查到哪个词、想深入就翻对应章。

## 图像基础

| 术语 | 含义 |
|------|------|
| 像素 (Pixel) | 图像的最小单元，一个带颜色值的点（第 2 章） |
| 分辨率 (Resolution) | 图像的宽×高像素数，如 1920×1080（第 2 章） |
| 灰度 (Grayscale) | 只有明暗、没有彩色的图，单通道 0~255（第 2 章） |
| 直方图 (Histogram) | 统计每个像素值出现次数的图表，判断曝光/对比度（第 3 章） |
| ROI (Region of Interest) | 这里指图像的一个子区域，只对其中一部分做处理；业务上的"感兴趣区"见第 22 章（第 3 章） |
| 色度抽样 (Chroma Subsampling) | 颜色信息按 4:4:4/4:2:2/4:2:0 等方式少存一些，人眼不敏感（第 4 章） |
| 二值化 (Binarization) | 把像素变成非黑即白（0 或 255），阈值是关键（第 8 章） |
| 帧率 (FPS) | 每秒帧数，视频流畅度与处理速度的度量（第 6 章） |

## 颜色与格式

| 术语 | 含义 |
|------|------|
| RGB | 红绿蓝三通道加色模型，屏幕显示标准（第 4 章） |
| BGR | RGB 的通道颠倒序，OpenCV 使用的顺序，不注意会出"蓝色人脸"（第 4 章） |
| HSV | 色相/饱和度/明度，贴近人描述颜色的方式，适合颜色筛选（第 4 章） |
| YUV / YCbCr | 亮度 + 两个色度分量，视频编码常用的颜色空间（第 4 章） |
| NV12 | YUV420 的一种内存排布，摄像头与解码器常见的输出格式（第 4 章） |
| JPEG | 有损压缩图片格式，核心是 DCT + 量化（第 5 章） |
| PNG | 无损压缩图片格式，基于 DEFLATE 算法（第 5 章） |

## 编解码与视频

| 术语 | 含义 |
|------|------|
| 编码 / 解码 (Codec) | 压缩、还原图像视频数据的过程与算法（第 5 章） |
| DCT (离散余弦变换) | 把图像从像素域变到频率域，JPEG 压缩的核心（第 5 章） |
| I 帧 / P 帧 / B 帧 | 视频中的独立帧 / 参考前帧 / 双向参考帧（第 6 章） |
| GOP (Group of Pictures) | 两个 I 帧之间的帧组，影响 seek 和压缩率（第 6 章） |
| 码率 (Bitrate) | 每秒视频数据量，决定画质和文件大小（第 6 章） |
| 容器 (Container) | MP4/MKV/MOV 等"包装盒"，里面装着编码后的流（第 6 章） |
| H.264 / H.265 | 最主流的视频编码标准，后者压缩率更高（第 6 章） |
| RTSP | 实时流协议，网络监控摄像头的标准传输协议（第 6 章） |

## 滤波、边缘与形态学

| 术语 | 含义 |
|------|------|
| 卷积 (Convolution) | 用一个核在图像上滑动加权求和，几乎所有空间滤波的基础（第 7 章） |
| 卷积核 (Kernel) | 卷积用的小权重矩阵，如 3×3 高斯核（第 7 章） |
| 高斯滤波 | 按高斯分布加权的平滑滤波器，最常用的降噪手段（第 7 章） |
| 中值滤波 | 取邻域中位数，专杀椒盐噪点且能保边（第 7 章） |
| 双边滤波 | 同时考虑空间距离和像素差值的保边平滑（第 7 章） |
| Sobel | 一阶边缘检测算子，Gx/Gy 两个核（第 8 章） |
| 拉普拉斯 | 二阶边缘检测算子，对边缘"过零点"敏感（第 8 章） |
| Canny | 业界标准的边缘检测流程，低误差、定位准（第 8 章） |
| 形态学 (Morphology) | 腐蚀/膨胀/开运算/闭运算，针对二值图（第 8 章） |
| 结构元素 (Structuring Element) | 形态学操作的"刷子"，形状大小影响效果（第 8 章） |

## 深度学习基础

| 术语 | 含义 |
|------|------|
| 神经网络 (Neural Network) | 由大量"神经元"（加权求和 + 激活函数）堆叠成的函数（第 11 章） |
| 训练 (Training) | 用数据反复调整权重，让模型学会任务（第 11 章） |
| 前向传播 (Forward) | 数据从输入流到输出、算出结果的过程（第 11 章） |
| 梯度下降 (Gradient Descent) | 训练时沿损失减小最快的方向更新权重（第 11 章） |
| 激活函数 (Activation) | 给神经元加非线性，ReLU/Sigmoid/Softmax 最常用（第 11 章） |
| ReLU | 负值归零、正值不变的激活函数，简单高效（第 11 章） |
| 感受野 (Receptive Field) | 一个神经元"看得到"的原始输入区域大小（第 11 章） |
| 参数量 (Parameters) | 模型权重的个数，直接决定模型文件大小（第 11 章） |
| FLOPs | 浮点运算次数，衡量模型的计算量（第 11 章） |
| 张量 (Tensor) | 高维数组，模型数据的标准载体（第 3、11 章） |
| 推理 (Inference) | 用训练好的模型对新数据做预测，本书主角（第 11、14 章） |
| Batch | 一次同时喂给模型的数据个数（第 11、13 章） |
| Softmax | 把一组数字变成和为 1 的概率分布（第 15 章） |
| Sigmoid | 把数字压进 (0,1) 的 S 形函数（第 15、16 章） |

## 模型部署与转换

| 术语 | 含义 |
|------|------|
| ONNX | 开放式神经网络交换格式，模型转换的"通用语"（第 13 章） |
| opset | ONNX 的算子集版本，越高算子越新（第 13 章） |
| 模型转换 (Conversion) | 把模型从一种框架/格式转到另一种（第 13 章） |
| 量化 (Quantization) | 把 FP32 权重压成 FP16/INT8，省内存、提速度（第 13 章） |
| FP32 / FP16 / INT8 | 单精度浮点 / 半精度浮点 / 8 位整数的数值格式（第 13 章） |
| TensorRT | NVIDIA GPU 的高性能推理引擎与转换工具（第 13 章） |
| OpenVINO | Intel 平台的推理工具包（第 13 章） |
| TFLite | TensorFlow Lite，移动端/嵌入式常用（第 13 章） |
| NCNN | 腾讯开源的移动端推理框架，纯 C++ 无依赖（第 13 章） |
| RKNN | 瑞芯微 NPU 的模型格式和工具链（第 13 章） |
| NPU | 神经网络专用处理器，推理快且省电（第 13、29 章） |
| 推理引擎 (Runtime) | 运行模型的运行时，如 ONNX Runtime、tract、TensorRT（第 14 章） |

## 预处理与后处理

| 术语 | 含义 |
|------|------|
| 预处理 (Preprocessing) | 推理前对图像做的所有准备工作（第 10 章） |
| 归一化 (Normalization) | 把像素缩放到 [0,1] 或标准化到均值 0 方差 1（第 10 章） |
| Letterbox | 等比缩放 + 灰边填充，保持长宽比不变形（第 10 章） |
| 插值 (Interpolation) | 缩放时计算新像素的方法：最近邻/双线性/双三次/Lanczos（第 10 章） |
| HWC / CHW | 张量的维度排布：高宽通道 / 通道高宽（第 4、10 章） |
| NCHW / NHWC | 带 batch 维度的排布，ONNX 常用 NCHW（第 10 章） |
| 后处理 (Post-processing) | 推理后把原始输出变成可用结果的工作（第 16 章） |
| 坐标还原 | 把模型输出坐标从 letterbox 图变回原始图像像素（第 16 章） |

## 模型家族（分类 / 检测 / 关键点 / 分割 / 差分 / 人脸）

| 术语 | 含义 |
|------|------|
| 分类 (Classification) | 判断整张图"是什么"，输出各类别分数（第 15 章） |
| Top-K | 取分数最高的 K 个类别作为结果（第 15 章） |
| 多标签 (Multi-label) | 一张图可同时属于多个类别，用 Sigmoid 而非 Softmax（第 15 章） |
| 锚框 (Anchor Box) | 检测模型预设的候选框；YOLOv5 用锚框，v8 改为无锚框（第 16 章） |
| 置信度 (Confidence) | 模型认为"这里有目标"的把握程度，0~1（第 16 章） |
| YOLO | You Only Look Once，经典单阶段检测器系列（第 16 章） |
| NMS | 非极大值抑制，删掉重叠重复的检测框（第 16 章） |
| IoU | 交并比，两个框重叠程度的度量（第 16 章） |
| mAP | 各个有效类别 AP 的平均值；检测/分割模型的常用精度指标，具体数值取决于评测协议（第 30 章） |
| 关键点 (Keypoint) | 目标上的语义点，如人体关节、人脸五官（第 17 章） |
| 热力图 (Heatmap) | 用高斯亮斑表示关键点位置概率的图（第 17 章） |
| 姿态估计 (Pose) | 由关键点推断出的人体/物体姿态（第 17 章） |
| 骨架 (Skeleton) | 把关键点按人体结构连起来的线（第 17 章） |
| 语义分割 (Semantic Segmentation) | 给每个像素打类别标签，不区分个体（第 18 章） |
| 实例分割 (Instance Segmentation) | 区分同类的不同个体，各自一张 mask（第 18 章） |
| 全景分割 (Panoptic Segmentation) | 语义分割 + 实例分割合一（第 18 章） |
| 原型 mask (Prototype Mask) | YOLO-seg 用少量原型线性组合出每个实例的掩膜（第 18 章） |
| 帧差 (Frame Difference) | 相邻帧相减，找出运动/变化区域（第 19 章） |
| 背景建模 (Background Modeling) | 学习静止背景，前景即运动目标（第 19 章） |
| 变化检测 (Change Detection) | 判断画面相对基准是否发生变化（第 19 章） |
| 人脸检测 (Face Detection) | 找出画面中人脸的位置框（第 20 章） |
| 人脸对齐 (Alignment) | 按关键点把人脸摆正，便于后续比对（第 20 章） |
| Embedding (人脸特征向量) | 把人脸编码成一串数字（如 512 维）用于比对（第 20 章） |
| 余弦相似度 (Cosine Similarity) | 用向量夹角衡量两个 Embedding 有多像（第 20 章） |
| 人脸库 (Gallery) | 已注册人脸 Embedding 的底库，用于 1:N 检索（第 20 章） |
| 活体检测 (Liveness) | 判断镜头前是真人还是照片/视频（第 20 章） |

## 跟踪与视频分析

| 术语 | 含义 |
|------|------|
| 多目标跟踪 (MOT) | 在视频里持续找出多个目标并保持各自身份（第 21 章） |
| 卡尔曼滤波 (Kalman Filter) | 用运动模型预测目标下一帧位置的经典估计器（第 21 章） |
| SORT | 卡尔曼滤波 + 匈牙利算法的轻量跟踪算法（第 21 章） |
| ByteTrack | 连低分框也利用起来的高性能跟踪算法（第 21 章） |
| 匈牙利算法 (Hungarian) | 求"检测 ↔ 轨迹"最优一对一匹配（第 21 章） |
| Track / ID | 一条轨迹及其唯一的身份编号（第 21 章） |
| ID switch | 同一目标身份被跟丢或串号的错误（第 21 章） |
| ROI（业务感兴趣区） | 业务上关心的多边形区域，只在其中触发事件（第 22 章） |
| Mask（掩膜） | 用 0/1 图标出可用区域与屏蔽区域（第 22 章） |
| 点在多边形 (Point-in-Polygon) | 判断一个点是否落在多边形内部（第 22 章） |
| 射线法 (Ray Casting) | 点在多边形的经典判定：数一条射线穿过多边形边的次数（第 22 章） |
| 静态过滤 | 滤掉长期不动、疑似误报的目标（第 22 章） |
| 绊线 (Tripwire) | 画一条线，目标越过即触发事件（第 23 章） |
| 单绊线 / 双绊线 | 一条线计一次 / 两条线判方向与先后顺序（第 23 章） |
| 叉积 (Cross Product) | 判断点在线的哪一侧、线段朝向（第 23 章） |
| 线段相交 (Segment Intersection) | 判断目标轨迹是否穿过了绊线（第 23 章） |
| Cooldown（冷却） | 同一目标一段时间内只报一次，防刷屏（第 24 章） |
| 时间窗 (Window) | 在一段时间内统计、聚合事件（第 24 章） |
| 去重 (Dedup) | 合并同一事件的重复上报（第 24 章） |
| N-of-M 确认 | M 帧里有 N 帧命中才确认，抑制抖动误报（第 24 章） |
| 脸人绑定 | 把人脸框与人体框/轨迹关联到同一个人（第 25 章） |
| 跨模型关联 (Cross-model Association) | 融合多个模型的输出到同一目标（第 25 章） |

## 工程

| 术语 | 含义 |
|------|------|
| 执行提供器 (EP, Execution Provider) | ONNX Runtime 里选 CPU/CUDA/TensorRT 等后端的插件（第 14、29 章） |
| warmup（预热） | 正式跑之前先做几次空推理，避免首帧因初始化而变慢（第 14、29 章） |
| 流水线并发 (Pipeline) | 解码/预处理/推理/后处理分阶段并行，提高吞吐（第 29 章） |
| 背压 / 丢帧 (Backpressure / Frame Drop) | 处理跟不上时主动丢弃旧帧，防止延迟越堆越高（第 29 章） |
| Golden 测试 | 固定输入并把结果与经确认的基准文件做容差比较（第 31 章） |
| 数据漂移 (Data Drift) | 线上输入分布随环境和时间变化，导致模型效果衰减（第 32 章） |
| Outbox | 先持久化业务事件，再由后台可靠投递并在确认后删除（第 32 章） |
| SLO | 服务等级目标，用可量化指标定义系统何时算健康（第 32 章） |
