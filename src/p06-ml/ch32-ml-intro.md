# 第 32 章 机器学习是怎么"学"的

> **本章导读**
> - 用大白话讲清楚：机器学习和"写死规则"到底差在哪，它凭什么能"举一反三"。
> - 建立一套贯穿后半本书的**核心词汇**：样本、特征、标签、模型、参数、损失函数、梯度下降、过拟合。
> - 亲手写一个**最小的梯度下降**，让你在终端里**亲眼看到 loss 一步步下降**——这就是"学"的过程。
> - 想通一件事：前几章辛辛苦苦算出的 HOG、LBP、颜色直方图，正是喂给机器学习模型的"口粮"。

## 场景：怎么教计算机认出一只猫

假设老板扔给你一个任务：写程序判断一张图里有没有猫。

**传统写死规则的思路**是：你亲自总结猫长什么样，然后翻译成 `if`。"猫有尖耳朵" → 检测三角形；"猫有胡须" → 找细长的白线；"猫有竖瞳" → ……你很快会崩溃：橘猫和黑猫颜色不同，趴着的猫和跳起来的猫形状不同，侧脸看不见两只耳朵……**世界的复杂程度，远超你能手写的 `if` 数量**。

再看看我们**是怎么教小孩认猫的**：我们从不给他讲"耳朵夹角小于 60 度"，只是指着一只只猫说"这是猫""这也是猫""那个是狗，不是猫"。看了几十上百个例子后，小孩自己就"悟"了——哪怕见到一只从没见过的品种，他也能认出来。

**机器学习（machine learning）走的正是第二条路**：不由人去写死规则，而是给机器**大量带答案的例子**，让它自己从例子里**找出规律**。这一章不写复杂算法，只把这套"从例子里学规律"的思想和词汇讲透——它是理解后面所有深度学习章节的地基。

> 📖 **术语**：**机器学习**。让计算机从数据中自动学习规律、而不是靠人手写规则的一类方法。一句话对比——传统编程是"人写规则 + 数据 → 答案"，机器学习是"数据 + 答案 → 机器自己总结出规则"。

## 三种学法：监督、无监督、强化

按"给机器的例子带不带答案"，机器学习分成三大类：

- **监督学习（supervised learning）**：每个例子都**带标准答案**。给一堆图，每张都标好"猫/狗"，让机器学"看到这样的图就答猫"。本书后面的分类、检测、回归，绝大多数是监督学习。
- **无监督学习（unsupervised learning）**：例子**不带答案**，让机器自己找结构。比如把一万张没标注的图**自动分成几堆**相似的（聚类），你事先都不知道该分几类。
- **强化学习（reinforcement learning）**：没有现成答案，机器靠**不断试错、拿奖励**来学（下棋、打游戏、机器人控制常用）。本书基本不涉及，知道有这么一类即可。

这一章的手写例子和下一章的**线性/逻辑回归**属于监督学习，**KMeans 聚类**属于无监督学习——下一章你会亲手把这三种都跑一遍。

## 一套必须记牢的词汇

机器学习的黑话其实就几个，用"根据身高体重猜性别"这个小例子一次讲清：

- **样本（sample）**：一条数据。这里"张三：身高 175、体重 68、男"就是一个样本。
- **特征（feature）**：描述样本的**输入**属性。这里的"身高""体重"就是两个特征。
- **特征向量（feature vector）**：把一个样本的所有特征排成一个数组，如 `[175, 68]`。**机器学习模型吃进去的永远是这样一串数字。**
- **标签（label）**：样本的**答案/输出**。这里的"男/女"。监督学习才有标签。
- **训练集 / 验证集 / 测试集**：把数据分三份。**训练集**给模型学；**验证集**在学的过程中帮你调参数、挑模型；**测试集**藏到最后，只用来**诚实地**估计模型在没见过的数据上表现如何。

> ⚠️ **注意**：**测试集是"高考题"，绝不能拿来训练或反复调参。** 一旦模型偷看过测试集，你算出来的准确率就是虚高的自欺欺人。工程上常见的分法是训练/验证/测试按 6:2:2 或 8:1:1 切开，**测试集只在最后碰一次**。

## 模型、参数、损失、梯度下降：一次讲透

有了词汇，"学"这件事就能说清楚了。

**模型（model）**是一个带**参数（parameter）**的函数，负责把特征向量映射成预测。最简单的模型就是一条直线 \\( y = kx + b \\)，其中 \\( k, b \\) 就是参数。**训练，就是不断调整参数，让模型的预测尽量贴近真实标签。**

那"贴不贴"怎么量化？靠**损失函数（loss function）**：它吃进"预测值"和"真实值"，吐出一个数——**预测越离谱，损失越大**。回归任务最常用**均方误差（MSE）**：

\\[ L(k, b) = \frac{1}{n} \sum_{i=1}^{n} (k x_i + b - y_i)^2 \\]

于是"学"就变成了一道优化题：**找到让 \\( L \\) 最小的参数**。怎么找？这就是**梯度下降（gradient descent）**登场的地方。

> 💡 **提示**：**下山类比。** 想象你蒙着眼站在山坡上（当前参数），想走到谷底（损失最小）。你能感觉到脚下哪个方向最陡（这就是**梯度**），于是朝**最陡的下坡方向**迈一小步，再感觉、再迈……只要步子别太大，早晚能摸到谷底。梯度下降就是这么个"摸着石头下山"的笨办法，却是几乎所有神经网络训练的核心。

数学上，"最陡上坡方向"就是损失对参数的**偏导数（梯度）**，我们朝它的**反方向**走：

\\[ \frac{\partial L}{\partial k} = \frac{2}{n} \sum_i (k x_i + b - y_i)\, x_i, \qquad \frac{\partial L}{\partial b} = \frac{2}{n} \sum_i (k x_i + b - y_i) \\]

\\[ k \leftarrow k - \eta\, \frac{\partial L}{\partial k}, \qquad b \leftarrow b - \eta\, \frac{\partial L}{\partial b} \\]

这里的 \\( \eta \\)（读作 eta）叫**学习率（learning rate）**，就是"每步迈多大"。太小则下山慢得让人着急，太大则可能一步迈过谷底、来回震荡甚至冲上天。下面的代码会让你对这几个式子有极其具体的手感。

## 动手写代码：让 loss 在你眼前下降

不用任何机器学习库，**只用标准库**，我们手写一遍梯度下降拟合直线。数据由 \\( y = 2x + 1 \\) 生成并加一丁点扰动，看模型能不能从"一无所知"（`k=b=0`）自己摸出 `k≈2, b≈1`。

这个例子不需要任何第三方依赖，`Cargo.toml` 的 `[dependencies]` 留空即可。完整代码（`examples/ch32_gradient_descent.rs`）：

```rust
fn main() {
    // 造数据：真实关系 y = 2x + 1，加一点点确定性的小扰动（模拟测量噪声）
    let n = 20usize;
    let xs: Vec<f64> = (0..n).map(|i| i as f64 * 0.1).collect();
    let ys: Vec<f64> = xs
        .iter()
        .enumerate()
        .map(|(i, &x)| 2.0 * x + 1.0 + if i % 2 == 0 { 0.05 } else { -0.05 })
        .collect();

    // 待学习的参数，故意从 0 开始（对答案一无所知）
    let mut k = 0.0f64;
    let mut b = 0.0f64;
    let lr = 0.1; // 学习率 η（每步迈多大）

    let nf = n as f64;
    for step in 0..=1000 {
        // 前向：算预测、累加损失和两个梯度
        let mut loss = 0.0;
        let mut grad_k = 0.0;
        let mut grad_b = 0.0;
        for (&x, &y) in xs.iter().zip(ys.iter()) {
            let pred = k * x + b;      // 模型预测
            let err = pred - y;        // 预测 - 真实
            loss += err * err;         // 平方误差累加
            grad_k += 2.0 * err * x;   // ∂L/∂k 的被加项
            grad_b += 2.0 * err;       // ∂L/∂b 的被加项
        }
        loss /= nf;
        grad_k /= nf;
        grad_b /= nf;

        // 沿梯度的反方向"下山"一步
        k -= lr * grad_k;
        b -= lr * grad_b;

        if step % 100 == 0 {
            println!("第 {:>4} 步: loss = {:.6}, k = {:.4}, b = {:.4}", step, loss, k, b);
        }
    }
    println!("\n真实: k=2.0, b=1.0");
    println!("学到: k={:.4}, b={:.4}", k, b);
}
```

运行 `cargo run --example ch32_gradient_descent`，终端打印（数字可复现）：

```text
第    0 步: loss = 9.732500, k = 0.6835, b = 0.5800
第  100 步: loss = 0.002557, k = 1.9785, b = 1.0229
第  200 步: loss = 0.002481, k = 1.9919, b = 1.0077
第  300 步: loss = 0.002481, k = 1.9925, b = 1.0072
第  500 步: loss = 0.002481, k = 1.9925, b = 1.0071
第 1000 步: loss = 0.002481, k = 1.9925, b = 1.0071

真实: k=2.0, b=1.0
学到: k=1.9925, b=1.0071
```

盯着这几行看，"学"的过程一目了然：

1. **loss 从 `9.73` 一路狂降到 `0.0025`**——模型从"瞎猜"变得越来越准，这就是学习在发生。
2. **参数从 `(0, 0)` 自己爬到了 `(1.99, 1.01)`**，几乎完美还原了真实的 `k=2, b=1`。我们从没告诉它答案，它是从 20 个例子里**自己算出来的**。
3. **loss 最后停在 `0.002481` 不再降**，不是没学好，而是我们故意加的 `±0.05` 扰动本身就贡献了约 \\( 0.05^2 = 0.0025 \\) 的误差下限——**数据里的噪声，模型再牛也消不掉**。这也预告了下一个概念：过拟合。

## 过拟合 vs 欠拟合：背题 vs 举一反三

学习最怕两种毛病，用"备考"来类比最贴切：

- **欠拟合（underfitting）**：模型太笨或没学够，连训练集都学不好——好比书没看完就上考场，平时和考试都考砸。表现是**训练误差和测试误差都高**。
- **过拟合（overfitting）**：模型太"轴"，把训练集**死记硬背**下来（连噪声都背了），却没学到真正的规律——好比只会背原题，题目一变就懵。表现是**训练误差极低、测试误差却高**。

我们真正想要的是**举一反三**（术语叫**泛化 generalization**）：在没见过的数据上也表现好。这正是前面为什么要留一份**测试集**——它就是那套"没见过的新题"，专门用来戳穿"死记硬背"的假象。后面章节会讲对付过拟合的常规武器：加更多数据、正则化、早停、Dropout……现在记住这个直觉就够了。

## 机器视觉的"特征"从哪来

你可能已经在犯嘀咕：上面拟合直线用的是现成的数字，可**图像**该怎么喂给模型？总不能把百万像素直接拍进去吧。

这正是本书前几部分的伏笔在此收网。**传统机器视觉的套路是：先用手工方法把图像压成一个定长特征向量，再把这个向量喂给机器学习模型。** 比如：

- 用 [第 27 章](../p04-features/ch27-handcrafted-features.md) 的 **HOG** 把一张 `64×128` 的行人图变成 `3780` 维向量（抓形状）；
- 用同章的 **LBP** 直方图描述纹理；
- 用 [第 12 章](../p02-image-basics/ch12-histogram.md) 的**颜色直方图**描述整体色彩分布。

这些向量就是模型的"特征向量"，训练时配上"是行人/不是行人"这样的标签，模型便能学会"看到这种向量就判为行人"。**手工特征负责'把图变成数字'，机器学习负责'从数字里学规律'**——两者接力，构成了深度学习普及前视觉识别的主流范式。而深度学习的革命性，恰恰在于把"设计特征"这一步也交给机器自己去学（第七部分再展开）。

## 常见坑与提示

> 🕳️ **坑**：**学习率是头号大坑。** 把上面代码的 `lr` 改成 `2.0` 再跑，你会看到 loss 不降反升、参数飙成 `NaN`——步子迈太大，直接冲出山谷。学习率太小又会慢到你怀疑人生。它没有万能值，需要试（常从 `0.1`、`0.01`、`0.001` 这些量级里挑）。

> ⚠️ **注意**：**特征的量纲差异会拖垮梯度下降。** 例子里我特意让 `x` 落在 `[0, 2]` 这种小范围。如果一个特征是"身高 175"、另一个是"收入 50000"，两者尺度悬殊，梯度下降会走得歪歪扭扭。实战中通常先做**归一化/标准化**（把各特征缩放到相近范围），这是下一章和后面反复要用的预处理。

> 💡 **提示**：**别把机器学习神化。** 它不是"通灵"，本质就是本章这套"定义损失 → 求梯度 → 迭代下山"的数值优化，外加海量数据和算力。理解了最小例子里发生的事，再复杂的模型也只是"更多参数、更花哨的函数、更聪明的下山策略"而已。

## 本章小结

- **机器学习**不靠人写死规则，而是从**带答案的例子**里自动找规律，解决了"世界太复杂、`if` 写不完"的困境。
- 按例子带不带答案分为**监督、无监督、（强化）** 三类；核心词汇是样本、**特征**、**标签**、特征向量、训练/验证/**测试**集。
- **训练 = 调参数让损失最小**；**损失函数**度量预测有多离谱，**梯度下降**像"摸着石头下山"一样反复朝下坡方向迈小步，**学习率**控制步长。手写例子里我们亲眼看到 loss 从 `9.73` 降到 `0.0025`、参数自己逼近真值。
- **过拟合是死记硬背、欠拟合是没学够**，我们要的是能**举一反三（泛化）**，测试集就是检验它的"新题"。
- 机器视觉里，模型的输入特征来自 **HOG / LBP / 颜色直方图**等手工特征——手工特征把图变数字，机器学习从数字学规律。

## 动手练习

1. **调学习率**：把 `lr` 依次设成 `0.01`、`0.5`、`2.0`，观察 loss 曲线分别是"下降太慢""快速收敛""发散成 NaN"。体会学习率的脾气。
2. **改真实关系**：把数据换成 \\( y = -3x + 5 \\)，其它不动，看梯度下降能不能照样把 `k、b` 学出来。
3. **加大噪声**：把扰动从 `±0.05` 放大到 `±0.5`，观察最终 loss 的"地板"是不是随之抬高——直观感受"数据噪声决定误差下限"。
4. **进阶**：把损失改成打印**每一步**的值并存进 `Vec`，用 [第 12 章](../p02-image-basics/ch12-histogram.md) 学过的思路把 loss 曲线画成一张 ASCII 折线图，看它"下山"的形状。
