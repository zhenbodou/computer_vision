## 场景引入：从"一张全是数字的网格"到"三个干净的框"

你在 [第 1 章](../p01-start/ch01-what-is-cv.md) 见过目标检测的样子：一张街景，行人、车辆各被一个方框圈住，框上标着"person 0.94"。但神经网络本身**不会画框**——它吐出来的是一大堆数字：一张被切成网格的图，每个格子都预测"我这儿可能有个目标，中心偏这边一点、大概这么大、我有八成把握"。

于是就有了检测的"后半程"三步：

1. **解码（decode）**：把每个格子那几个原始数字，还原成图像坐标系里一个具体的框；
2. **抑制（NMS）**：同一个目标常被相邻好几个格子同时预测出来，得把重复的框收拢成一个；
3. **评估（后续章节）**：剩下的框到底准不准，要用 IoU 去和真值比对。

这三步的公共货币，就是一个衡量"两个框有多像"的数字——**IoU**。我们从它讲起。

## 框怎么表示：xyxy / xywh / cxcywh

同一个框，业界有三种常见写法，各有各的用武之地：

| 表示法 | 含义 | 最适合 |
|--------|------|--------|
| **xyxy** | 左上角 + 右下角 \\( (x_1,y_1,x_2,y_2) \\) | 算 IoU、裁剪 |
| **xywh** | 左上角 + 宽高 \\( (x,y,w,h) \\) | 画框、COCO 标注存储 |
| **cxcywh** | 中心 + 宽高 \\( (c_x,c_y,w,h) \\) | 检测器**回归** |

为什么检测器偏爱 **cxcywh**？因为让网络直接猜"左上角在图像哪个绝对像素"太难了，而猜"目标中心相对我这个格子偏了多少"要容易得多——偏移量是个小范围的相对量，好学、好收敛。三种表示之间的互转是纯代数，务必让往返转换**无损**（转过去再转回来必须和原始一模一样），这是后面一切坐标操作可信的前提。

> 📖 **术语**：**GT（Ground Truth，真值）**——人工标注的"标准答案"框。检测器输出的框叫**预测框（prediction）**。训练是让预测框逼近 GT，评估是拿预测框和 GT 算分。

## IoU：两个框有多"像"

**IoU（Intersection over Union，交并比）** 用一个 \\( [0,1] \\) 的数回答"两个框重叠得有多好"：交集面积除以并集面积。

```text
   ┌───────────┐
   │ A         │
   │     ┌─────┼─────┐      交集 = 两框重叠的那块
   │     │▓▓▓▓▓│     │      并集 = A + B − 交集
   └─────┼─────┘     │      IoU = 交集 / 并集
         │         B │
         └───────────┘
```

先算交集矩形的宽和高（没有重叠时取 0）：

\\[ w_I = \max(0,\ \min(x_2^a, x_2^b) - \max(x_1^a, x_1^b)) \\]

高度 \\( h_I \\) 同理。于是

\\[ \text{IoU} = \frac{A_I}{A_a + A_b - A_I},\quad A_I = w_I \cdot h_I \\]

几个直觉标尺（本章代码实测）：两个 100×100 的框**完全重合** IoU=1.0；**沿一个方向平移一半** IoU=0.3333；一个 50×50 的框**内含**在 100×100 里 IoU=0.25；**完全不沾** IoU=0。记住 **IoU=0.5 是检测里最常用的"算不算命中"分界线**。

> ⚠️ **注意**：坐标用**半开区间** `[x1, x2)` 理解——宽就是 `x2 - x1`，不要在整数像素上随手 `+1`。训练、解码、评估三处对宽高的定义必须一致，否则会埋下"训练和评估悄悄差一像素"的坑。

## 网格 + anchor：单阶段检测器怎么"解码"出框

单阶段检测器（YOLO 是代表）把输入图（比如 128×128）按 **stride（步长）** 切成网格。stride=32 就切成 4×4=16 个格子，每格"负责"原图 32×32 的一片区域。每个格子预测一组原始数字 \\( (t_x, t_y, t_w, t_h, t_{obj}) \\)，外加各类别的分数。

**anchor（锚框）** 是预设的"参考尺寸"——网络不从零猜宽高，而是猜"相对某个预设框缩放多少"。解码就是把原始数字还原成绝对坐标框：

\\[ c_x = (\sigma(t_x) + \text{col}) \cdot s,\quad c_y = (\sigma(t_y) + \text{row}) \cdot s \\]

\\[ w = a_w\ e^{t_w},\quad h = a_h\ e^{t_h},\quad \text{conf} = \sigma(t_{obj}) \\]

这里 \\( \sigma \\) 是 sigmoid 函数 \\( \sigma(x)=1/(1+e^{-x}) \\)，把任意实数压到 \\( (0,1) \\)。`col/row` 是格子的列/行号。读一遍公式就明白设计巧思：

- \\( \sigma(t_x) \in (0,1) \\)，加上格子列号再乘 stride，**中心被牢牢锁在本格内**，不会乱飘；
- 宽高用 \\( e^{t_w} \\) 保证**恒为正**，且以 anchor 为基准做乘性缩放，\\( t_w=0 \\) 就正好是 anchor 原尺寸；
- objectness（有无目标的置信度）过 sigmoid 变成 \\( (0,1) \\) 的概率，低于阈值的格子直接丢弃——这就完成了从"16 格密集预测"到"少数候选框"的第一次瘦身。

## NMS：把一堆重复框收拢成几个

解码后有个恼人的现实：**同一个目标，往往被相邻好几个格子同时预测出来**，于是你得到一簇高度重叠、都挺自信的框。**NMS（Non-Maximum Suppression，非极大值抑制）** 就是来收拾它们的，逻辑朴素得像"排队占座"：

```text
① 把所有框按 score 从高到低排队
② 取出当前最高分的框，保留它（它"占座"成功）
③ 把队列里剩下的、与它 IoU 超过阈值的框全部划掉（同一个目标的重复框）
④ 回到 ②，直到队列空
```

阈值（常用 0.5）越小抑制越狠。它有几个必须钉死的工程细节：**按类还是跨类**抑制、相同分数时的**稳定排序**、以及对 NaN 和零面积框的处理。

> 💡 **提示**：暴力删除重复框有时会误伤——两个真实目标本来就挨得很近（比如并排的两个人），会被 NMS 当重复框抹掉一个。**Soft-NMS** 的改良是：不直接删，而是按重叠程度**给它降分**，让它还有机会活下来。此外还有 DIoU-NMS、Weighted Boxes Fusion 等变体，适用场景不同，不能只因名字新就无脑替换。

## 动手写代码：IoU、解码、NMS 一条龙

下面这个例子**只用 std**，合成检测框，不需要任何模型或图片，`cargo run` 一键复现。先是三种框表示、互转与 IoU：

```rust
/// xyxy：左上 + 右下，最适合算 IoU
#[derive(Clone, Copy)]
struct Xyxy { x1: f32, y1: f32, x2: f32, y2: f32 }
/// cxcywh：中心 + 宽高，检测器回归最常用
#[derive(Clone, Copy)]
struct Cxcywh { cx: f32, cy: f32, w: f32, h: f32 }

impl Xyxy {
    fn area(self) -> f32 {
        (self.x2 - self.x1).max(0.0) * (self.y2 - self.y1).max(0.0)
    }
    /// 交并比 IoU ∈ [0,1]
    fn iou(self, o: Xyxy) -> f32 {
        let ix1 = self.x1.max(o.x1); let iy1 = self.y1.max(o.y1);
        let ix2 = self.x2.min(o.x2); let iy2 = self.y2.min(o.y2);
        let iw = (ix2 - ix1).max(0.0); // 无交集时取 0
        let ih = (iy2 - iy1).max(0.0);
        let inter = iw * ih;
        let uni = self.area() + o.area() - inter;
        if uni <= 0.0 { 0.0 } else { inter / uni }
    }
}
impl Cxcywh {
    fn to_xyxy(self) -> Xyxy {
        Xyxy { x1: self.cx - self.w/2.0, y1: self.cy - self.h/2.0,
               x2: self.cx + self.w/2.0, y2: self.cy + self.h/2.0 }
    }
}
```

网格解码：把一份合成的"原始网格输出"还原成绝对坐标框，低置信格子直接丢弃：

```rust
fn sigmoid(x: f32) -> f32 { 1.0 / (1.0 + (-x).exp()) }

struct RawCell { tx: f32, ty: f32, tw: f32, th: f32, obj: f32 }

/// 网格解码：每格 raw 输出 → 绝对坐标框 + 置信度
fn decode_grid(grid: &[Vec<RawCell>], stride: f32, anchor: (f32, f32),
               conf_thresh: f32) -> Vec<(Xyxy, f32)> {
    let (aw, ah) = anchor;
    let mut out = Vec::new();
    for (row, line) in grid.iter().enumerate() {
        for (col, c) in line.iter().enumerate() {
            let score = sigmoid(c.obj);
            if score < conf_thresh { continue; } // 低置信格子丢弃
            let cx = (sigmoid(c.tx) + col as f32) * stride; // 中心锁在本格内
            let cy = (sigmoid(c.ty) + row as f32) * stride;
            let w = aw * c.tw.exp(); // 宽高以 anchor 为基准做乘性缩放
            let h = ah * c.th.exp();
            out.push((Cxcywh { cx, cy, w, h }.to_xyxy(), score));
        }
    }
    out
}
```

贪心 NMS：

```rust
/// 按分数降序，保留最高分框，抑制与它 IoU 超阈值的其余框
fn nms(mut boxes: Vec<(Xyxy, f32)>, iou_thresh: f32) -> Vec<(Xyxy, f32)> {
    boxes.sort_by(|a, b| b.1.partial_cmp(&a.1).unwrap()); // 分数高的先占座
    let n = boxes.len();
    let mut suppressed = vec![false; n];
    let mut keep = Vec::new();
    for i in 0..n {
        if suppressed[i] { continue; }
        keep.push(boxes[i]);
        for j in (i + 1)..n {
            if !suppressed[j] && boxes[i].0.iou(boxes[j].0) > iou_thresh {
                suppressed[j] = true; // 重叠过多 → 抑制
            }
        }
    }
    keep
}
```

完整代码（含合成数据、损失数值示例）在 `code/examples/ch45_detection_principles.rs`，运行：

```bash
cargo run --example ch45_detection_principles
```

真实输出（数字可复现）：

```text

  完全重合: IoU = 1.0000
  平移一半 : IoU = 0.3333
  小框内含 : IoU = 0.2500
  完全不沾 : IoU = 0.0000

== ③ 网格 + anchor 解码（4x4 网格, stride=32, 模型输入 128x128）==
网格共 16 格，过 conf>0.5 阈值后解出 2 个候选框：
  框 [x1=23.0,y1=23.0,x2=73.0,y2=73.0]  中心(48.0,48.0) 宽高(50.0,50.0)  conf=0.900
  框 [x1=83.8,y1=55.8,x2=144.9,y2=101.0]  中心(114.4,78.4) 宽高(61.1,45.2)  conf=0.858

== ④ 贪心 NMS 非极大值抑制 ==
抑制前共 12 个框（同目标框对示例 IoU=0.895）
NMS(IoU>0.5) 后剩 3 个框：
  保留框 中心(61.2,59.4) 宽高(56.4,56.8)  score=0.916
  保留框 中心(111.0,182.9) 宽高(47.0,71.4)  score=0.788
  保留框 中心(184.9,79.6) 宽高(59.0,50.5)  score=0.759
```

三个结论对上了原理：① IoU 的四个标尺数字正是我们预判的 1.0 / 0.3333 / 0.25 / 0；② 16 个格子里只有 2 个 objectness 过阈值，被解码成中心 (48,48)、(114.4,78.4) 的两个框，宽高也随 \\( e^{t_w} \\) 精确缩放（50→61.1）；③ **12 个重叠框，NMS 后干净地剩 3 个**——正好对应合成时埋的 3 个目标，每个目标那一簇里只留下了分数最高的代表（0.916 / 0.788 / 0.759）。

## 正负样本匹配与损失：训练时"谁负责谁"

推理是解码 + NMS，那训练呢？核心问题是**匹配（assignment）**：成千上万个 anchor / 网格位置里，**谁该为这个 GT 负责**？规则通常是——某个 anchor 与某个 GT 的 IoU 足够高，就把它判为该 GT 的**正样本**，让它去学这个 GT 的类别和位置；离所有 GT 都远的判为**负样本**（背景）；不上不下的常设为**忽略**，不参与损失。anchor-free 方法（如按中心点、按距离）换了匹配方式，但"谁负责谁"这个灵魂问题一样要回答清楚。

匹配好后，检测的总损失一般是三项加权和：

\\[ L = \lambda_{cls} L_{cls} + \lambda_{obj} L_{obj} + \lambda_{box} L_{box} \\]

- **分类损失 \\( L_{cls} \\)**：判类别。多标签常用 **BCE（二元交叉熵）**，单选一类常用 **CE（交叉熵）**。BCE 对一个正样本是 \\( L=-\log p \\)（\\( p \\) 是预测概率）。
- **objectness \\( L_{obj} \\)**：判"这儿到底有没有目标"，也常用 BCE。
- **定位损失 \\( L_{box} \\)**：让框更准。**L1 / smooth-L1** 直接惩罚坐标误差；**IoU 系（GIoU/DIoU/CIoU）** 直接优化 \\( 1-\text{IoU} \\)，与最终指标更一致，但在两框无交集时梯度行为要特别处理。

本章代码对"一个匹配上的正样本"算了一次真实损失：objectness logit=1.5 → \\( p=\sigma(1.5)=0.8176 \\)，BCE=0.2014；预测框与 GT 的 L1 误差 12.0 px；两者 IoU=0.8708 → IoU loss=0.1292；取 \\( \lambda_{obj}=1, \lambda_{box}=5 \\) 得加权总损失 0.8473。这些数字本身不重要，重要的是你看清了损失是**怎么由匹配结果一项项拼出来的**。

> ⚠️ **注意**：各损失项的**数值大小 ≠ 梯度贡献**。调 \\( \lambda \\) 权重时，光看 loss 谁大谁小会被误导，应记录各项的**梯度范数**和**分任务指标**（分类准不准、框紧不紧）再判断。

## mAP：检测好不好，一个数说了算？（引子）

检测器最终要用一个数来打分——**mAP（mean Average Precision，平均精度均值）**。它的直觉是：把预测框按置信度排序，逐个和 GT 用 IoU 匹配，画出 **precision-recall 曲线**，曲线下面积就是 AP，多类取平均就是 mAP。你会常听到 **mAP@0.5**（IoU≥0.5 算命中）和更严格的 **mAP@[.5:.95]**。

这套评估体系细节不少（一对一匹配、11 点插值 vs 全点积分、置信区间……），我们放到 [第 48 章](ch48-metrics-annotation.md) 用一整章手写实现。这里你只需记住：**IoU 不仅在推理时用于 NMS，更是评估时判定"命中"的唯一标尺**——所以本章把它吃透，绝对值。

## 常见坑与提示

> 🕳️ **坑**：**解码必须精确逆转训练时的每一步变换。** 网格坐标、stride、anchor、sigmoid/exp 参数化，一步都不能错；如果推理前还做了 letterbox（保持长宽比的缩放 + 补边），解码回原图时那个 scale 和两侧 padding 也要原样逆回去。**过早取整**会把小目标的框搞歪。完整的坐标往返在 [第 46 章](ch46-yolo-inference.md) 细讲。

> ⚠️ **注意**：**NMS 是"按类"还是"跨类"要想清楚。** 按类：每个类别内部各自抑制，允许"人"和"车"的框重叠（正常，它们本就可能重叠）。跨类：不分类别一起抑制，适合"一个位置只该有一个目标"的场景。选错会要么漏掉正常的重叠目标，要么留下一堆语义重复框。

> 🕳️ **坑**：**IoU 类损失遇到"两框完全无交集"会退化。** 此时 IoU 恒为 0、梯度消失，框永远学不动。这正是 GIoU/DIoU 等改进要解决的——它们额外引入"最小闭包框"或"中心距离"项，让无交集时也有下降方向。选定位损失前，务必先在纸上画一遍**退化情形**。

> 💡 **提示**：**先分诊，再优化。** 检测系统的性能瓶颈可能来自召回（漏检）、定位（框不准）、分类（认错类）或后处理（NMS 删多了）。把错误按这四类分桶统计，才知道该修哪儿——盲目换更大的模型常常是浪费。

## 本章小结

- 检测的"后半程"是**解码 → NMS → 评估**，三者的公共货币是 **IoU**。
- 框有 **xyxy / xywh / cxcywh** 三种表示，检测器回归偏爱中心宽高（cxcywh），互转必须无损。
- **IoU** = 交集 / 并集；IoU=0.5 是最常用的"命中"分界线，本章实测了 1.0 / 0.3333 / 0.25 / 0 四个标尺。
- 单阶段检测器把图切**网格**，每格基于 **anchor** 预测偏移，解码公式用 sigmoid 锁中心、用 exp 缩宽高；本章 16 格解出 2 个候选框。
- **贪心 NMS** 按分数排序、抑制高 IoU 重复框；本章 12 个重叠框被收拢成 3 个。Soft-NMS 是"降分不删"的温柔改良。
- 训练靠 **IoU 匹配** 决定"谁负责谁"，总损失 = 分类(BCE/CE) + objectness + 定位(L1/IoU) 的加权和。
- **mAP** 是检测的总评分，细节见 [第 48 章](ch48-metrics-annotation.md)。

## 动手练习

1. **调 NMS 阈值**：把 `nms` 的 IoU 阈值从 0.5 改成 0.3 和 0.7，观察最终保留框数怎么变。想想为什么阈值越小、留下的框越少。
2. **加一个目标**：在合成重叠框里再埋第 4 个目标（一簇新的重叠框），确认 NMS 后正好剩 4 个。
3. **写性质测试**：给 `iou` 写单元测试，覆盖对称性（`a.iou(b)==b.iou(a)`）、同框（=1）、无交集（=0）、退化框（宽或高为 0）。这是专家级实现的标配。
4. **进阶——letterbox 逆变换**：假设原图 640×480 被 letterbox 到 128×128，手推 scale 和上下/左右 padding，再把本章解码出的框逆映射回原图坐标。（对答案见 [第 46 章](ch46-yolo-inference.md)）
