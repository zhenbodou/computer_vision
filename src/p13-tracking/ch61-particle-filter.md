# 第 61 章 粒子滤波：非线性、多峰与退化

> **本章导读**
> - 用"一大群假设"的直觉讲透**粒子滤波（Particle Filter, PF）**：为什么它能对付**非线性、非高斯**，而卡尔曼不行。
> - 走一遍三步循环：**预测（扩散粒子）→ 更新（按观测似然赋权）→ 重采样（systematic resampling）**。
> - 认识粒子滤波的两大死穴：**粒子退化**与有效粒子数 \(N_{eff}\)、以及**多峰后验下"均值失效"**。
> - 动手：用固定种子实现 2D 粒子滤波，跟踪一个非线性观测下的合成目标，实测**误差从 60 像素收敛到个位数**。

## 场景引入：当卡尔曼的假设塌了

上一章的卡尔曼滤波很美，但它有个前提：运动和观测都得是**线性 + 高斯**的。现实常常不给面子——

- 传感器只测得到目标的**距离和角度**（雷达、声呐、单目测角），而 \(\text{距离} = \sqrt{x^2 + y^2}\) 是**非线性**的；
- 检测偶尔冒出**离群点**、光照突变让误差**不再是高斯**；
- 目标可能同时有**两种可能位置**（后验是"多峰"的），一个高斯分布根本描述不了。

卡尔曼那套"用一个高斯（均值 + 协方差）表示不确定度"就崩了。粒子滤波换了个彻底的思路：**我不假设分布长什么样，我用一大堆样本点（粒子）去把它'画'出来。**

## 原理：用一群粒子近似后验

### 直觉：撒一把假设，让观测来投票

想象你在找一个信号源，但只知道"它离我大约 50 米"。你没法用一个点表示它的位置——它可能在以你为圆心、半径 50 米的**整个圆弧上**。粒子滤波的做法是：**先撒几千个"猜测点"（粒子），每个粒子就是一个完整的状态假设**；然后每来一次观测，就看每个粒子"有多符合观测"，符合的给高权重、不符合的给低权重；权重高的假设留下、繁衍，权重低的被淘汰。一轮轮下来，粒子群就自动聚拢到真相附近。

这套"用带权样本近似概率分布"的思想叫**序贯重要性重采样（Sequential Importance Resampling, SIR）**。它对分布的形状**零假设**——非线性、非高斯、多峰，统统能表示。

### 三步循环

设有 \(N\) 个粒子，每个带一个状态和一个权重 \(w_i\)。每来一帧观测 \(z\)：

1. **预测（predict）**：让每个粒子按运动模型往前走一步，并注入**过程噪声**（随机扰动）——这一步在"扩散"粒子群，覆盖目标可能去的地方。
2. **更新（update）**：算每个粒子的观测似然 \(p(z \mid \text{粒子}_i)\)，乘到权重上：\(w_i \leftarrow w_i \cdot p(z \mid \text{粒子}_i)\)，再归一化。像观测的粒子权重涨、不像的权重跌。
3. **重采样（resample）**：按权重**有放回地抽样** \(N\) 个粒子——权重大的被复制多份，权重小的被淘汰，抽完权重重置为均匀。

目标位置的估计，就是所有粒子的**加权平均**。

### 粒子退化与有效粒子数

不重采样会出大问题：几轮之后，**几乎所有权重都集中到极少数粒子上**，其余几千个粒子权重趋近 0——它们还在算，却对结果毫无贡献。这叫**粒子退化（degeneracy）**。衡量它的指标是**有效粒子数**：

\[ N_{eff} = \frac{1}{\sum_{i=1}^{N} w_i^2} \]

全都均匀时 \(N_{eff} = N\)（最健康）；退化到只剩一个有效粒子时 \(N_{eff} \to 1\)。工程上的标准做法是：**只在 \(N_{eff}\) 掉到某个阈值（如 \(N/2\)）以下时才重采样**——既抗退化，又避免"每帧都重采样"导致的另一个毛病：**样本贫化（sample impoverishment）**，即粒子被反复复制、多样性耗尽。

### systematic resampling：一根梳子扫过去

最常用、方差最低、又好实现的重采样叫 **systematic resampling**：把所有粒子权重首尾相接铺成 \([0, 1)\) 区间，再拿一根有 \(N\) 个**等间隔齿**、起点随机落在 \([0, 1/N)\) 的"梳子"扫过去，每个齿落在谁的区间里，就复制谁：

```text
 权重区间(宽度∝权重):
   |--p1--|------p2------|-p3-|---------p4---------|-p5-|
   0     .12            .45  .53                 .93   1.0
 梳子(N个等间隔齿, 起点随机):
   ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑     ↑
 落到:  p1    p2    p2    p2    p4    p4    p4    p4    p5
         -> p2、p4 各被复制多份，p3、p5 被淘汰，p1 保 1 份
```

## 动手写代码

完整示例在 `code/examples/ch61_particle_filter.rs`，核心只用 `std` + 一个自带的固定种子伪随机数发生器（保证可复现），image 只用来存可视化 PNG。运行：

```bash
cargo run --example ch61_particle_filter
```

我们跟踪一个做"匀速 + 缓慢转弯"的目标，观测是**非线性**的"距离 + 方位角"（从原点传感器看目标），并加较大高斯噪声。几个工程要点值得强调：

**① 用对数权重 + log-sum-exp 归一化，避免数值下溢。** 观测似然是 \(\exp(-\text{很大的数})\)，直接连乘会迅速下溢到 0。正确做法是全程在**对数域**累加对数似然，最后用 log-sum-exp 稳定地归一化：

```rust
// 更新：把观测对数似然【累加】到对数权重上（不 exp，避免下溢）
for p in ps.iter_mut() {
    let (r, b) = observe(p.x, p.y);          // 非线性观测：距离 + 方位角
    let dr = r - z.0;
    let db = wrap(b - z.1);                   // 角度差归一化到 [-pi, pi]
    p.lw += -0.5 * (dr * dr / (sig_r * sig_r) + db * db / (sig_b * sig_b));
}
// log-sum-exp 归一化得到线性权重 w（数值稳定）
let lws: Vec<f64> = ps.iter().map(|p| p.lw).collect();
let lse = log_sum_exp(&lws);
let w: Vec<f64> = lws.iter().map(|&v| (v - lse).exp()).collect();
```

**② systematic resampling，且只在 \(N_{eff} < N/2\) 时触发**：

```rust
let neff = 1.0 / w.iter().map(|wi| wi * wi).sum::<f64>();
if resample && neff < n as f64 / 2.0 {
    ps = systematic_resample(&ps, &w, &mut rng);  // 见下
}
```

```rust
fn systematic_resample(ps: &[Particle], w: &[f64], rng: &mut Rng) -> Vec<Particle> {
    let n = ps.len();
    let mut cum = vec![0.0; n];                 // 累积权重
    let mut acc = 0.0;
    for i in 0..n { acc += w[i]; cum[i] = acc; }
    let start = rng.uniform() / n as f64;        // 梳子第一个齿落在 [0, 1/N)
    let (mut out, mut j) = (Vec::with_capacity(n), 0usize);
    for i in 0..n {
        let u = start + i as f64 / n as f64;
        while j < n - 1 && u > cum[j] { j += 1; }
        let mut np = ps[j];
        np.lw = 0.0;                             // 重采样后权重重置为均匀
        out.push(np);
    }
    out
}
```

**③ 同时输出加权均值和 MAP（最大权重粒子）**——这是为多峰情况埋的伏笔（见下方"坑"）。初始时我们故意把 3000 个粒子撒在一个**又宽又偏**的先验里（中心离真值约 60 像素），看它能否被多帧观测"拉"回来。

### 实测输出

```text
初始先验中心距真值约 60 px（撒得又宽又偏，还没用上任何观测）
== 2D 粒子滤波（3000 个粒子，非线性"距离+方位"观测）==
 步   估计(x,y)         真值(x,y)        位置误差   N_eff   重采样?
  0  (  47.2,  22.1)  (  55.0,  25.0)     8.30       36   是
  2  (  50.9,  33.0)  (  55.6,  31.4)     5.00      509   是
  5  (  60.9,  39.5)  (  55.6,  41.2)     5.57     1654   否
 10  (  55.8,  58.2)  (  52.9,  57.1)     3.08     2051   否
 20  (  38.1,  82.6)  (  38.5,  85.9)     3.32     1588   否
 29  (   9.7, 101.4)  (  16.8, 105.1)     8.02     1970   否

收敛过程：先验中心 ~60 px --首帧观测--> 第0步 8.3 px --多帧--> 末10步平均 6.0 px（稳稳跟住真值）
同一次运行，MAP 估计末 10 步平均误差 = 9.4 px
对照【从不重采样】：末 N_eff = 1.0（几乎只剩 1 个有效粒子，严重退化），末 10 步平均误差 = 24.3 px
```

三组数字把粒子滤波讲透了：

- **收敛**：还没用观测时，先验中心离真值约 **60 像素**；第一帧观测一到，估计误差骤降到 **8.3 像素**；多帧之后稳定在 **6 像素**左右——非线性观测下照样收敛得漂漂亮亮，这是卡尔曼直接做不到的。
- **重采样的威力**：开着重采样，末段平均误差 **6.0 像素**；**关掉重采样，同样的数据末段误差飙到 24.3 像素**，而且最终 \(N_{eff}\) 塌到 **1.0**——三千个粒子只剩一个还"活着"，教科书般的退化。
- **N_eff 的节律**：第 0 步 \(N_{eff}\) 只有 36（宽先验下权重极不均），触发重采样；之后回升到一两千，健康地维持着。

## 常见坑与提示

> 🕳️ **坑：多峰后验时，别再用加权均值！** 如果后验有两个峰（比如目标可能在左也可能在右），加权均值会落在**两峰正中间**——那往往是个**根本不可能的位置**（两条路中间的墙里）。这时应改用 **MAP（最大权重粒子）**、或对粒子做聚类后输出各个峰、或干脆输出整片不确定度。本章示例是单峰，所以 MAP（9.4 px）比均值（6.0 px）略差——**单峰下均值才是最优的**；但一旦多峰，均值就会给出灾难性的答案。

> ⚠️ **注意：似然的"尖锐度"要配好。** 观测噪声 \(\sigma\) 设得过小 → 似然太尖 → 只有一两个粒子拿到几乎全部权重 → 一帧就坍缩、退化；设得过大 → 似然太平 → 所有粒子权重差不多 → 根本定位不了。示例里 \(\sigma_r = 6, \sigma_b = 0.12\) 是调出来的平衡点。

> 💡 **提示：粒子数是精度与算力的权衡。** 粒子越多，对分布的近似越准、越不容易跟丢，但计算量线性增长。低维问题几百到几千个够用；状态维度一高，所需粒子数会**指数爆炸**（维度灾难）——这也是纯粒子滤波很少用于高维问题的原因。先用够小的数跑通，再按需要加。

> ⚠️ **注意：重要性分布的选择。** 本章用"运动模型"当提议分布（predict 一步就是从它采样），实现最简单，但当观测很"信息量大"而运动模型很粗时，会浪费大量粒子。进阶做法是把当前观测也纳入提议分布（如 EKF/UKF 提议），让粒子更"聪明"地撒。

## 本章小结

- 粒子滤波用**一大群带权粒子**近似后验分布，对**非线性、非高斯、多峰**零假设——这正是它相对卡尔曼的核心优势。
- 三步循环：**预测（扩散）→ 更新（按似然赋权）→ 重采样**；估计取粒子的加权平均（多峰时改用 MAP/聚类）。
- **粒子退化**用 \(N_{eff} = 1/\sum w_i^2\) 度量，只在 \(N_{eff} < N/2\) 时做 **systematic resampling**，兼顾抗退化与防样本贫化。
- 实测：非线性观测下，估计误差从先验的 60 px 收敛到 6 px；关掉重采样则退化到 24.3 px、\(N_{eff}\) 塌到 1.0。
- 工程加固：对数权重 + log-sum-exp 防下溢、似然尖锐度要调、多峰别用均值、粒子数按维度权衡。

## 卡尔曼 vs 粒子：怎么选

| 维度 | 卡尔曼滤波（[第 60 章](ch60-kalman.md)） | 粒子滤波（本章） |
|------|------|------|
| 适用模型 | **线性 + 高斯** | **任意非线性/非高斯/多峰** |
| 分布表示 | 一个高斯（均值 + 协方差） | 一大群带权样本 |
| 计算量 | 极小（几个矩阵运算） | 大（∝ 粒子数） |
| 高维 | 从容 | 维度灾难 |
| 一句话 | 又快又准，但前提苛刻 | 万能但吃算力 |

现实里常常**取长补短**：SORT 用卡尔曼（快、够用），复杂非线性场景才上粒子滤波。这两章的滤波器输出的都是一条 \((x, y)\) 轨迹，它们**将在第十八部分被业务规则层消费**（绊线、逆行、停留判断等）。

## 动手练习

1. **扫粒子数**：把粒子数从 3000 改到 200、500、10000，记录末段平均误差和运行时间。多少个粒子起，精度就"够用不再明显变好"了？
2. **关掉重采样看退化**：把示例第二次调用改成 `resample = true` 对照，打印每一步的 \(N_{eff}\) 曲线，亲眼看它在不重采样时怎么一路塌到 1。
3. **造一个双峰**：让观测在某几帧"模棱两可"（比如似然对两个位置都高），验证加权均值会落到两峰中间的荒谬位置，再改用 MAP 看是否恢复正常。
4. **（挑战）离群观测**：随机往观测里塞几个跳得很远的离群点，把高斯似然换成**重尾似然**（如 t 分布或高斯 + 均匀背景的混合），验证粒子滤波对离群点的鲁棒性远胜卡尔曼。
