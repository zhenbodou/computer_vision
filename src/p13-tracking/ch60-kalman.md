# 第 60 章 卡尔曼滤波：状态、噪声与一致性

> **本章导读**
> - 用"我以为 + 我看到"的融合直觉，讲透**卡尔曼滤波（Kalman Filter）**：预测与更新两步、卡尔曼增益 \(K\) 的含义。
> - 用**匀速模型**状态 \([x, y, v_x, v_y]\) 搭出完整的 \(F, H, Q, R\)，用 nalgebra 从零实现。
> - 亲手量出**滤波前后对真值的 RMSE**——看它把噪声压下去多少。
> - 学会判断滤波器"信得过吗"：**NIS 一致性检查**、\(Q/R\) 调参含义、匀速模型对机动目标的局限。

## 场景引入：又抖又缺的检测框怎么变平滑

上一章的光流告诉我们像素怎么动，但真实跟踪里，我们更常拿到的是**目标检测器每帧吐出的一个框**——而且这些框**又抖又偶尔跳错**：同一个匀速走路的人，中心点却在真实轨迹附近乱跳好几像素。

有没有办法，既利用"人是匀速走的"这个先验，又参考"这一帧检测到的位置"，把两者**加权融合**成一条平滑又准确的轨迹？这正是卡尔曼滤波的拿手好戏，也是现代多目标跟踪（[第 62 章](ch62-mot.md) 的 SORT/DeepSORT）的运动核心。

## 原理：预测 + 更新，两步走

### 直觉：拿捏"我以为"和"我看到"

开车进隧道，GPS 没信号了，但你依然能靠"我刚才时速 60、方向朝北"**推算**当前位置（这叫**预测**）；一出隧道 GPS 回来了，你又用它**校正**推算的位置（这叫**更新**）。卡尔曼滤波干的就是这件事，而且它会精确地算出：这两个来源各有多大误差，该更信哪个。

- **预测**：用运动模型往前推一步，得到"先验估计"，同时不确定度（协方差 \(P\)）会**变大**（推算越久越没底）。
- **更新**：拿来一帧观测，与预测比较，按各自的可信度加权融合，得到"后验估计"，不确定度**变小**（看到了就更有底）。

### 状态、观测与四个矩阵

我们把目标状态设成四维 \(x = [x, y, v_x, v_y]^\top\)（位置 + 速度）。线性高斯模型写成两条方程（\(w, v\) 分别是过程噪声与观测噪声）：

\[ x_k = F\,x_{k-1} + w, \qquad z_k = H\,x_k + v \]

**匀速（constant velocity, CV）模型**下，位置每步加上"速度 × 帧间隔 \(\Delta t\)"，速度不变，于是状态转移矩阵 \(F\) 与观测矩阵 \(H\)（只测得到位置、测不到速度）为：

\[ F = \begin{bmatrix} 1 & 0 & \Delta t & 0 \\ 0 & 1 & 0 & \Delta t \\ 0 & 0 & 1 & 0 \\ 0 & 0 & 0 & 1 \end{bmatrix}, \qquad H = \begin{bmatrix} 1 & 0 & 0 & 0 \\ 0 & 1 & 0 & 0 \end{bmatrix} \]

还有两个"噪声旋钮"：**过程噪声** \(Q\)（模型有多不靠谱，比如目标可能突然加速）和**观测噪声** \(R\)（检测器有多不准）。它们的比值决定滤波器"更信模型还是更信观测"。

### 五行核心公式

**预测**（先验，上标减号表示"还没用观测校正"）：

\[ \hat{x}_k^- = F\,\hat{x}_{k-1}, \qquad P_k^- = F\,P_{k-1}\,F^\top + Q \]

**更新**（先算新息 \(y\)、新息协方差 \(S\)、卡尔曼增益 \(K\)，再融合）：

\[ y = z_k - H\,\hat{x}_k^-, \quad S = H\,P_k^-\,H^\top + R, \quad K = P_k^-\,H^\top S^{-1} \]

\[ \hat{x}_k = \hat{x}_k^- + K\,y, \qquad P_k = (I - K H)\,P_k^- \]

关键是**卡尔曼增益** \(K\)：它衡量"这一帧观测该占多大权重"。观测很准（\(R\) 小）时 \(K\) 大、猛往观测靠；观测很脏（\(R\) 大）时 \(K\) 小、稳住自己的预测。而且 \(K\) 会随时间**自动收敛**——一开始很不确定，猛信观测；越滤越有底，越来越信预测。

## 动手写代码

完整示例在 `code/examples/ch60_kalman.rs`，只用 nalgebra（矩阵）和 image（存图），运行：

```bash
cargo run --example ch60_kalman
```

核心就是把上面五行公式翻译成 nalgebra 的矩阵运算。这里用 `Matrix4 / Matrix2 / Matrix2x4 / Matrix4x2 / Vector4 / Vector2`（复习见 [第 30 章 nalgebra](../p05-numeric/ch30-nalgebra.md)），协方差更新用**数值更稳的 Joseph 形式** \(P = (I-KH)P(I-KH)^\top + K R K^\top\)（它天然保持对称半正定，避免长时间运行后 \(P\) "跑偏"）：

```rust
use nalgebra::{Matrix2, Matrix2x4, Matrix4, Matrix4x2, Vector2, Vector4};

// 每步：先预测，再用观测 z 更新。返回滤波后位置、增益、平均 NIS
for z in meas.iter().skip(1) {
    // —— 预测（先验）——
    x = f * x;
    p = f * p * f.transpose() + q;
    // —— 更新（用观测校正）——
    let z = Vector2::new(z.0, z.1);
    let y = z - h * x;                       // 新息：观测 - 预测
    let s = h * p * h.transpose() + r;       // 新息协方差
    let s_inv = s.try_inverse().unwrap();
    let k: Matrix4x2<f64> = p * h.transpose() * s_inv;  // 卡尔曼增益
    x += k * y;
    let ikh = i4 - k * h;                     // Joseph 形式更新协方差
    p = ikh * p * ikh.transpose() + k * r * k.transpose();
    // NIS = yᵀ S⁻¹ y：一致性自检（均值应接近观测维度 2）
    nis_sum += (y.transpose() * s_inv * y)[(0, 0)];
}
```

过程噪声 \(Q\) 用标准的**离散白噪声加速度模型**，由一个加速度标准差 `sigma_a` 统一决定（`sigma_a` 越大＝越承认"目标会乱动"＝越信观测）。`main` 里合成一条匀速直线真值轨迹，叠加标准差 8 像素的高斯观测噪声，跑 KF。

> ⚠️ **注意：小矩阵求逆可以，大矩阵请解方程。** 这里新息协方差 \(S\) 只有 2×2，`try_inverse` 完全够用。但当观测维度很高时，`K = P Hᵀ S⁻¹` 应改成**解线性方程组**（`S Kᵀ = H Pᵀ`，用 LU/Cholesky）而非显式求逆——更快也更稳。

### 实测输出

```text
== ① 匀速直线轨迹（观测噪声 std=8 px）==
 步  观测(x,y)         滤波(x,y)         真值(x,y)        增益K[0,0]
  1  (   5.5,  17.8)  (   6.2,  16.9)  (  12.2,  21.3)   0.940
  3  (  18.0,  21.5)  (  18.1,  24.3)  (  16.6,  23.9)   0.767
 10  (  32.6,  46.2)  (  37.6,  36.4)  (  32.0,  33.0)   0.340
 59  ( 149.2,  95.2)  ( 138.9,  94.5)  ( 139.8,  96.7)   0.106
原始观测 RMSE = 11.711 px（全程）/ 11.938 px（稳态）
卡尔曼滤波 RMSE = 5.991 px（全程）/ 5.289 px（稳态）
稳态误差降幅 = 55.7%
平均 NIS = 2.01（观测维度=2，落在其附近说明 Q/R 与真实噪声一致）
```

两个数字最关键：**稳态 RMSE 从 11.94 像素降到 5.29 像素，误差砍掉一半还多（55.7%）**；而**平均 NIS 恰好落在 2.01**——观测是二维的，NIS 的理论均值就该是 2，这说明我们设的 \(Q/R\) 与真实噪声"对得上"，滤波器**不自欺**。同时看增益 `K[0,0]` 从 0.940 一路收敛到 0.106：一开始几乎全信观测，越滤越信自己的预测。

> 📖 **术语**：**NIS（归一化新息平方，Normalized Innovation Squared）** \(= y^\top S^{-1} y\)。它衡量"这一帧的观测偏差，落在滤波器自己预报的误差范围内吗"。若长期均值远大于观测维度，说明滤波器**过度自信**（\(P\) 估小了）；远小于则过度保守。NIS/NEES 是工程上验收卡尔曼滤波是否可信的标准手段。

### 机动目标：\(Q\) 的调参含义

真值若不再匀速、而是**转弯**（违背 CV 假设），会怎样？示例第二部分合成一条匀速转弯轨迹，用大小两种 \(Q\) 各滤一遍：

```text
== ② 转弯（机动）轨迹：Q 调参 ==
原始观测         RMSE = 10.677 px
小 Q(σa=0.05) 滤波 RMSE = 13.538 px  <- 太信匀速模型，转弯处滞后
大 Q(σa=1.20) 滤波 RMSE =  6.148 px  <- 更信观测，跟得上但更抖
```

这组对比意味深长：**小 \(Q\) 时滤波结果反而比原始观测还差**（13.54 > 10.68）！因为滤波器死信"匀速直线"，目标一转弯它就滞后、系统性地"抄近道"。把 \(Q\) 调大、承认目标会机动，滤波才重新跟得上（6.15 px）。**这就是 \(Q/R\) 调参的精髓：\(Q\) 大＝信观测（跟得快但抖），\(Q\) 小＝信模型（平滑但对机动迟钝）。** 没有万能值，取决于你的目标有多"听话"。

> 💡 **提示**：滤波后的这条 \((x, y)\) 轨迹，正是跟踪系统要为每个目标维护的东西。在 [第 62 章](ch62-mot.md) 的 SORT 里，每个目标框都配一个这样的卡尔曼滤波器来预测下一帧位置、再和新检测做匹配。这些轨迹随后**将在第十八部分被业务规则层消费**（绊线、逆行、停留判断等）。

## 常见坑与提示

> 🕳️ **坑：初始协方差别设太小。** 初始状态基本靠猜（示例里速度直接设 0），若把初始 \(P\) 设得很小，等于"我对这个瞎猜非常自信"，滤波器会迟迟不肯相信观测、收敛极慢。正确做法是把初始 \(P\) 设大（示例设成 500 倍单位阵），表达"我很不确定"。

> ⚠️ **注意：丢帧/漏检时"只预测、别更新"。** 某帧没有检测到目标（遮挡、漏检），不要硬塞一个假观测。正确做法是**只做预测步**，让 \(P\) 自然变大（不确定度上升）；等下次观测回来再更新。连续预测多帧后 \(P\) 会很大，正好表达"我快跟丢了"。

> 💡 **提示：用马氏距离做门控（gating）。** 多目标场景里，一个新检测该不该关联到某条轨迹？用新息的**马氏距离** \(y^\top S^{-1} y\) 设个阈值：超出就认为"这不是同一个目标"，直接拒绝关联。这能有效挡住离群检测的干扰。

> ⚠️ **注意：单位与时间戳。** \(F\) 里的 \(\Delta t\) 必须和速度单位一致；变帧率时要每帧用真实 \(\Delta t\) 重算 \(F\) 和 \(Q\)。时间戳乱序、单位写错（像素/帧 vs 像素/秒）是卡尔曼滤波最常见的低级致命错误。

## 本章小结

- 卡尔曼滤波 = **预测（信模型）+ 更新（信观测）的最优加权融合**；卡尔曼增益 \(K\) 决定两者权重，并随时间自动收敛。
- 匀速模型用状态 \([x, y, v_x, v_y]\) 和矩阵 \(F, H, Q, R\) 描述；核心就五行公式，用 nalgebra 几十行即可实现。
- 实测：匀速轨迹上稳态 RMSE 从 11.94 px 降到 5.29 px（降 55.7%），平均 NIS≈2.01 印证 \(Q/R\) 一致。
- \(Q/R\) 调参是灵魂：\(Q\) 小信模型（平滑、对机动迟钝，甚至比原始观测更差），\(Q\) 大信观测（跟手但抖）。
- 工程加固：Joseph 形式保协方差半正定、大矩阵解方程而非求逆、NIS 做一致性验收、漏检时只预测、马氏距离门控。

## 动手练习

1. **调 \(Q/R\) 看 NIS**：把观测噪声 `r_std` 从 8 改到 3 和 20，但**故意不改** \(R\)。观察平均 NIS 怎么偏离 2，体会"滤波器谎报自信"是什么样子。
2. **漏检实验**：在观测序列里随机抹掉 30% 的帧（漏检），改成"有观测才更新、没有就只预测"。画出 \(P\) 的迹随时间的变化，看它在漏检段是否鼓起来。
3. **换匀加速模型**：把状态扩展成 \([x, y, v_x, v_y, a_x, a_y]\)（六维），改写 \(F, H, Q\)。它在转弯轨迹上是不是比匀速模型更跟手？
4. **（挑战）加门控**：合成几个离群观测（突然跳到很远），用马氏距离阈值把它们挡在更新之外，对比加门控前后的 RMSE。
