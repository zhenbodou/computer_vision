# 前言：写给想入门机器视觉的你

> **本书导读**
> - 这是一本从**零基础**走向**专家能力**的机器视觉书，全程以 **Rust** 为实现主线（不依赖 OpenCV）。
> - 你会学到：从"图像到底是一堆什么数字"，到经典算法、深度学习、三维视觉、工业落地与工程部署。
> - 完成正文、阶段验收和真实毕业项目后，你将具备独立设计、验证和交付视觉系统的能力；
>   仅阅读正文不等于专家，专家结论必须由实验、错误分析和生产证据支撑。

## 你好，未来的机器视觉工程师

如果你现在对"机器视觉"这四个字还有点发怵——不知道它和"人工智能"是什么关系，不知道一张照片在电脑里长什么样，更不知道该从哪儿写下第一行代码——**那太好了，这本书就是为此刻的你写的。**

我们不会一上来就甩给你一堆公式和黑话。相反，我会像一个耐心的师兄，带你从"图像其实就是一大堆数字"这种最朴素的直觉出发，一步一步，把机器视觉这座大山拆成一级一级好走的台阶。等你爬到山顶回头看，会发现所谓"高深"的目标检测、人脸识别、三维重建，不过是这些台阶自然堆叠的结果。

## 这本书有什么不一样

市面上讲机器视觉的书，要么是纯理论（读完不会写代码），要么绑死 Python + OpenCV（换个语言就抓瞎）。这本书有三个鲜明的选择：

**1. 用 Rust 实现视觉算法，不依赖 OpenCV。** 基础实验以 `image`、`imageproc`、`ndarray`、`nalgebra` 等 Rust 库为主，先在 CPU 上学会算法。

- “算法用 Rust”不表示整个系统没有原生依赖：编译需要平台链接器，视频章节的可选 FFmpeg 路线需要外部程序，GPU 需要驱动和对应后端。
- 浏览器、嵌入式与桌面不是同一个编译目标；设备接入、模型支持和资源预算需要分别验证。各独立工程的 `Cargo.toml` 才是依赖依据。
- Rust 帮我们管理内存与并发；算法正确性、业务准确率和服务可靠性仍需实验与测试证明。

**2. 通俗，但不肤浅。** 每个概念我都先用生活里的例子讲清楚"它到底在干嘛、为什么需要它"，再给出严谨的原理和公式，最后配上**配套可运行实验与标明上下文的代码片段**。直觉、原理、代码，三样都不缺。

**3. 学术 + 工业，两手都硬。** 很多书只讲算法（分类、检测、分割……），却对真实项目里最值钱的部分只字不提——比如监控系统里怎么用 **ROI 区域、绊线、时间窗口、冷却去抖**把一堆检测框变成一条靠谱的报警。这本书专门有一整个部分讲这些**工业落地**的门道，还有工业机器视觉里的**精密测量、缺陷检测、视觉定位、工业读码**。

## 你需要什么基础

- **机器视觉基础：零。** 不需要你懂任何图像或 AI 知识，我们从头讲。
- **编程基础：会一点点就行。** 哪怕你只写过一点点别的语言的代码也没关系。[第 4 章](p01-start/ch04-rust-crash-course.md) 会用一章"速成营"把后面要用到的 Rust 知识补齐——够用就行，不求全。
- **数学基础：初中高中水平即可起步。** 遇到线性代数、概率的地方，我会即用即讲，附录 B 还有一份"随查随用"的数学速查。
- **硬件：一台普通电脑。** 大部分内容 CPU 就能跑；用到 GPU 加速的地方（比如 Mac 的 Metal）我会专门说明。

## 这本书怎么读

全书共 **21 个部分、113 章**，像一条由缓到陡的登山路线：

| 阶段 | 部分 | 你会得到 |
|------|------|----------|
| **打地基** | 第一~五部分 | 看懂图像的本质，玩转经典图像处理与特征 |
| **上台阶** | 第六~七部分 | 从传统机器学习过渡到深度学习 |
| **攀主峰** | 第八~十六部分 | 分类、检测、分割、关键点、人脸、跟踪、三维、生成式、视频 |
| **接地气** | 第十七~十八部分 | 工业测量/缺陷/读码，以及事件后处理与规则引擎（工业落地核心） |
| **搞交付** | 第十九~二十一部分 | 模型部署、实战项目、性能优化与工程化 |

建议的读法：

- **纯新手**：先做 [附录 H 的入学自测与数学热身](appendix/h-learning-path.md)，再按其中的先修路线阅读。每章先预测结果，再运行、修改、解释失败。遇到进阶验收可以分两遍完成。
- **有编程经验**：可以快速略过 [第 4 章](p01-start/ch04-rust-crash-course.md)，其余顺序读。
- **想解决具体问题**：先读完第一~三部分建立直觉，再按 [SUMMARY 目录](SUMMARY.md) 跳到你关心的主题（比如"目标检测"或"绊线计数"）。

> 💡 **提示**：这本书最大的价值在于**动手**。每章末尾都有"动手练习"，请务必自己敲代码、改参数、看结果。看会了和写会了，中间隔着一整个机器视觉行业。

各部分收束章还包含“阶段验收”。普通练习用于确认概念和 API，阶段验收则要求固定数据、
建立基线、报告不确定性、分析失败、测量性能并完成开放式交付。全书统一证据标准见
[附录 G](appendix/g-expert-standard.md)。没有完成这些验收，不应把“看完”表述为“精通”。

## 代码约定

- 主工程采用 **Rust 2024 edition**，位于 `code/`，crate 名为 `cv_examples`；深度学习、项目、GPU 和 Web 示例另有独立工程。运行入口见 [附录 K](appendix/k-code-index.md)。
- 核心依赖系列为 `image 0.25`、`imageproc 0.27`、`ndarray 0.17`、`nalgebra 0.35`。复现实验请保留各工程的 `Cargo.toml` 与 `Cargo.lock`，使用 `--locked`；不要为了复现而自行换成“相近版本”。
- 代码块里的注释是中文，关键步骤都会解释"为什么这么写"。
- 需要在终端敲的命令，用 ` ```bash ` 标注，例如：

```bash
cd code
cargo run --locked --example ch07_load_save
```
