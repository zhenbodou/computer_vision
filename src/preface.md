# 前言：写给零基础的你

## 这本书是写给谁的

这本书写给这样的你：

- 会一点 Rust（能写基本的函数、结构体、能看懂 `Result` 和错误处理就够了）；
- 但对机器视觉**完全没有概念**——不知道一张 JPG 图片在内存里长什么样，不知道"模型推理"是什么意思，更没听过 NMS、letterbox、ONNX 这些词；
- 想**从工程角度**把机器视觉这条线彻底搞明白，而不是只背概念。

别担心，这本书默认你除了 Rust 语法之外**什么都不会**。每一个新概念，都会先拿生活中的例子打比方，再上代码动手做。你不需要懂线性代数、不需要懂深度学习理论，只需要跟着书一节一节往下走。

## 机器视觉到底是个啥

用一句话说：**机器视觉就是让计算机"看"懂图片和视频的技术**。

你手机的人脸解锁、超市的扫码枪、工厂的自动质检、特斯拉的自动驾驶——背后都是机器视觉。它做的事情拆开看永远是一样的五步流水线：

```text
摄像头/文件 → ① 解码成像素 → ② 预处理 → ③ 模型推理 → ④ 后处理 → 人能看懂的结果
             （第 5、6 章）  （第 10 章） （第 14 章）  （第 16 章）
```

这本书的主线就是把这条流水线的每一环都讲透，然后扩展到真实的视频分析（跟踪、业务过滤、多模型协同），最后串起来做几个完整的实战项目。

全书分成 **9 个部分、32 章**，外加 4 个附录。整体沿着上面那条流水线走一遍，再扩展成真实项目，最后补齐评估、测试和生产运维：

| 部分 | 章节 | 讲什么 |
| --- | --- | --- |
| 第一部分 · 打地基 | 第 1~4 章 | 机器视觉全景、图像的本质、Rust 图像处理工具、色彩空间与内存布局 |

| 第四部分 · 预处理 | 第 10 章 | 缩放、letterbox、色彩转换、归一化、张量布局——喂给模型前的准备 |

## 阅读前的约定

**1. Rust 版本与 crate 版本。** 全书代码基于 Rust 2021 edition，主要使用下面这些 crate。具体基线见附录 B 和各章的 `Cargo.toml`；不要把预发布版或发生过破坏性升级的 crate 盲目换成最新版，否则示例 API 可能不兼容。

| crate | 用途 |
| --- | --- |
| `image` | 读写 JPG/PNG 等图片，基础图像操作 |
| `ndarray` | 多维数组（就是张量），Rust 版的 NumPy |
| `imageproc` | 图像处理算法（画框、滤波、边缘检测等） |
| `fast_image_resize` | 高性能缩放（工业界常用的图像缩放库） |
| `tract-onnx` | 纯 Rust 的 ONNX 推理引擎 |
| `ort` | ONNX Runtime 的 Rust 绑定（性能更强） |
| `opencv` | OpenCV 的 Rust 绑定（视频解码、丰富算法），编译较重，可选 |
| `nalgebra` | 线性代数（卡尔曼滤波等会用到） |

**2. 贯穿全书的例子。** 我们会一直用同一个任务当"陪练"：**检测一张照片里有哪些物体（目标检测）**。每一章都为这个任务添一块砖，到综合实战部分（第 26~28 章）拼出完整程序。这样你能清楚看到每个知识点在流水线里站在哪一格。

**3. 代码的风格。** 书中代码优先保证**能看懂**，其次才是性能。真正上线的工业代码会有更多错误处理、零拷贝等优化，书中会在合适的地方提醒你"这里工程上通常会怎么做"。

**4. 数学。** 全书只在必要的地方用到一点点数学（均值、方差、矩阵乘法、Softmax、IoU），而且都会先算一遍给你看。附录 A 汇总了所有用到的数学知识，忘了随时翻。

## 建议你这样读

1. **按顺序读**。这本书的章节是流水线顺序，前面是后面的地基，跳着读容易看不懂。
2. **代码一定要自己敲一遍**。看懂和能写是两回事，每一章的代码都请你新建一个 cargo 项目亲手跑通。
3. **做章末的练习**。练习都不难，但能让你发现"以为自己懂了"的部分。
4. **不懂就回头**。读后面章节时忘了前面的概念很正常，回头看一眼对应章节再回来。
