# 第 38 章 经典网络结构演进（LeNet→ResNet→Transformer）

> **本章导读**

> - 重点吃透 **ResNet 的残差连接**——用"抄近道"的直觉理解它为什么能把网络堆到上百层还不退化。

> - 用一张表横向对比各网络的年代、关键创新与参数量级，为后面用 `candle` 跑 ResNet 分类、以及生成/多模态部分的 ViT、CLIP 埋下伏笔。

## 场景：一场持续二十多年的登山接力

上一章我们搭好了 CNN 的积木——卷积、ReLU、池化、全连接。但**同样的积木，怎么搭才最好？** 这个问题，一代代研究者用二十多年、一篇篇里程碑论文接力回答。

这一章没有太多代码，我们讲**故事**：从 1998 年识别手写邮编的 LeNet，到 2012 年引爆整个深度学习浪潮的 AlexNet，再到能堆到上百层的 ResNet，最后到抛开卷积、用"注意力"重新想象图像的 Vision Transformer。**你会发现，网络结构的每一次跃迁，都是在解决上一代撞到的一堵墙。** 看懂这条演进线，你再去读任何一个现代网络的结构图，都能一眼看出它"站在谁的肩膀上、又往前迈了哪一步"。

## LeNet-5（1998）：卷积网络的开山鼻祖

故事从 Yann LeCun 说起。早在 1998 年，他就用一个叫 **LeNet-5** 的网络识别手写数字，真的部署到银行去读支票、邮局去读邮政编码。

LeNet-5 的结构，今天看来朴素得亲切：**卷积 → 池化 → 卷积 → 池化 → 全连接 → 全连接 → 输出**，七层左右，参数只有**约 6 万**。它已经包含了上一章讲的全部核心思想——局部感受野、权值共享、层级特征——可以说 CNN 的骨架在这里就定型了。

但它生不逢时：当年既没有海量标注数据，也没有强大算力，网络稍微加深加宽就训不动。LeNet 证明了"卷积这条路走得通"，却只能在手写数字这种小任务上小试牛刀。**深度学习还要再等十四年，才等来它的引爆点。**

## AlexNet（2012）：一声惊雷，引爆深度学习

2012 年，Krizhevsky、Sutskever 和 Hinton 带着 **AlexNet** 参加 ImageNet 大赛（一个要在 1000 个类别里分类上百万张图的硬仗）。结果：top-5 错误率从上一年最好的约 **26%** 骤降到约 **16%**——断崖式的领先，把用传统手工特征的对手远远甩开。**这一战，直接点燃了整个深度学习时代。**

AlexNet 结构上像"加大加深版 LeNet"（5 个卷积层 + 3 个全连接层，约 **6000 万参数**），但它带来几个影响至今的关键改进：

- **用 ReLU 替代 sigmoid**：还记得 [第 36 章](ch36-neural-nets.md) 的梯度消失吗？ReLU 正区间导数恒为 1，让深层网络终于训得动、还快得多。
- **Dropout**：训练时随机"关掉"一部分神经元，逼网络别过度依赖某几个，有效防止过拟合。
- **数据增强 + 双 GPU 训练**：用翻转、裁剪扩充数据，并第一次大规模用 GPU 硬啃训练——**算力**从此成为深度学习的核心生产力。

AlexNet 告诉世界：**只要有足够的数据、算力和几个关键技巧，"大深网络"能碾压一切手工特征。** 接下来的问题自然就是——**还能更深吗？**

## VGG 与 GoogLeNet（2014）：把网络做深、做巧

2014 年，两条路线同时给出回答。

**VGG** 走的是"大道至简"：它把卷积核**全部统一成最小的 3×3**，然后靠**堆叠**把网络加深到 16 层（VGG16）、19 层（VGG19）。为什么小核堆叠好？因为两个 3×3 叠起来的感受野等于一个 5×5，但参数更少、非线性更多。VGG 结构规整得像搭积木，成了后来无数工作的骨干网络——代价是参数量惊人，**VGG16 约 1.38 亿参数**，又大又慢。

**GoogLeNet（Inception）** 走的是"精打细算"：它设计了 **Inception 模块**，在同一层里**并行**用 1×1、3×3、5×5 几种核和池化，捕捉**多种尺度**的特征再拼起来；更关键的是用 **1×1 卷积先降维**，大幅削减计算量。结果它有 22 层，参数却只有**几百万**（约 500 万上下），比 VGG 小得多还更准。**1×1 卷积"降维减负"的思想**，此后被反复借用。

## ResNet（2015）：残差连接，"抄近道"破解深层退化

网络越深越好，那我们一路堆到几百层不就完事了？**偏偏不行。** 何恺明等人在 2015 年发现一个反直觉的现象——**退化（degradation）**：把网络从 20 层加到 56 层，**训练误差反而上升了**。这不是过拟合（连训练集都学不好），而是**太深的网络连"什么都不做"都学不会**：理论上多出来的层只要做"恒等映射"（原样透传）就不会更差，可让一堆非线性层精确拟合出恒等映射，实践中竟然很难。

**ResNet 的解法优雅得让人拍案：既然让层去学"恒等透传"很难，那我就直接给它修一条"近道"。** 具体做法是加一条**残差连接（residual/skip connection）**——把这一块的输入 \\( x \\) 直接"抄近道"加到输出上：

```text
      x ───────────────────────┐  (恒等捷径 shortcut：把输入直接抄过来)
      │                         │
   [Conv → ReLU → Conv]         │   这几层要学的是"残差" F(x)
      │                         │
      ▼                         ▼
     F(x) ───────────(+)─────── x
                       │
                     ReLU
                       │
                       ▼
             输出 H(x) = F(x) + x
```

关键在于视角一转：这一块的目标输出记作 \\( H(x) \\)，但我们**不让它直接学 \\( H(x) \\)，而是学"残差" \\( F(x) = H(x) - x \\)**，最后输出 \\( H(x) = F(x) + x \\)。这带来两个巨大好处：

- **学残差比学原函数容易**。如果这一块的最优解就是"啥也别改、原样透传"（即 \\( H(x) = x \\)），那网络只需把 \\( F(x) \\) 学成 0——把权重往 0 推谁不会啊！这比让几层非线性凑出一个精确的恒等映射容易太多了。
- **给梯度修了条高速公路**。那条"+x"的捷径让反向传播的梯度可以**绕过中间的层直接回传**，梯度消失（[第 36 章](ch36-neural-nets.md) 的老朋友）被大大缓解。

于是 ResNet 一口气把网络堆到了 **50、101 甚至 152 层**（ResNet-50 约 2500 万参数），还越深越准，当年 ImageNet 夺冠。**残差连接如今是几乎所有深层网络的标配**——你后面会在无数模型里再见到这条"抄近道"的小尾巴。

> 💡 **提示**：残差连接的精神可以一句话概括——**"实在学不好，起码别帮倒忙。"** 捷径保证了信息和梯度总有一条畅通无阻的通道，中间那几层"锦上添花"即可，学不到东西时退化成透传也不亏。

## MobileNet（2017）：把网络做"小"，塞进手机

前面的网络都在拼"更准更深"，但要跑在手机、摄像头这类**边缘设备**上，"小而快"才是刚需。**MobileNet** 用**深度可分离卷积（depthwise separable convolution）**把标准卷积拆成两步——先每个通道各卷各的（depthwise），再用 1×1 卷积跨通道混合（pointwise）——用一点点精度换来计算量和参数量的大幅下降（MobileNetV1 仅约 **420 万参数**）。这条"轻量化"路线，是移动端和嵌入式视觉的主力，我们在第二十一部分讲边缘部署时还会细说。

## Vision Transformer（2020）：抛开卷积，让图像学会"环顾全图"

2020 年，一个更激进的想法登场：**能不能干脆不用卷积？** **Vision Transformer（ViT）** 借用了自然语言处理里大杀四方的 Transformer，把图像当成"一句话"来读。

做法是：**把图像切成一个个固定大小的小块（patch，如 16×16），每个 patch 拉直、投影成一个向量，当作一个"单词（token）"**；再加上位置编码，整句"图像话"送进 Transformer，用**自注意力（self-attention）**来处理。

**自注意力的直觉**：你读句子时，理解某个词会**回看**句中所有相关的词。自注意力就是让每个 patch"**环顾全图所有 patch，算出该重点关注谁**"，再按关注度加权汇总信息。这和 CNN 有本质不同：CNN 要靠堆很多层才能慢慢扩大感受野，而**自注意力一步就能让每个位置"看到"全图**（全局感受野），更擅长捕捉长距离的关系。

> ⚠️ **注意**：**ViT 强，但有前提——它吃数据。** 卷积天生带有"局部性、平移等变"这类关于图像的先验（专业叫**归纳偏置**），ViT 几乎把这些先验全抛了，改成"从数据里自己学"。所以在**数据量不够大**时，ViT 往往打不过同规模 CNN；只有用**超大规模数据集**（如三亿张图级别）预训练后，它才展现出超越 CNN 的威力。别看到"Transformer 更先进"就无脑上 ViT，数据不够时它反而更差。

## 一张表看懂十年演进

| 网络 | 年代 | 关键创新 | 层数 | 参数量级 |
|------|------|----------|------|----------|
| **LeNet-5** | 1998 | 卷积+池化雏形，识别手写数字，CNN 开山 | 约 7 | 约 6 万 |
| **AlexNet** | 2012 | ReLU、Dropout、GPU 训练，ImageNet 夺冠引爆 DL | 8 | 约 6000 万 |
| **VGG** | 2014 | 全用 3×3 小核堆叠、加深、结构规整 | 16 / 19 | 约 1.38 亿(VGG16) |
| **GoogLeNet/Inception** | 2014 | Inception 多尺度并行、1×1 卷积降维减负 | 22 | 约 500 万 |
| **ResNet** | 2015 | 残差连接破解深层退化，可堆到上百层 | 18 ~ 152 | 约 2500 万(R50) |
| **MobileNet** | 2017 | 深度可分离卷积，轻量、边缘部署 | 约 28 | 约 420 万 |
| **ViT** | 2020 | 图像切 patch 当 token、自注意力、抛开卷积 | 12+ 个 Transformer 块 | 约 8600 万(Base) |

看这张表，能读出几条清晰的主线：**AlexNet 起把网络做深做大 → VGG/GoogLeNet 一个做深一个做巧 → ResNet 用残差连接彻底解放了深度 → MobileNet 反向做轻量 → ViT 换掉卷积这个"发动机"。** 每一步都在补上一代的短板。

## 常见坑与提示

> 🕳️ **坑**：**别神化任何一个网络，"新"不等于"处处更好"。** ViT 再火，在小数据集上也常输给 ResNet；ResNet 再经典，要上手机你还得看 MobileNet。**选网络永远要看任务、数据量和部署环境**，而不是看谁最新最潮。工业界至今大量在用 ResNet、MobileNet 这些"老将"，因为它们稳、快、生态成熟。

> ⚠️ **注意**：**参数量级别记错，也别死记精确数字。** 不同实现、不同变体（VGG16 vs VGG19、ResNet-50 vs 152）参数量差别很大，本章给的都是"量级"参考。你要记住的是**相对关系和趋势**——比如"VGG 又大又重、GoogLeNet 用 1×1 把参数压下去了、MobileNet 是轻量级"，而不是背下"138M"这种精确值。

> 💡 **提示**：**这些网络你很快就会亲手跑起来。** 别停留在"听个故事"。到 [第八部分](../p08-classification/ch42-candle-classify.md) 我们会用 `candle` 加载预训练的 ResNet 做真实图像分类；生成与多模态部分还会用到 ViT 和 CLIP。到时候回头再看这一章，你会对"为什么它长这样"有完全不同的体会。

## 本章小结

- **LeNet（1998）** 定型了 CNN 骨架，但受限于数据与算力；**AlexNet（2012）** 靠 ReLU、Dropout、GPU 在 ImageNet 一战成名，引爆深度学习。
- **VGG（2014）** 用 3×3 小核堆深、结构规整但参数巨大；**GoogLeNet/Inception（2014）** 用多尺度并行和 1×1 卷积降维，做到又深又省。
- **ResNet（2015）** 是重中之重：**残差连接**让网络学 \\( F(x) = H(x) - x \\) 而非直接学 \\( H(x) \\)，既让"退化"时能轻松退回恒等透传，又给梯度修了条高速公路，从此网络能堆到上百层。
- **MobileNet（2017）** 用深度可分离卷积主打轻量化，服务边缘部署；**ViT（2020）** 把图像切 patch 当 token、用自注意力抛开卷积，但**依赖超大数据**才占优。
- 选网络看任务、数据、部署，别神化新网络；参数量记量级和趋势即可。
