## 场景：老照片、糊监控、和"一键梵高"

三个再常见不过的需求，其实是同一类问题的三张面孔：

- **超分辨率**：一张分辨率很低的老照片、或者监控里远处那张糊掉的人脸，能不能"放大并变清晰"？
- **去噪**：夜里拍的照片、高 ISO 的监控帧，满是雪花噪点，能不能"擦干净"？
- **风格迁移**：把一张普通照片，套上梵高《星空》的笔触、或者某种色调，变成一幅"画"？

它们都属于**图像复原与生成（image restoration & generation）**——**图进、图出**，但出来的图要比进去的"更好"或"更不一样"。这一章我们三个都动手，而且坚持一条原则：**能纯 Rust 真跑通的，就给真数字；纯 Rust 暂时做不到的（比如需要下载 VGG 的真 NST），就老实说清边界、给务实替代**，绝不编数字。

## Part A · 超分辨率：双线性插值 vs SRCNN

### 原理：放大的本质是"猜出不存在的像素"

把一张 16×16 的图放大到 32×32，你得**凭空多造出 3/4 的像素**。最朴素的办法是**插值**——新像素的值，由它周围的老像素**加权平均**猜出来。[第 13 章](../p03-classic/ch13-convolution.md) 我们就见过这种"邻域加权"的思想。

最常用的两种插值：

- **双线性（bilinear）**：新像素 = 最近 4 个老像素按距离加权平均。快、平滑，但**边缘会糊**——因为"平均"天生会把锐利的跳变抹平。
- **双三次（bicubic）**：用最近 16 个像素、三次多项式拟合，比双线性锐一点，但边缘依旧不够利。

问题的根子在于：**插值只会"抹平",不会"脑补细节"**。它不知道"这条模糊的边，原本应该是一条锐利的直线"。而这，正是深度学习能补上的一环。

> 📖 **术语**：**超分辨率（Super-Resolution，SR）**。从低分辨率图（LR）恢复出高分辨率图（HR）的任务。**\\( 2\times \\) 超分**就是边长放大 2 倍、像素数变 4 倍。评价好坏最常用 **PSNR**（越大越像原始高清图）。

### SRCNN 与"残差学习"：只让网络学"锐化那一点点"

**SRCNN**（Super-Resolution CNN，2014）是第一个把 CNN 用于超分的经典工作，思路朴素得可爱：**先用双线性/双三次把 LR 插值放大到目标尺寸，再用几层卷积把这张"糊图"精修成"清图"**。也就是说，卷积网络负责干插值干不了的活——**把糊掉的边缘重新变锐**。

我们再加一个让训练**又快又稳**的技巧——**残差学习（residual learning）**：不让网络直接输出整张高清图，而是只输出一张**"修正量"**（残差），加回到双线性图上：

```text
 LR 低清图 ──双线性放大──▶ 糊图 x ──┬──────────────▶(＋)──▶ 高清输出
                                    │                  ▲
                                    └──▶ 卷积网络 ──▶ 残差 r（锐化修正）
```

好处很直接：网络**初始残差≈0 → 起点就等于双线性基线**，训练只会把质量往上推、几乎不可能变得比基线还差。用公式写，输出是 \\( \hat{x} = x + r_{\theta}(x) \\)，其中 \\( x \\) 是双线性放大图、\\( r_{\theta} \\) 是网络学的残差。

### 动手：搭 SRCNN、写 PSNR、和基线 PK

> ⚠️ **注意**：本章代码基于 **candle 0.11.0**，纯 CPU。完整独立工程见 `code/dl_labs/ch72_restoration/`，`cd` 进去 `cargo run --release` 一键跑完超分、去噪、风格迁移三部分。`Lcg`、`det_init` 沿用 [第 42 章](../p08-classification/ch42-candle-classify.md)。

先把两块**纯 Rust 基础件**写好：双线性插值（既用来做"退化"，也用来做基线），和 **PSNR**。

```rust
// 纯 Rust 双线性插值 resize（半像素中心对齐）
fn bilinear_resize(src: &[f32], sw: usize, sh: usize, dw: usize, dh: usize) -> Vec<f32> {
    let mut out = vec![0f32; dw * dh];
    let (rx, ry) = (sw as f32 / dw as f32, sh as f32 / dh as f32);
    for dy in 0..dh {
        let fy = ((dy as f32 + 0.5) * ry - 0.5).max(0.0);
        let (y0, wy) = ((fy.floor() as usize).min(sh - 1), fy - fy.floor());
        let y1 = (y0 + 1).min(sh - 1);
        for dx in 0..dw {
            let fx = ((dx as f32 + 0.5) * rx - 0.5).max(0.0);
            let (x0, wx) = ((fx.floor() as usize).min(sw - 1), fx - fx.floor());
            let x1 = (x0 + 1).min(sw - 1);
            let top = src[y0 * sw + x0] * (1.0 - wx) + src[y0 * sw + x1] * wx; // 上边两点插值
            let bot = src[y1 * sw + x0] * (1.0 - wx) + src[y1 * sw + x1] * wx; // 下边两点插值
            out[dy * dw + dx] = top * (1.0 - wy) + bot * wy;                    // 再纵向插值
        }
    }
    out
}
```

**PSNR 我们自己算**——像素值域 \\( [0,1] \\) 时最大值 \\( \text{MAX}=1 \\)：

\\[ \text{PSNR} = 10 \cdot \log_{10}\!\left(\frac{\text{MAX}^2}{\text{MSE}}\right) = -10 \cdot \log_{10}(\text{MSE}) \\]

```rust
fn psnr_vec(a: &[f32], b: &[f32]) -> f32 {
    let mse: f32 = a.iter().zip(b).map(|(x, y)| { let d = x - y; d * d }).sum::<f32>() / a.len() as f32;
    if mse <= 1e-12 { 99.0 } else { -10.0 * mse.log10() } // MAX=1 → PSNR = -10 log10(MSE)
}
```

数据这样造：合成 32×32 高清图（随机几条横竖白条，边缘丰富），**退化**成 16×16 低清，再**双线性放大**回 32×32 当作网络输入与基线。SRCNN 就三层卷积 + 残差：

```rust
struct SrCnn { c1: Conv2d, c2: Conv2d, c3: Conv2d }
impl SrCnn {
    fn load(vb: VarBuilder) -> Result<Self> {
        Ok(Self {
            c1: conv2d(1, 32, 5, Conv2dConfig { padding: 2, ..Default::default() }, vb.pp("c1"))?,
            c2: conv2d(32, 16, 3, Conv2dConfig { padding: 1, ..Default::default() }, vb.pp("c2"))?,
            c3: conv2d(16, 1, 3, Conv2dConfig { padding: 1, ..Default::default() }, vb.pp("c3"))?,
        })
    }
    fn forward(&self, x: &Tensor) -> Result<Tensor> {
        let h = self.c1.forward(x)?.relu()?;
        let h = self.c2.forward(&h)?.relu()?;
        let r = self.c3.forward(&h)?; // 预测「双线性图 → 高清」的残差
        x + &r                        // 残差学习：起点≈双线性，训练只会把 PSNR 往上推
    }
}
```

训练循环还是熟悉的 MSE（目标是高清原图），跑 300 轮后在测试集比 PSNR：

```text
==== 1) 超分辨率：纯 Rust 双线性插值基线 vs SRCNN（2x 放大） ====
  epoch 300  训练 MSE = 0.001623
  双线性插值基线 PSNR = 15.23 dB
  SRCNN 超分       PSNR = 29.93 dB   （提升 14.70 dB）
```

**从 15.23 dB 到 29.93 dB，整整提升 14.70 dB。** 对照图 `out_ch72_sr.png`（低清 | 双线性 | SRCNN | 高清原图）里，双线性那列的白条边缘一片朦胧，而 SRCNN 那列的边缘明显锐利、贴近最右的高清原图。**网络确实学会了插值学不会的事——把糊边重新变锐。**

> 💡 **提示**：真实世界的超分（如 SRResNet、ESRGAN、Real-ESRGAN）网络更深、还常用**转置卷积/PixelShuffle** 在网络内部完成放大，并用**感知损失 + 对抗损失**代替纯 MSE，出片更锐更真。但**内核思想和我们这个小 SRCNN 完全一致**：让网络去脑补插值补不出的高频细节。

## Part B · 去噪：经典滤波 vs DnCNN

### 经典基线：高斯 vs 中值，各有各的脾气

去噪的老办法是**空间滤波**——拿一个小窗口在图上滑动，用邻域像素"投票"决定中心该是多少（[第 13 章](../p03-classic/ch13-convolution.md) 讲过卷积滤波）。两个经典代表：

- **高斯滤波**：邻域**加权平均**（中间权重大）。能压平随机噪声，但它**分不清"噪声"和"边缘"**——边缘也是一种剧烈变化，于是被一起抹糊。
- **中值滤波**：取邻域的**中位数**。对"个别离谱的噪点"特别有效，而且**保边能力强**（中位数不容易被少数极端值带偏）。

两个都能纯 Rust 手写。以中值为例：

```rust
fn median3(src: &[f32], side: usize) -> Vec<f32> {   // 3x3 中值滤波
    let mut out = vec![0f32; side * side];
    let at = |x: i32, y: i32| src[(y.clamp(0, side as i32 - 1) as usize) * side
                                   + x.clamp(0, side as i32 - 1) as usize];
    for y in 0..side as i32 {
        for x in 0..side as i32 {
            let mut w = [0f32; 9];
            let mut k = 0;
            for dy in -1..=1 { for dx in -1..=1 { w[k] = at(x + dx, y + dy); k += 1; } }
            w.sort_by(|a, b| a.partial_cmp(b).unwrap());
            out[y as usize * side + x as usize] = w[4]; // 9 个值的中位数
        }
    }
    out
}
```

### DnCNN：让网络去"认出噪声"

**DnCNN**（Denoising CNN，2017）的思路和上面 SRCNN 的残差学习异曲同工，甚至更纯粹：**不让网络直接输出干净图，而是让它输出"噪声长什么样"，再从脏图里把噪声减掉。**

\\[ \hat{x}_{\text{clean}} = x_{\text{noisy}} - r_{\theta}(x_{\text{noisy}}) \\]

其中 \\( r_{\theta} \\) 是网络预测的噪声。为什么学噪声比学干净图容易？因为噪声的统计规律（到处都差不多的随机扰动）比"千变万化的干净内容"简单得多，网络更好抓。

```rust
struct DnCnn { c1: Conv2d, c2: Conv2d, c3: Conv2d }
impl DnCnn {
    fn forward(&self, noisy: &Tensor) -> Result<Tensor> {
        let h = self.c1.forward(noisy)?.relu()?;
        let h = self.c2.forward(&h)?.relu()?;
        let resid = self.c3.forward(&h)?; // 预测噪声
        noisy - &resid                    // 干净 = 噪声图 - 噪声
    }
}
```

给干净形状图加上强噪声（半幅 0.35 的均匀噪声）后训练，测试集上四方 PK：

```text
==== 2) 去噪：纯 Rust 经典滤波基线 vs DnCNN ====
  含噪图         PSNR = 16.95 dB（去噪前）
  高斯滤波基线   PSNR = 16.72 dB（模糊了边缘，边缘密集时几乎不赚甚至倒亏）
  中值滤波基线   PSNR = 19.59 dB（保边更好，明显改善）
  DnCNN 去噪     PSNR = 32.32 dB（学习式，大幅领先）
```

这四个数字讲了一个**特别诚实**的故事：

- **高斯滤波（16.72）居然比不去噪（16.95）还略低！** 因为我们的图边缘密集，高斯在压噪声的同时把边缘也抹糊了，一进一出几乎白忙、甚至倒亏。这不是 bug，是高斯滤波的**固有代价**——它分不清噪声和边缘。
- **中值滤波（19.59）明显改善**：保边能力强，是这类"分块平坦 + 锐利边缘"图像更合适的经典工具，+2.6 dB。
- **DnCNN（32.32）一骑绝尘**：比最好的经典基线还高出 **12 dB 以上**。对照图 `out_ch72_denoise.png`（含噪 | 中值 | DnCNN | 干净）里，含噪列几乎被雪花淹没，中值列干净了但形状发圆发钝，DnCNN 列则还原出锐利干净的方块，逼近最右的原图。

> ⚠️ **注意**：**别被"学习式碾压经典"冲昏头。** 这里 DnCNN 大胜，是因为**训练噪声和测试噪声同分布**、内容也简单。真实场景里噪声类型五花八门（读出噪声、散粒噪声、压缩块效应……），训练分布一旦和现场不匹配，学习式方法可能**翻车得比经典方法更难看**。经典滤波胜在**零训练、可预测、稳**——这正是 [第 1 章](../p01-start/ch01-what-is-cv.md) 说的"经典方法至今不可替代"的道理。工程上常常是**先经典、扛不住再上学习式**。

## Part C · 风格迁移：一条诚实的边界线

### 原理：内容损失 + 风格损失 + Gram 矩阵

**神经风格迁移（Neural Style Transfer，NST）**，即 Gatys 等人 2015 年的经典工作，要同时满足两个愿望：**输出图的"内容"像照片 A，"风格"像画作 B**。妙就妙在它怎么把"内容"和"风格"这两个玄乎的概念，变成可计算的**损失函数**——靠一个**预训练好的 CNN（通常是 VGG）**当"眼睛"：

- **内容损失（content loss）**：把生成图和内容图 A 都喂进 VGG，取**某一深层**的特征图，要求两者接近。深层特征编码的是"有什么东西、在哪儿"这种**语义/布局**，所以匹配它 = 匹配内容。写作 \\( L_{\text{content}} = \| F - F_A \|^2 \\)（\\( F \\) 是特征图）。
- **风格损失（style loss）**：风格是什么？Gatys 的洞见是——**风格 = 特征之间的相关性，而非它们的空间位置**。这个相关性用 **Gram 矩阵**刻画：把某层特征图摊平成矩阵 \\( F \\)（每行是一个通道），则

\\[ G = F F^{\top} \\]

  \\( G \\) 的第 \\( (i,j) \\) 项是通道 \\( i \\) 和通道 \\( j \\) 的内积——**它丢掉了"在哪儿"，只留下"什么纹理/颜色总是一起出现"**，这恰好就是"风格"的数学化身。风格损失就是让生成图的 Gram 矩阵逼近风格图 B 的：\\( L_{\text{style}} = \sum_l \| G^l - G^l_B \|^2 \\)（对多个层求和）。

总损失是两者加权：\\( L = \alpha L_{\text{content}} + \beta L_{\text{style}} \\)，然后**用梯度下降去优化那张生成图本身**（而不是网络权重），一步步把它"逼"成既像 A 的内容、又像 B 的风格。

> 📖 **术语**：**Gram 矩阵（Gram matrix）**。一组向量两两内积组成的矩阵。在 NST 里，它把"特征图"压成"特征间相关性"，**抹掉空间位置、只保留统计共现**——这正是"风格"的关键：风格是"整体的质感与配色倾向"，不关心某个笔触具体落在画布哪一点。

### 纯 Rust 能做到哪、做不到哪（诚实边界）

真 NST 要跑起来，**必须有一个预训练好的 VGG**当那只"眼睛"。这就撞上了本书反复强调的边界：

> ⚠️ **注意（本章最重要的诚实边界）**：**纯 Rust 生态没有捆绑 VGG 权重**，真正的神经风格迁移需要**联网下载**几十上百 MB 的 VGG `.safetensors`。技术上完全可行——candle 官方 examples 里就有加载 VGG/风格迁移的实现，套路和 [第 42 章](../p08-classification/ch42-candle-classify.md) 加载 safetensors 一模一样：下权重 → `from_mmaped_safetensors` 加载 → 取中间层特征 → 按上面的损失优化生成图。但它**不满足本书"自包含、免联网、一键复现"的约束**，所以本章**不跑它、更不编造它的数字**。想上真 NST，路径就是「**candle + 下载 VGG 权重**」，请参考 candle 官方 `examples/neural-style-transfer`。

那自包含的 demo 演示点什么？——演示**"风格 = 统计量迁移"这个直觉的最简版本**。Gram 矩阵捕捉的是"颜色/纹理的统计共现"；我们退一步，只迁移最朴素的一种统计量——**颜色的均值和方差**，也就是经典的 **Reinhard 颜色迁移**。它对每个通道做一次"对齐"：

\\[ x_{\text{out}} = \frac{x - \mu_c}{\sigma_c}\ \sigma_r + \mu_r \\]

把内容图某通道**标准化**（减自己的均值 \\( \mu_c \\)、除自己的标准差 \\( \sigma_c \\)），再**套上参考图该通道的均值 \\( \mu_r \\) 与标准差 \\( \sigma_r \\)**。一句话：**让输出图的色彩统计，变得和参考图一样**。这就是"把参考图的色彩风格搬到内容图上"的最小可运行版本——**纯 Rust、零下载、确定性可复现**。

### 动手：颜色统计迁移

核心就三步——算统计、做迁移：

```rust
// 迁移：把 content 每个通道标准化后，套上 reference 的均值/标准差（Reinhard 式）
fn color_transfer(content: &[u8], cs: &[(f32, f32); 3], rs: &[(f32, f32); 3], n: usize) -> Vec<u8> {
    let mut out = vec![0u8; 3 * n];
    for i in 0..n {
        for c in 0..3 {
            let z = (content[i * 3 + c] as f32 - cs[c].0) / cs[c].1;   // 标准化
            out[i * 3 + c] = (z * rs[c].1 + rs[c].0).clamp(0.0, 255.0) as u8; // 套参考的均值/方差
        }
    }
    out
}
```

拿一张**冷色调**内容图（暗蓝渐变 + 两个亮块）和一张**暖色调**参考图（橙红渐变）跑一遍，打印每个通道迁移前后的（均值，标准差）：

```text
  通道         内容图(均值,标准差)     参考图(均值,标准差)     输出图(均值,标准差)
  R      51.7,  69.9          219.2,  11.5          218.4,  11.7
  G      94.1,  57.2          148.6,  34.7          148.2,  34.8
  B     177.4,  36.8           49.9,  11.6           49.4,  11.6
```

**输出图的每通道均值/标准差，都精确对齐了参考图**（218.4≈219.2、11.7≈11.5……零点几的差是 u8 量化误差）。对照图 `out_ch72_style.png`（内容 | 参考 | 迁移结果）里，你能看到**内容图的结构（两个方块、渐变布局）完整保留**，但**配色从冷蓝整体翻转成了暖橙**——参考图的"色彩风格"被搬了过来。

这当然不是真 NST（它只迁移了颜色统计、迁移不了笔触纹理），但它把那个最核心的直觉演示得明明白白：**所谓"风格"，很大程度上就是一堆可以被度量、被迁移的统计量**。从"迁移均值方差"升级到"迁移 Gram 矩阵"，再换上 VGG 深层特征，就是从这个 demo 通往真 NST 的完整阶梯。

## 常见坑与提示

> 🕳️ **坑**：**PSNR 比较必须公平。** 网络输出可能略微超出 \\( [0,1] \\)，双三次插值在锐边处也会**过冲（ringing）** 到 \\( [0,1] \\) 之外。算 PSNR 前**所有图都要先 `clamp(0,1)`**，否则谁没夹谁吃亏，比出来的高低是假的。本章对 SRCNN、DnCNN 输出都做了 `clamp`。

> ⚠️ **注意**：**PSNR 高 ≠ 人眼觉得好。** PSNR 只是逐像素 MSE 的换算，对"糊"很宽容、对"位置偏一点"很严厉。两张图 PSNR 一样，观感可能天差地别。工业界还会用 **SSIM**（结构相似度）等更贴近人眼的指标，前沿超分甚至专门优化"看起来真"而非 PSNR——这也是 [第 16 章](../p03-classic/ch16-threshold.md) 反复讲的"一个数字要问它怎么来的"。

> 🕳️ **坑**：**残差学习的加号别丢。** SRCNN/DnCNN 都是"网络学残差、再和输入相加/相减"。如果忘了那步 `x + &r`（或 `noisy - &resid`），网络就得从零学整张图，训练慢得多、也更容易学崩。残差连接是这类复原网络又快又稳的关键。

> 💡 **提示**：**训练噪声要贴近真实噪声。** 去噪网络"学的是它见过的噪声"。你若只用高斯噪声训练，拿去处理手机夜景的真实噪声（散粒噪声 + 压缩块）可能水土不服。务实做法：**用尽量接近目标场景的噪声模型来合成训练数据**，或直接用成对的真实"干净/含噪"图。

## 本章小结

- **超分辨率**：插值（双线性/双三次）只会抹平、补不出高频细节；**SRCNN + 残差学习**让网络专门去锐化。实测双线性 **15.23 dB** → SRCNN **29.93 dB**，+14.70。
- **去噪**：**高斯**压噪但糊边（本例 16.72，甚至低于不处理的 16.95）；**中值**保边更好（19.59）；**DnCNN**（学噪声、再相减）大幅领先（32.32）。经典方法胜在零训练、稳、可预测，**别无脑上学习式**。
- **风格迁移**：诚实边界——真 NST 需 candle + **下载 VGG 权重**（不满足自包含约束，故不跑、不编数字）。原理 = **内容损失（深层特征匹配）+ 风格损失（Gram 矩阵匹配）**；**Gram 矩阵**把特征压成"抹掉位置、只留共现"的相关性，正是"风格"的数学化身。
- 自包含 demo 用**纯 Rust 颜色统计（Reinhard）迁移**演示"风格 = 统计量迁移"：输出图每通道均值/方差精确对齐参考图，结构不变、配色翻转。
- **PSNR** 我们纯手写：\\( -10\log_{10}(\text{MSE}) \\)（值域 \\( [0,1] \\)）。比 PSNR 前务必统一 `clamp`；且 PSNR 高不等于人眼好。

## 动手练习

1. **换基线、换尺度**：把超分的插值基线换成双三次（可用 `image::imageops::resize` 的 `CatmullRom`，纯 Rust），再把放大倍数从 2× 提到 4×（HR=32、LR=8），看双三次基线和 SRCNN 的 PSNR 各掉多少、差距怎么变。
2. **给去噪加难度**：把去噪的噪声从均匀噪声换成**椒盐噪声**（随机把一些像素置 0 或 1），重训 DnCNN，并和中值滤波再比一次——你会看到中值对椒盐噪声特别在行，差距会缩小，体会"经典方法在对口场景下有多能打"。
3. **风格迁移进一步**：给颜色统计迁移**加一个强度系数** \\( \lambda \in [0,1] \\)，输出 = 内容原色 × (1−λ) + 迁移色 × λ，做出"风格化强度可调"的效果，存几张不同 λ 的图对比。
4. **想一想（也可动手）**：要在本书框架里跑**真 NST**，你需要哪几样东西？（提示：一个能下载的 VGG `.safetensors`、[第 42 章](../p08-classification/ch42-candle-classify.md) 的加载套路、取 VGG 中间层特征的方法、以及把"生成图"本身设成可训练 `Var` 来优化。）列出步骤，就是你把这章的 demo 升级成真 NST 的施工图。
