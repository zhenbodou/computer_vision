# 第 71 章 扩散模型（Stable Diffusion 推理）

> **本章导读**

## 场景：能不能"逆转"墨水的扩散？

[第 70 章](ch70-gan.md) 的 GAN 靠"对抗"逼出锐利，但训练不稳、还爱模式崩溃。扩散模型换了一条完全不同、却出奇稳健的思路。

滴一滴墨水进清水，它会自发扩散、直到均匀——这是物理必然，不用"学"。**如果能训练一个网络，让它把这个过程逆转一小步——从"稍微扩散一点"的状态，猜回"扩散之前"的状态——那么把这一小步重复很多次，不就能从一杯均匀的脏水，倒推回最初那一滴墨水了吗？**

扩散模型正是这么干的：**前向**，往数据里一点点加高斯噪声，几十步后数据彻底变成纯雪花（这步是固定的数学操作，无需学习）；**反向**，训练一个网络学会"每一步该去掉多少噪声"，于是从一团随机雪花出发，一步步去噪，最终"采样"出一个全新的、像真数据的样本。它就是今天 **Stable Diffusion、Midjourney** 背后的引擎。

> 📖 **术语**：**DDPM（去噪扩散概率模型，Denoising Diffusion Probabilistic Model）**。2020 年 Ho 等人提出的扩散模型经典形式。**前向过程**把数据 \\( x_0 \\) 逐步加噪成 \\( x_1, x_2, \dots, x_T \\)（\\( x_T \\) 近似纯高斯噪声）；**反向过程**用神经网络从 \\( x_T \\) 一步步去噪回 \\( x_0 \\)。训练目标简单得惊人：**让网络预测每一步加进去的噪声**。

## 原理：加噪、调度、去噪

### 前向扩散：一条加噪的马尔可夫链

前向过程每一步给样本掺一点高斯噪声，噪声量由**噪声调度**里的 \\( \beta_t \\) 控制（\\( \beta_t \\) 随 \\( t \\) 增大）。神奇的是，"从 \\( x_0 \\) 直接跳到任意第 \\( t \\) 步"有**闭式解**，不用真的一步步加：

\\[ x_t = \sqrt{\bar\alpha_t}\ x_0 + \sqrt{1-\bar\alpha_t}\ \varepsilon, \qquad \varepsilon \sim \mathcal{N}(0, I) \\]

其中 \\( \alpha_t = 1 - \beta_t \\)，\\( \bar\alpha_t = \prod_{s=1}^{t}\alpha_s \\) 是"累积保留的信号比例"。\\( t \\) 越大，\\( \bar\alpha_t \\) 越小，信号越弱、噪声越强。当 \\( \bar\alpha_T \to 0 \\)，\\( x_T \\) 就基本是纯噪声了。

> 🕳️ **坑**：**步数少时，\\( \beta \\) 要够大，才能把数据噪声"干净"。** 教科书的 DDPM 用 \\( T=1000 \\)、\\( \beta \\) 只到 0.02。可玩具里我们想要 \\( T \\) 小（跑得快），就必须把 \\( \beta \\) 调大，否则末步还残留信号、反向没法从纯噪声起步。本章用 \\( T=100 \\)、\\( \beta \\) 从 `1e-4` 线性升到 `0.10`，实测 **\\( \sqrt{\bar\alpha_T} = 0.075 \\)**（末步信号只剩 7.5%，已近纯噪声）。这个数一定要**打印出来核对**。

### 反向去噪：为什么是"预测噪声"

反向要从 \\( x_t \\) 猜回 \\( x_{t-1} \\)。DDPM 的关键选择是：**不直接预测 \\( x_{t-1} \\) 或 \\( x_0 \\)，而是预测"当初加进去的那团噪声 \\( \varepsilon \\)"**。为什么？因为由前向闭式解，只要知道了 \\( \varepsilon \\)，就能反推 \\( x_0 \\)，三者等价；但"预测噪声"这个目标**尺度稳定**（\\( \varepsilon \\) 永远是标准正态、量纲一致），网络最好训，损失就是最朴素的 **MSE**：

\\[ L = \mathbb{E}_{x_0,\ t,\ \varepsilon}\big[\ \lVert \varepsilon - \varepsilon_\theta(x_t, t) \rVert^2\ \big] \\]

训练一个 batch 只需三步：随机取 \\( x_0 \\)、随机取时间步 \\( t \\)、随机采噪声 \\( \varepsilon \\) 拼出 \\( x_t \\)，让网络 \\( \varepsilon_\theta \\) 预测 \\( \varepsilon \\)，算 MSE。训练好后，用**反向采样公式**从 \\( x_T \\) 一步步走回来：

\\[ \mu_\theta(x_t, t) = \frac{1}{\sqrt{\alpha_t}}\left(x_t - \frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\ \varepsilon_\theta(x_t, t)\right) \\]

每步取 \\( x_{t-1} = \mu_\theta + \sqrt{\beta_t}\ z \\)（\\( z \\) 是新采的高斯噪声，最后一步不再加）。这点**注入的随机性**让采样能探索到分布的各个角落——这正是扩散**不易模式崩溃**的一个原因。

> 📖 **术语**：扩散 vs **VAE**（[第 69 章](ch69-autoencoder.md)）vs **GAN**（[第 70 章](ch70-gan.md)）。三者都能生成，路数不同：**VAE** 一步编码-解码，训练稳但重建偏糊；**GAN** 一步生成，够锐利但训练不稳、爱模式崩溃；**扩散**把生成拆成**几十上百个小步**，每步只干"去一点噪"这件容易的事——**训练稳如 VAE，样本质量和覆盖度却更好**。代价是采样慢（要跑很多步）。

## 动手：极小 DDPM 在 9 个高斯团上采样

> ⚠️ **注意**：本章代码基于 **candle 0.11.0**，纯 CPU。完整独立工程见 `code/dl_labs/ch71_diffusion/`，**`cd` 进去 `cargo run --release`** 一键复现。`Lcg` 与 `det_init` 沿用 [第 69 章](ch69-autoencoder.md)（candle 0.11 的 CPU 后端不能 `set_seed`）。

**数据**：2D 平面上 **9 个高斯团**排成 3×3 网格（间距 1.6、每团标准差 0.14），再标准化到零均值、单位方差。选**多模态**分布是故意的——正好检验扩散会不会像 GAN 那样崩模式。

**噪声调度**：预先算好 \\( \beta_t, \alpha_t, \bar\alpha_t \\) 三个数组：

```rust
fn make_schedule(beta_t: f32) -> Schedule {
    let mut beta = vec![0f32; T];
    for t in 0..T { beta[t] = 1e-4 + (beta_t - 1e-4) * t as f32 / (T - 1) as f32; } // 线性 β
    let alpha: Vec<f32> = beta.iter().map(|b| 1.0 - b).collect();
    let mut abar = vec![0f32; T];
    let mut acc = 1.0;
    for t in 0..T { acc *= alpha[t]; abar[t] = acc; }   // ᾱ_t = ∏ α
    Schedule { beta, alpha, abar }
}
```

**噪声预测网络**：一个小 MLP，输入是"带噪样本 \\( x_t \\) + 时间步 \\( t \\) 的嵌入"，输出预测的噪声 \\( \varepsilon \\)（2 维）。这里有两个关键编码技巧：

```rust
// 把「带噪样本 x_t + 时间步 t」编码成网络输入
fn encode(x: &[f32], t_norm: f32) -> Vec<f32> {
    let mut f = Vec::with_capacity(IN);
    for d in 0..DIM { f.push(x[d]); }                       // 原始坐标
    for d in 0..DIM {                                        // 坐标的 Fourier 特征（破谱偏置）
        for &fr in &SP_FREQ { f.push((fr*x[d]).sin()); f.push((fr*x[d]).cos()); }
    }
    f.extend_from_slice(&time_emb(t_norm));                  // 时间步的正弦嵌入
    f
}
```

> 🕳️ **坑**：**MLP 有"谱偏置"，别让模式靠"角度"区分。** 我最初把 9 个模式排成**圆环**（都在同一半径、只能靠角度分辨），结果无论怎么训、怎么加 Fourier 频率，DDPM 都**只覆盖一半模式**（隔一个丢一个）——因为普通 MLP 天生偏爱低频函数，学不好"高角频率"的环形结构。换成**网格**排布（模式靠坐标的正负直接区分，是低频结构），一下就**全覆盖**了。给坐标额外加一组 **Fourier 特征**（sin/cos 多频率）也是缓解谱偏置的通用手段。这是个真实、值得记住的教训：**数据的几何结构和网络的归纳偏置要对得上。**

**训练**：每步组装一个 batch（随机 \\( x_0 \\)、随机 \\( t \\)、随机 \\( \varepsilon \\) → 前向加噪 → 预测 → MSE）：

```rust
let (sqrt_ab, sqrt_1mab) = (sch.abar[t].sqrt(), (1.0 - sch.abar[t]).sqrt());
for d in 0..DIM {
    let eps = trng.randn();
    xt[d] = sqrt_ab * train[i*DIM+d] + sqrt_1mab * eps; // 前向加噪 x_t = √ᾱ·x0 + √(1-ᾱ)·ε
    tgt.push(eps);                                       // 目标就是这团噪声
}
// ... 攒满一个 batch 后：
let loss = (&net.forward(&it)? - &tt)?.sqr()?.mean_all()?; // MSE(预测噪声, 真实噪声)
opt.backward_step(&loss)?;
```

跑 25000 步，损失稳步下降：

```text
step     1  MSE(ε̂, ε) = 0.9945
step  5000  MSE(ε̂, ε) = 0.3555
step 12000  MSE(ε̂, ε) = 0.2675
step 25000  MSE(ε̂, ε) = 0.2892
```

> ⚠️ **注意**：**扩散的损失也不会降到 0，别指望。** 在高噪声步（\\( x_t \\) 几乎是纯雪花），当初那团噪声 \\( \varepsilon \\) 本就**无从预测**，MSE 天然有下界；把所有步平均下来，loss 收敛到 **0.28 附近**就已训好。判断好坏依旧要看**采样出来的分布**，而不是 loss 数值本身——这一点和 [第 70 章](ch70-gan.md) 的 GAN 一脉相承。

**反向采样**：从纯噪声 \\( x_T \sim \mathcal{N}(0,I) \\) 出发，按公式一步步去噪：

```rust
let eps = net.forward(&it)?.to_vec2::<f32>()?;   // 预测这一步的噪声
let inv_sqrt_a = 1.0 / a.sqrt();
let coef = b / (1.0 - ab).sqrt();
for i in 0..m { for d in 0..DIM {
    let mean = inv_sqrt_a * (x[i*DIM+d] - coef * eps[i][d]); // μ = 1/√α·(x_t - β/√(1-ᾱ)·ε̂)
    x[i*DIM+d] = if t > 0 { mean + b.sqrt() * rng.randn() } else { mean }; // t>0 再注入噪声
}}
```

### 采样结果：分布匹配的真实数字

对采样出的 1500 个点，和目标分布逐项对比：

```text
均值   目标=(0.00,0.00)  生成=(0.02,0.01)
模式覆盖：目标 9/9   生成 9/9
各模式命中计数：目标 [178×9]   生成 [162,193,152,144,167,168,164,176,172]
落在目标流形附近(距最近真实点 < 0.041)的生成样本比例 = 88.0%
```

**三条硬证据**：① 生成分布的**均值 (0.02, 0.01)** 精准对齐目标原点；② **9 个模式全部覆盖（9/9）**，而且各模式的样本数（144~193）相当**均衡**——对照 [第 70 章](ch70-gan.md) 无条件 GAN "6 个模式只画 1 个"的惨状，扩散模型**天然不模式崩溃**，这是它相比 GAN 的一大优势；③ **88.0%** 的生成点落在离某个真实点很近（< 0.041）的地方，即绝大多数样本都稳稳落在目标流形上。

存下的采样轨迹图 `out_ch71_trajectory.png`（从左到右是反向过程的快照 \\( t = 100, 40, 20, 8, 0 \\)）里，你能看到一团弥散的高斯噪声云，如何在最后二三十步里**突然"结晶"**成整齐的 3×3 点阵——生成的结构总是在去噪的**末段**才浮现，这也是扩散采样的典型现象。对照图 `out_ch71_compare.png`（左=目标、右=生成）里，两个 3×3 网格几乎重合。

## 诚实的 Stable Diffusion 边界

本章的玩具 DDPM 把**核心机制**（前向加噪、噪声调度、预测 \\( \varepsilon \\)、反向采样）跑通了，但真实的 **Stable Diffusion（SD）** 比它多了整整几层，纯 Rust + CPU **一键 demo 跑不动**。诚实地说清差在哪：

- **潜空间扩散（Latent Diffusion）**：SD 不在像素上扩散，而是先用一个 **VAE**（[第 69 章](ch69-autoencoder.md) 的近亲）把 512×512 图像压进一个小得多的潜空间（如 64×64），在**潜空间**里做扩散，最后再解码回像素。这让计算量降了一两个数量级——但你得先有一个训练好的 VAE。
- **文本条件 + 交叉注意力**：SD 是"**按文字生成**"。它用 **CLIP**（[第 73 章](ch73-clip-vlm.md) 的主角）把提示词编码成向量，再通过 **交叉注意力（cross-attention）** 把文本信息注入去噪网络的每一层——这正是本章玩具**完全没有**的部分（我们只做了无条件生成）。
- **巨型 U-Net**：SD 的去噪网络不是我们这个几层 MLP，而是带残差块、自注意力、时间嵌入的**大型 U-Net**，参数近 10 亿。
- **classifier-free guidance（CFG）**：采样时同时算"有文本条件"和"无条件"两个预测，按一个引导系数放大二者之差，让生成更贴合提示词。

> 📖 **术语 / 真实路线**：想在 Rust 里跑**真正的** Stable Diffusion，**candle 官方就带一个 `stable-diffusion` example**（`candle-examples` 仓库里），纯 Rust 实现了上述 VAE + CLIP + U-Net + 调度器全套。但它**必须联网下载数 GB 的预训练权重**（SD 1.5 / SDXL 等），且 CPU 上生成一张图要好几分钟。本书坚持"自包含、免联网、一键复现"，所以**不在正文跑它、也绝不编造它的数字**；有兴趣、且带 GPU 的读者，可按 candle 官方文档下载权重亲自体验——你会发现，它每一步做的，仍是本章这套"预测噪声、反向去噪"，只是规模大了千万倍。

## 常见坑与提示

> 🕳️ **坑**：**\\( \sqrt{\bar\alpha_T} \\) 一定要接近 0。** 若末步还残留信号，反向就没法从"纯噪声"这个已知起点出发，采样会跑偏。步数 \\( T \\) 小就把 \\( \beta_T \\) 调大，并**打印 \\( \sqrt{\bar\alpha_T} \\) 核对**（本章 0.075）。

> 💡 **提示**：**预测噪声、用 MSE，不要用 BCE。** 扩散的回归目标是标准正态噪声、值域覆盖正负，天生适合 MSE（`(pred - eps).sqr().mean_all()`）；[第 70 章](ch70-gan.md) 那个数值不稳定的 BCE 是给"真/假二分类"的，别混用。

> 💡 **提示**：**采样慢是扩散的原生短板。** 本章每采一批要跑 \\( T=100 \\) 步网络前向。真实 SD 动辄 20~50 步（用 DDIM、DPM-Solver 等**加速采样器**把上千步压到几十步），这也是扩散领域的重要研究方向。想更快，可试着减小 \\( T \\) 或实现 DDIM 采样。

> ⚠️ **注意**：**别被玩具的"完美"冲昏头。** 9 个高斯团区分度极大，DDPM 轻松 9/9。真实图像分布复杂无数倍，需要大 U-Net、海量数据、上千步调度。这里验证的是**机制正确、思路可复现**，不是"扩散很简单"。

## 本章小结

- **扩散模型 = 前向加噪（固定、无需学）+ 反向去噪（训网络预测噪声 \\( \varepsilon \\)）**。前向有闭式解 \\( x_t = \sqrt{\bar\alpha_t}\ x_0 + \sqrt{1-\bar\alpha_t}\ \varepsilon \\)；训练目标是最朴素的 **MSE**。
- **噪声调度** \\( \beta/\alpha/\bar\alpha \\) 决定加噪节奏；步数少就得把 \\( \beta \\) 调大，保证 **\\( \sqrt{\bar\alpha_T}\approx 0 \\)**（本章 0.075）。
- 我们的极小 DDPM 在 9 个高斯团上：loss **0.99→0.28**，采样均值对齐目标、**9/9 模式全覆盖且均衡**、**88.0%** 样本落在流形上——**天然不模式崩溃**，胜过 [第 70 章](ch70-gan.md) 的无条件 GAN。
- **谱偏置**是真实教训：模式靠角度区分（圆环）时 MLP 只学到一半，靠坐标区分（网格）+ Fourier 特征就全覆盖。**数据几何要配网络归纳偏置。**
- **诚实边界**：真实 Stable Diffusion = 潜空间扩散 + CLIP 文本条件 + 交叉注意力 + 巨型 U-Net + CFG，权重数 GB；candle 有官方 example 但需下载权重、CPU 极慢。本章只演示核心机制，不跑 SD、不编 SD 的数字。

## 动手练习

1. **调噪声调度**：把 \\( \beta_T \\) 从 0.10 改成 0.02、0.30，各跑一遍，打印 \\( \sqrt{\bar\alpha_T} \\) 并观察采样质量——体会"末步没噪干净"或"加噪太猛"分别怎么坏事。
2. **复现"谱偏置翻车"**：把 9 个网格模式改回**圆环**排布（都在同一半径），看模式覆盖如何从 9/9 掉到只覆盖一半，亲历本章最硬的那个坑。
3. **实现 DDIM 加速采样**：查阅 DDIM 的确定性采样公式，把采样步数从 100 压到 10~20，比较速度与分布匹配度的取舍。
4. **想一想**：本章是**无条件**生成（随机吐一个模式）。若想"指定生成第 3 个模式"，该怎么把类别信息喂进去？（提示：回顾 [第 70 章](ch70-gan.md) 的条件 GAN，扩散里对应的就是 SD 的"文本条件"那一路。）
