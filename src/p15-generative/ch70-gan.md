# 第 70 章 生成对抗网络 GAN

> **本章导读**
> - 学完你能：用 **candle**（0.11.0）亲手搭一个**小 GAN**——生成器把随机噪声变成小图，判别器判它真假，两者在"造假 vs 验假"里互相较劲，全程只用**数值稳定 BCE**、纯 CPU 可跑。
> - 你会看到三件真事：① **朴素训练很不稳**（判别器损失一度跌到 **0.069**、生成样本忽好忽坏）；② 加了稳定技巧后训练**平稳、单个模式画得很清晰**（精度距离 **0.551**，逼近真实样本的 **0.326**），可它翻来覆去**只画 6 个模式里的 1 个**——这就是**模式崩溃**；③ 换成**条件 GAN**，6 个模式**全覆盖**（覆盖 **6/6**，"召回距离"从 **7.59** 一路降到 **0.67**）。
> - 搞懂贯穿生成模型的核心：**对抗博弈（min-max）、交替更新、模式崩溃、纳什均衡**，以及**标签平滑、平衡更新步数、学习率、条件化**这些稳定与救场技巧。
> - 代码在本机 `cargo run --release` 实测通过，正文所有数字都是真实运行结果、可复现。

## 场景：让"糊"的生成变"真"

[第 69 章](ch69-autoencoder.md) 的自编码器能从一个低维向量"造"出图，可重建总是**偏糊**——因为 MSE 损失鼓励网络在拿不准时"取平均、抹一层灰"。要生成**锐利、以假乱真**的图，得换个思路。

想象一个造假币的团伙和一名验钞警察：造假者（**生成器 generator**）不停印假钞，警察（**判别器 discriminator**）不停学着识别真假。警察越练越毒，逼得造假者不得不把假钞做得越来越像真的——直到警察也分不出来。**GAN（生成对抗网络，Generative Adversarial Network）** 就是把这场猫鼠游戏搬进神经网络：不再用"和目标图逐像素比"的 MSE，而是让一个**会进化的判别器**来定义"像不像真"，逼生成器造出连它都挑不出毛病的样本。

> 📖 **术语**：**生成对抗网络（GAN）**。两个网络对抗训练：**生成器 \\( G \\)** 把随机噪声（隐向量 \\( z \\)）映射成一张图，目标是骗过判别器；**判别器 \\( D \\)** 吃一张图、输出"它是真样本的概率"，目标是别被骗。二者此消彼长，最终把彼此逼成高手。2014 年由 Goodfellow 等人提出，是扩散模型崛起前最主流的生成范式。

## 原理：一场 min-max 博弈

### 目标函数

判别器想让"真判真、假判假"的概率都高；生成器想让"假被判成真"。写成一个**二人零和博弈**：

\\[ \min_G \max_D \; V(D,G) = \mathbb{E}_{x\sim p_{\text{data}}}\big[\log D(x)\big] + \mathbb{E}_{z\sim p_z}\big[\log\big(1 - D(G(z))\big)\big] \\]

\\( D \\) 想把这个式子**放大**（真样本 \\( D(x)\to 1 \\)、假样本 \\( D(G(z))\to 0 \\)）；\\( G \\) 想把它**缩小**（让 \\( D(G(z))\to 1 \\)）。理论上的最优点是**纳什均衡**：\\( G \\) 造出的分布和真实分布一模一样，\\( D \\) 只能瞎猜、输出 \\( 0.5 \\)。

> 💡 **提示**：**GAN 的损失不会一路降到 0**，这和你在 [第 40 章](../p07-dl-basics/ch40-burn-train.md) 见过的分类训练**完全不同**。均衡时判别器"两头为难"，它那个由两项 BCE 相加的损失会**稳定在 \\( 2\ln 2 \approx 1.386 \\) 附近**（我们的条件 GAN 实验实测 \\( D\_\text{loss}\approx 1.38 \\)，正是这个值）。所以**别拿"损失降到 0"当成功标志**——那反而说明一方碾压了另一方。判断 GAN 好不好，要看**生成样本的质量与多样性**。

### 交替更新与数值稳定 BCE

训练就是**交替**做两件事：先固定 \\( G \\) 更新 \\( D \\)（真判真、假判假），再固定 \\( D \\) 更新 \\( G \\)（让假被判成真）。两边的损失本质都是**二分类交叉熵（BCE）**，作用在判别器输出的原始 logit 上。

> 🕳️ **坑**：**别用 candle 的 `binary_cross_entropy_with_logit`**——它是 `sigmoid(x).log()` 的直译，logit 一大就 `log(0)→NaN`（[第 44 章](../p08-classification/ch44-finegrained.md) 已踩过）。GAN 里 logit 动辄很大，几乎必崩。**自己写数值稳定版**：

\\[ \text{BCE}(x, y) = \max(x, 0) - x y + \log\big(1 + e^{-|x|}\big) \\]

其中 \\( x \\) 是判别器输出的 logit，\\( y \\) 是目标（\\( 1 \\)=真、\\( 0 \\)=假）。这个式子和"先 sigmoid 再取对数"数学等价，但**永不溢出**。翻译成 candle：

```rust
// 数值稳定 BCE-with-logits：L = mean( relu(x) - x*y + log(1+exp(-|x|)) )
fn bce(logits: &Tensor, y: f64) -> Result<Tensor> {
    let relu_x = logits.relu()?;                 // max(x,0)
    let xy = logits.affine(y, 0.0)?;             // x * y（affine = mul*x+add）
    let e = logits.abs()?.neg()?.exp()?;         // exp(-|x|)
    let sp = (&e + 1.0)?.log()?;                 // log(1+exp(-|x|))
    (&(&relu_x - &xy)? + &sp)?.mean_all()
}
```

### 模式崩溃：GAN 最出名的翻车

真实分布往往有**多个模式（mode）**（比如"竖条"和"横条"是不同的模式）。GAN 有个臭名昭著的失败：**模式崩溃（mode collapse）**——生成器发现"只要死磕某一个能骗过判别器的样本"就能拿高分，于是**无论输入什么噪声都吐出几乎一样的图**，把其他模式全丢了。它的样本可能**很逼真，却毫无多样性**。

怎么用数字**抓住**模式崩溃？我们借一对"Chamfer 式"距离：

- **精度距离**：每个**生成**样本到**最近真实**样本的平均距离——衡量"生成得像不像真"（越小越像）。
- **召回距离**：每个**真实**样本到**最近生成**样本的平均距离——衡量"真实分布被覆盖得全不全"（越小越全）。

模式崩溃的指纹极清晰：**精度距离很小**（造的那一个模式很逼真），**召回距离却很大**（其余模式压根没被生成，真实样本找不到近邻）。下面的实验会亲眼看到这一幕。

## 动手：小 GAN 在 6 个模式上的对抗训练

> ⚠️ **注意**：本章代码基于 **candle 0.11.0**，纯 CPU。完整独立工程见 `code/dl_labs/ch70_gan/`，**`cd` 进去 `cargo run --release`** 一键复现。`Cargo.toml` 依赖 `candle-core`、`candle-nn`、`image`，并加一行空的 `[workspace]` 让它独立于主工程。随机数发生器 `Lcg` 与确定性初始化 `det_init` 沿用 [第 69 章](ch69-autoencoder.md)（candle 0.11 的 CPU 后端不能 `set_seed`）。

**数据**：16×16 灰度小图，真实分布有 **6 个离散模式**——3 根竖条（列位置 2/7/12）+ 3 根横条（行位置 2/7/12），各加一点微噪。模式彼此不重叠，方便量化"生成覆盖了几个模式"。实测真实样本到自己那根干净模板的平均距离是 **0.326**（这是"清晰"的上限参照）。

**网络**：为了把对抗机制看得最清，生成器、判别器都用最朴素的全连接 MLP（隐向量 16 维 → 图 256 维；图 256 维 → 1 个 logit）：

```rust
// 生成器 G：[z(16)+标签(6)] → 128 → 128 → 256，末层 sigmoid 到 [0,1]
fn forward(&self, z: &Tensor, lbl: &Tensor) -> Result<Tensor> {
    let x = Tensor::cat(&[z, lbl], 1)?;         // 拼接隐向量与标签（非条件实验里 lbl 全 0）
    let h = self.fc1.forward(&x)?.relu()?;
    let h = self.fc2.forward(&h)?.relu()?;
    candle_nn::ops::sigmoid(&self.fc3.forward(&h)?)
}
// 判别器 D：[图(256)+标签(6)] → 128 → 1 个 logit（不加 sigmoid，交给稳定 BCE）
fn forward(&self, x: &Tensor, lbl: &Tensor) -> Result<Tensor> {
    let x = Tensor::cat(&[x, lbl], 1)?;
    let h = self.fc1.forward(&x)?.relu()?;
    self.fc2.forward(&h)
}
```

**训练循环**就是"先更新 D、再更新 G"的交替，两边共用上面的稳定 BCE：

```rust
// === 更新判别器 D：真判真(目标=real_label)、假判假(目标=0) ===
let fake = gen.forward(&z, &fake_lbl)?.detach(); // detach：更新 D 时把生成图当固定输入
let d_loss = (&bce(&disc.forward(&real, &real_lbl)?, real_label)?
            + &bce(&disc.forward(&fake, &fake_lbl)?, 0.0)?)?;
d_opt.backward_step(&d_loss)?;                   // 只更新 D（优化器只持有 D 的参数）

// === 更新生成器 G：让 D 把生成图判成"真"(目标=1) ===
let g_loss = bce(&disc.forward(&gen.forward(&z2, &fl)?, &fl)?, 1.0)?;
g_opt.backward_step(&g_loss)?;                   // 只更新 G
```

> 💡 **提示**：\\( G \\) 与 \\( D \\) 各配一个 `AdamW` 优化器、各持有自己的参数。更新 \\( D \\) 时对生成图 `.detach()`，把它当成"固定的假数据"，梯度不回传到 \\( G \\)；更新 \\( G \\) 时则让梯度穿过 \\( D \\) 传回 \\( G \\)。谁的优化器被调用，才更新谁——这是 candle 里隔离两个网络的干净做法。

我们跑**三组对照实验**，把"稳定技巧"的作用一次看透。

### 实验 A：朴素训练——不稳定

配置：\\( D \\) 与 \\( G \\) 每轮各更新 1 次、学习率都是 `2e-4`、判别器真样本目标用 `1.0`。真实输出（节选）：

```text
[naive] step  1000  D_loss=0.557  G_loss=1.747  | 平均最近距离=1.742  模式覆盖=1/6
[naive] step  5000  D_loss=0.069  G_loss=3.661  | 平均最近距离=2.815  模式覆盖=1/6
[naive] step  7000  D_loss=0.132  G_loss=2.594  | 平均最近距离=4.463  模式覆盖=0/6
[naive] step 10000  D_loss=0.402  G_loss=1.918  | 平均最近距离=1.609  模式覆盖=1/6
最终 Chamfer：精度距离=1.540  召回距离=7.547
```

**判别器损失一度跌到 0.069**——它把生成器碾压了，生成器拿不到有用梯度，样本质量随之**忽好忽坏**（平均最近距离在 1.6 到 4.5 之间反复横跳）。这就是"训练不稳定"的真实模样。

### 实验 B：稳定技巧——稳了、清晰了，却还是崩

只改三个旋钮：**生成器每轮多更新 1 步**（G 走 2 步、D 走 1 步，别让 D 太强）、**判别器学习率减半**（`1e-4`）、**标签平滑**（真样本目标用 `0.9` 而非 `1.0`，抑制判别器过度自信）：

```text
[stable] step  1000  D_loss=0.789  G_loss=1.091  | 平均最近距离=6.454  模式覆盖=0/6
[stable] step  6000  D_loss=0.765  G_loss=2.075  | 平均最近距离=0.630  模式覆盖=1/6
[stable] step 10000  D_loss=0.705  G_loss=2.009  | 平均最近距离=0.575  模式覆盖=1/6
最终 Chamfer：精度距离=0.551  召回距离=7.591
```

判别器损失稳稳待在 **0.7 左右**（不再崩），生成样本越来越**清晰**——**精度距离 0.551，已经逼近真实样本自己的 0.326**。存下来的演化网格 `out_ch70_stable_progress.png`（每行一个训练阶段、6 列是同一批固定噪声）里，最后一行 6 列**是一模一样的一根清晰竖条**。

**问题来了：模式覆盖始终是 1/6，召回距离高达 7.591。** 稳定技巧让训练变稳、把那**一个**模式画得很漂亮，却治不了模式崩溃——生成器只会画 6 个模式里的 1 个。**这正是模式崩溃的数字指纹：精度距离小（0.551，那一个很逼真）、召回距离大（7.591，其余 5 个模式一片空白）。**

### 实验 C：条件 GAN——6 个模式全覆盖

治本的办法之一是**条件化（conditional GAN, cGAN）**：把"要画哪个模式"的**类别标签**（one-hot）同时喂给 \\( G \\) 和 \\( D \\)。这样 \\( D \\) 判的不再是"像不像真图"，而是"**这张图配不配得上这个标签**"；\\( G \\) 想骗过它，就必须**按标签**画出对应模式。每个标签"认领"一个模式，生成器**无从崩溃**：

```text
[cgan] step  1000  D_loss=1.319  G_loss=0.850  | 平均最近距离=2.111  模式覆盖=6/6
[cgan] step 10000  D_loss=1.381  G_loss=0.796  | 平均最近距离=0.662  模式覆盖=6/6
最终 Chamfer：精度距离=0.643  召回距离=0.672
```

从 1000 步起就**覆盖全部 6/6 模式**，判别器损失稳定在 **1.38**（正是前面说的 \\( 2\ln 2 \\) 均衡值——它真的分不出真假了）。最关键的是**召回距离从 7.59 暴跌到 0.67**，和精度距离（0.643）**双双很小且相当**——生成得既逼真、又覆盖全。对照图 `out_ch70_cgan_modes.png`（上行=6 个真实模式，下行=各模式对应的生成样本）里，3 根竖条、3 根横条**位置全对**。

> 💡 **提示**：一个实现细节值得一提——我们把 one-hot 标签的"1"放大成了 **5.0**。因为标签只有 6 维，混在 256 维图像里很容易被判别器**忽略**；放大幅度让这 6 维信号"喊得够响"，条件化才真正生效（不放大时实测 cGAN 依旧崩到 1/6）。

**三个实验一张表看清**：

| 实验 | 训练稳定性 | 精度距离↓ | 召回距离↓ | 模式覆盖 |
|------|-----------|-----------|-----------|---------|
| A 朴素 | 差（D_loss 跌到 0.069） | 1.540 | 7.547 | 1/6 |
| B 稳定技巧 | 好（D_loss≈0.7） | **0.551** | 7.591 | 1/6（仍崩） |
| C 条件 GAN | 好（D_loss≈1.38） | 0.643 | **0.672** | **6/6** |

**结论**：标签平滑、平衡步数、调学习率这些技巧能让训练**变稳、把单个样本画清晰**，但**治不了模式崩溃**；要覆盖全部模式，得上**条件化**（或后面提到的更强手段）。

## 常见坑与提示

> 🕳️ **坑**：**判别器太强，生成器就废了。** 实验 A 里 D_loss 跌到 0.069，意味着判别器几乎百分百识破假图，此时 \\( \log(1-D(G(z))) \\) 的梯度趋近于 0，生成器"学不动"。对策就是实验 B 的组合：**给 G 多走几步、给 D 降学习率、标签平滑**——核心是**别让任何一方碾压另一方**，把博弈维持在势均力敌。

> ⚠️ **注意**：**GAN 的损失曲线不能当"进度条"看。** 它天生震荡、不收敛到 0；均衡时判别器损失反而稳在 \\( 2\ln 2 \\)。要判断训练好坏，得另设**样本质量指标**（本章用了"到最近模式的距离"和 Chamfer 精度/召回），光盯 loss 会被误导。

> 🕳️ **坑**：**模式崩溃是常态，不是意外。** 无条件 GAN 在多模式数据上极易崩。除了本章的**条件化**，工业界常用的救场手段还有：**minibatch discrimination / minibatch-std**（让 D 能"看见"一批样本多不多样，逼 G 增加多样性）、**WGAN-GP**（换 Wasserstein 距离 + 梯度惩罚，梯度更平滑）、**unrolled GAN**、**谱归一化**等。它们思路各异，但都在回答同一个问题：怎么不让生成器躲进"一个万金油样本"里。

> 📖 **术语 / 诚实边界**：本章是**核心机制的最小演示**。真实的高保真 GAN（如 **StyleGAN**）是几千万到上亿参数的大卷积网络，靠海量图片、多 GPU 训数天，还叠了渐进式增长、自适应判别器增强、风格调制等一大堆工程。**纯 Rust + CPU 跑不动那个量级**——但你在这 16×16 玩具上看懂的对抗博弈、模式崩溃、稳定技巧，正是它们的地基，一分没少。

## 本章小结

- **GAN = 生成器（造假）+ 判别器（验假）的 min-max 博弈**：交替更新，最优点是"以假乱真、\\( D \\) 只能瞎猜"的纳什均衡（判别器损失稳定在 \\( 2\ln 2\approx 1.386 \\)，而非 0）。
- 两边损失都用**自写的数值稳定 BCE** `max(x,0)-xy+log(1+exp(-|x|))`，**别用** candle 自带的 `binary_cross_entropy_with_logit`（会 NaN）。
- **模式崩溃**是 GAN 的招牌翻车：生成器只产出少数几个模式。数字指纹=**精度距离小、召回距离大**。我们的稳定实验实测精度 0.551、召回 7.591、覆盖 1/6。
- **稳定技巧**（标签平滑、平衡更新步数、降 D 学习率）让训练**变稳、样本变清晰**，但**治不了模式崩溃**；**条件 GAN** 把类别标签喂给 G/D，实测覆盖 **6/6**、召回距离降到 **0.67**。
- 真实大 GAN 体量巨大、纯 CPU 跑不动，但核心机制就是本章这一套。

## 动手练习

1. **亲手制造模式崩溃**：把实验 C 的条件标签关掉（`conditional: false`）、其余不变，看覆盖率如何从 6/6 掉回 1/6，并对照 `out_ch70_*_progress.png` 观察"同一批噪声吐出同一张图"的崩溃现场。
2. **学习率的威力**：把实验 A 的判别器学习率从 `2e-4` 调到 `5e-4`、再调到 `5e-5`，各跑一遍，记录 D_loss 最低跌到多少、样本质量怎么变——体会"势均力敌"为什么重要。
3. **实现 minibatch-std**：给判别器加一个"批内多样性"特征（算这一批样本每个隐藏特征的标准差、拼到特征后面），看它能不能在**无条件**情况下缓解模式崩溃（提示：这是 ProGAN/StyleGAN 的标准做法，但在这种小图上未必稳，正好体会"救场技巧也挑场景"）。
