## 从"看见"到"看懂"

先看两个你天天都在用、却可能没意识到的例子。

**例子一：手机相册。** 你从没手动整理过，可相册却能自动把照片分成"人像""风景""美食""截图"，还能搜"狗"就把所有有狗的照片翻出来。

**例子二：停车场道闸。** 车开到闸口前，摄像头"扫一眼"车牌，几秒钟后杆子自动抬起，还准确记下了你的车牌号。

这两件事背后是同一门手艺：**让计算机从图像或视频里，自动读出有用的信息，并据此做出判断。** 这就是**机器视觉（Machine Vision）**，学术界更常叫它**计算机视觉（Computer Vision，简称 CV）**。

人类做这件事毫不费力——一眼就知道"这是只狗""那是川 A·12345"。但对计算机来说，它拿到的**只是一大堆数字**（具体是怎样一堆数字，我们下一章 [第 5 章](ch05-what-is-an-image.md) 会拆开看）。机器视觉要做的，就是把"一堆数字"翻译成"狗""车牌 12345"这样**人能理解的信息**。

> 📖 **术语**：**机器视觉** vs **计算机视觉**。在英文里 Computer Vision 偏学术研究，Machine Vision 偏工业应用（工厂里的检测、测量、定位）。在中文语境里两者常混用，本书统一叫"机器视觉"，但会同时覆盖**学术算法**和**工业落地**两条线。它们和"图像处理（Image Processing）"也不同：图像处理是"图进、图出"（比如把照片调亮、去噪），而机器视觉是"图进、**信息**出"（比如告诉你图里有几个人）。图像处理是机器视觉的基本功，是我们第二、三部分要练的。

## 机器视觉能做什么：一张全景地图

机器视觉不是单一技术，而是一大类任务的统称。下面这张地图列出了最主流的方向——**这也正是本书的骨架**。现在你只需要建立个印象，知道"哦，原来这些都属于机器视觉"，后面每一项都会有专门的部分手把手带你实现。

| 任务 | 一句话解释 | 生活例子 | 本书位置 |
|------|-----------|---------|---------|
| **图像分类** Classification | 判断"这张图**是什么**" | 相册区分猫/狗/美食 | 第八部分 |
| **目标检测** Detection | 找出"图里**有哪些东西、在哪**"（画框） | 自动驾驶框出行人、车辆 | 第九部分 |
| **图像分割** Segmentation | 精确到**每个像素**属于什么 | 人像抠图、医学影像勾画病灶 | 第十部分 |
| **关键点/姿态** Keypoints/Pose | 定位物体上的**关键点** | 健身 App 数你做了几个深蹲 | 第十一部分 |
| **人脸技术** Face | 检测、识别、比对人脸 | 手机刷脸解锁、门禁考勤 | 第十二部分 |
| **目标跟踪** Tracking | 在视频里**持续追踪**同一目标 | 监控里跟住某个可疑人物 | 第十三部分 |
| **三维视觉** 3D | 从图像恢复**深度与空间结构** | 手机人像虚化、机器人避障、AR | 第十四部分 |
| **生成/多模态** Generative | **生成**图像、看图说话 | AI 画图、以文搜图 | 第十五部分 |
| **视频理解** Video | 理解视频里**发生了什么** | 识别"有人摔倒了" | 第十六部分 |
| **工业视觉** Industrial | 测量、缺陷检测、定位、读码 | 检查零件尺寸是否合格、读工业二维码 | 第十七部分 |
| **事件与规则** Events | 把检测结果变成**业务告警** | "有人翻越围墙"报警、客流计数 | 第十八部分 |

看起来很多、很唬人？别急。你会发现它们**层层递进、彼此复用**：分割用到分类的思想，跟踪建立在检测之上，工业测量靠的是最基础的边缘检测……只要地基打牢，往上盖楼是水到渠成的事。

## 一个机器视觉系统长什么样

不管是相册分类还是道闸识别车牌，几乎所有机器视觉系统都遵循同一条流水线。把它记在脑子里，你以后看任何视觉项目都能对号入座：

```text
  ①采集         ②预处理         ③特征/模型        ④后处理/业务规则     ⑤决策/输出
┌────────┐   ┌──────────┐   ┌──────────────┐   ┌────────────────┐   ┌──────────┐
│摄像头/ │──▶│去噪、缩放 │──▶│ 提特征 或    │──▶│ 阈值过滤、ROI、 │──▶│ 报警/记录/│
│图片/视频│   │颜色转换…  │   │ 跑神经网络   │   │ 绊线、去重、冷却 │   │ 抬杆/展示 │
└────────┘   └──────────┘   └──────────────┘   └────────────────┘   └──────────┘
```

- **① 采集**：从摄像头、图片文件或视频流拿到图像。（第二、十六部分）
- **② 预处理**：把图像"收拾干净"——缩放到合适大小、去噪、调整颜色/亮度，让后续步骤更好干活。（第二、三部分）
- **③ 特征提取 / 模型推理**：这是"看懂"的核心。传统做法是手工设计**特征**（第四部分），现代做法是让**神经网络**自动学特征（第七部分及以后）。
- **④ 后处理 / 业务规则**：模型的原始输出往往"毛糙"——有误检、有抖动、有重复。真实项目里，你要用**置信度阈值、ROI 区域、时间窗口投票、冷却去抖、绊线判断**等一整套规则，把它变成靠谱的业务事件。**这一步最不起眼，却是工业项目里决定成败的地方**，本书第十八部分专门讲。
- **⑤ 决策 / 输出**：根据判断结果去行动——弹出报警、抬起道闸、把结果存进数据库、在画面上画框展示。

> 💡 **提示**：新手常常只盯着第 ③ 步（"我要训练一个牛逼的模型"），而高手知道，一个能落地的系统，② 和 ④ 往往同样关键。一个再准的模型，如果输出满屏乱跳的框、同一件事报警 100 次，也没法用。本书会带你把这五步都练扎实。

## 机器视觉 = 深度学习吗？

这是新手最容易有的误解。答案是：**不完全等于。**

深度学习（Deep Learning）是当今机器视觉最强大的工具，本书后半程会重点讲。但它不是全部：

- 很多**经典算法**（边缘检测、形态学、霍夫变换、模板匹配）至今仍在工业界大量使用，因为它们**快、稳、可解释、不需要训练数据**。工厂里量一个零件的尺寸，用经典方法又快又准，杀鸡不必用牛刀。
- 深度学习也**站在经典方法的肩膀上**：卷积神经网络里的"卷积"，正是我们第三部分要学的经典操作。

所以本书的路线是：**先扎实经典，再进阶深度学习，最后融会贯通**。这样你不仅会"调包跑模型"，更懂得每一步背后发生了什么——这正是"会用"和"精通"的分水岭。

## 为什么现在是入门的好时机

- **模型开放**：大量强大的预训练模型（YOLO、SAM、CLIP……）免费开放，你可以直接拿来用，不必从零训练。
- **算力普及**：一台普通笔记本（哪怕只有 CPU）就能跑很多视觉任务；Mac 的 Metal、NVIDIA 的 CUDA 让加速触手可及。
- **Rust 生态成熟**：`image`、`imageproc`、`candle`、`burn` 等纯 Rust 库已经能覆盖从图像处理到深度学习的完整链路——这也正是本书能"只用 Rust"的底气。（下一章 [第 2 章](ch02-why-rust.md) 细说为什么选 Rust。）

## 本章小结

- 机器视觉是**让计算机从图像/视频中自动读出信息并做判断**的技术；计算机看到的本质上是一堆数字。
- 主流任务包括分类、检测、分割、关键点/姿态、人脸、跟踪、三维、生成、视频理解、工业视觉、事件规则——它们层层递进、彼此复用，构成了本书的骨架。
- 一个机器视觉系统的标准流水线是：**采集 → 预处理 → 特征/模型 → 后处理/业务规则 → 决策/输出**；其中"后处理/业务规则"是工业落地的胜负手。
- 机器视觉 ≠ 深度学习。经典算法依然重要，且是理解深度学习的基础。本书先经典、后深度、终融会。

## 动手练习

这一章不写代码，我们练"眼力"——学会用机器视觉的眼光观察世界：

1. **找应用**：列出你今天用到（或身边发生）的 5 个机器视觉应用（如刷脸支付、扫码、拍照翻译……），并给每个标注它主要属于地图里的哪个任务。
2. **拆流水线**：挑其中一个应用，试着按"采集 → 预处理 → 模型 → 后处理 → 输出"五步拆解它大概是怎么工作的。
3. **想一想**：停车场识别车牌，如果只有第 ③ 步（识别出车牌号）而没有第 ④ 步（业务规则），可能会出什么问题？（提示：同一辆车停在闸口，摄像头每秒识别 25 次……）
4. **立个 flag**：在这张任务地图里，圈出**最让你兴奋、最想做出来**的 1–2 个方向。带着这个目标读下去，学习会更有劲。
