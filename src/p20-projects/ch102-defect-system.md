# 第 102 章 项目：工业缺陷检测系统

> **本章导读**
> - 这是一个**集成项目**：把前面学的**逐像素分割**（[第 49 章](../p10-segmentation/ch49-semantic-seg.md)）、**自编码器**（[第 69 章](../p15-generative/ch69-autoencoder.md)）、**连通域分析**（[第 18 章](../p03-classic/ch18-contours.md)）串成一条能用的**表面缺陷检测**流水线：图像 → **分割出缺陷区** → 阈值 → 连通域 → **缺陷框 + 严重度（面积）**。
> - 你会实现**两条路线**并用真实数字对比：**路线 A 监督分割**（有缺陷标注，小 U-Net），**路线 B 异常检测**（只用正常样本训自编码器，重建误差高=缺陷，**零缺陷标注**）。
> - 真实结果：A 缺陷像素 IoU **0.512**、缺陷级检出率 **99.1%**、**0 误报**；B 检出率 **100%**、**零标注**但有 **36 个误报**——一次把"精准但要标注"和"免标注但更吵"的取舍看清楚。
> - **诚实**：讲清工业界为何在缺陷**稀少、形态未知**时更偏爱异常检测；真产线还要高分辨率、亚像素、极低误报、受控光照（呼应 [第 80 章](../p17-industrial/ch80-defect.md)、[第 82 章](../p17-industrial/ch82-imaging-hardware.md)）。
> - 代码本机 `cargo run --release` 实测（纯 CPU、约 50 秒），数字均为真实输出、可复现。

## 场景：产线上，怎么自动揪出表面划痕和孔洞

一条金属件产线，每分钟几百个零件飞过相机。人工目检又慢又累、还会漏。任务很明确：**给一张表面图，自动判断有没有缺陷、缺陷在哪、有多严重**（划痕、孔洞、污点……）。

这本质上就是我们在第十部分练熟的**分割**——把"缺陷像素"从"正常表面"里分出来。但工业缺陷检测有一个绕不开的、决定技术选型的现实：

> ⚠️ **注意（工业缺陷的两个残酷现实）**：**① 缺陷样本极稀少**——产线良率 99%+，你可能收几万张图才凑出几十张有缺陷的。**② 缺陷形态未知**——今天是划痕，明天可能是从没见过的新裂纹。这让"收集大量缺陷、逐像素标注、监督训练"在很多场景**不现实**。于是工业界发展出另一条主流思路：**异常检测**——**只学"正常长什么样"，凡是不像正常的就是缺陷**。

本章我们把两条路线都实现出来，让你亲眼看到它们的取舍。

## 原理：两条路线

### 路线 A：把缺陷检测当分割问题（有标注时）

如果你**确实有**一批标注好缺陷区域的图，那最直接的办法就是 [第 49 章](../p10-segmentation/ch49-semantic-seg.md) 的**逐像素分割**：训练一个小 U-Net，输入表面图，输出每个像素"正常 / 缺陷"两类。这条路**缺陷像素分得最准**，但有两个前提：得有标注、且只能认**训练时见过的缺陷类型**。

这里有个绕不开的**类别不平衡**：缺陷像素通常只占很小一撮（本章合成数据里约 **7.3%**）。普通交叉熵会"偷懒"——**把所有像素都预测成正常也能拿到 93% 的逐像素准确率**，缺陷却全漏了。对策是**给缺陷像素更大的损失权重** \\( w \\)（本章用 \\( w=4 \\)），逼网络认真对待稀少的缺陷类。

### 路线 B：异常检测——只学"正常"，重建误差高就是缺陷

这是工业界在缺陷稀少/未知时的**主流思路**，也呼应 [第 80 章](../p17-industrial/ch80-defect.md)。核心用 [第 69 章](../p15-generative/ch69-autoencoder.md) 的**自编码器（autoencoder）**：

- **只用正常样本**训练一个自编码器（编码到低维瓶颈再重建）。它会学会"正常表面纹理长什么样"，并能很好地重建正常图。
- **推理时**：把待测图喂进去重建。正常区域重建得好（误差小）；**缺陷区域是它没见过的、重建不出来 → 重建误差大**。于是**逐像素重建误差图**就是一张"异常热力图"。

\\[ \text{误差}(x,y) = \big(I(x,y) - \hat{I}(x,y)\big)^2 \\]

怎么定"多大算异常"？**在一批正常验证图上统计重建误差**，取阈值 \\( \tau = \mu + k\sigma \\)（本章 \\( k=4 \\)）——**全程没用到任何缺陷标注**。这就是异常检测的魅力：**你不需要见过缺陷，就能发现缺陷**。

### 后处理：从掩码到"缺陷框 + 严重度"

两条路线都输出一张**缺陷二值掩码**，之后走**同一套后处理**（工业报警需要的是"框 + 严重度"，不是一堆散像素）：

```text
缺陷掩码 ──连通域(第18章)──▶ 每个缺陷块 ──▶ 外接框 + 面积(严重度) ──▶ 报警/分级
```

**连通域分析（connected components）** 把相连的缺陷像素聚成一个个独立缺陷块，每块给出外接框和面积；面积就是最朴素的**严重度**（也可换成长度、对比度等）。再按最小面积滤掉零星噪点，就得到干净的缺陷列表。

## 动手：两条路线一起跑

> ⚠️ **注意**：代码基于 **candle 0.11.0**，纯 CPU。完整工程见 `code/projects/ch102_defect/`，`cargo run --release` 即可复现（约 50 秒）。`Cargo.toml` 依赖 `candle-core/candle-nn/image/imageproc`（含空 `[workspace]` 独立成工程）。

**合成"工业表面"**（灰度）：正常图是**水平条纹纹理 + 噪声**（模拟拉丝/织纹），相位随机；缺陷叠三种——**划痕**（亮线，打断条纹）、**孔洞**（暗圆盘）、**污点**（灰色不规则团块），并记下逐像素缺陷掩码。注意合成随机数用**固定种子 LCG 且只取高位**（`self.next() >> 11`），避免 LCG 低位规律污染纹理，也保证可复现。

**路线 A 的网络**直接复用 [第 49 章](../p10-segmentation/ch49-semantic-seg.md) 的小 U-Net（改成 1 通道输入、2 类输出），解码器只用 **2× 整数最近邻上采样**（`8→16→32`）——这是 [第 50 章](../p10-segmentation/ch50-instance-seg.md) 踩过的坑：candle 0.11 的上采样**反向只支持整数倍**。关键是**类别加权的逐像素交叉熵**（candle 的 `cross_entropy` 不带类别权重，我们自己写）：

```rust
// 缺陷像素只占约 7%，给它们更大权重 w_pos，逼网络认真分缺陷（类不平衡对策）
fn pixel_ce_weighted(logits: &Tensor, target_u32: &Tensor, w_pos: f64) -> Result<Tensor> {
    let (n, c, h, w) = logits.dims4()?;
    let p = n * h * w;
    let flat = logits.permute((0, 2, 3, 1))?.contiguous()?.reshape((p, c))?; // [P,2]
    let logp = candle_nn::ops::log_softmax(&flat, 1)?;                        // [P,2]
    let picked = logp.gather(&target_u32.reshape((p, 1))?, 1)?.reshape((p,))?;// 真值类 log 概率
    let tgtf = target_u32.reshape((p,))?.to_dtype(DType::F32)?;              // 0/1
    let weight = tgtf.affine(w_pos - 1.0, 1.0)?;                             // 1 + (w-1)*缺陷
    let wsum = weight.sum_all()?;
    picked.neg()?.broadcast_mul(&weight)?.sum_all()?.broadcast_div(&wsum)    // 加权平均 NLL
}
```

**路线 A 训练 + 评估**（走完整后处理管线）真实输出：

```text
数据：80 张带缺陷图（缺陷像素占比 7.3%）、80 张正常图（训异常检测）、60 张测试图。
测试集缺陷类型分布：划痕=43  孔洞=28  污点=43
========== 路线 A：监督分割（小 U-Net 逐像素分缺陷）==========
  epoch   1  加权逐像素交叉熵 loss = 0.7032
  epoch 100  加权逐像素交叉熵 loss = 0.1800
路线 A 结果：缺陷像素 IoU = 0.512，缺陷级检出率 = 99.1%（113/114），全测试集误报 = 0 个
```

**114 个缺陷检出 113 个（99.1%）、0 误报**——加了类别权重后，稀少的缺陷也被稳稳分出（不加权时检出率只有 89.5%）。像素 IoU 0.512 看着不高，是因为**划痕只有 2 像素宽**，边界差一个像素 IoU 就掉一大截；但**缺陷级检出率**（有没有揪出这个缺陷）才是产线关心的，这个 99.1% 很能打。

**路线 B 的自编码器**复用 [第 69 章](../p15-generative/ch69-autoencoder.md)（1 通道，瓶颈 32 维），**只喂正常图**训练 MSE 重建。然后在正常验证集上定阈值、在测试图上算重建误差图（`error_map` 做逐像素平方误差 + 3×3 平滑抑噪），超阈即异常：

```rust
let recon = ae.forward(&x)?;                       // 只在正常图上训练过
let loss = (&recon - &xnorm)?.sqr()?.mean_all()?;  // MSE 重建损失
// ...推理：正常验证集统计 τ = 均值 + 4σ；测试图误差 > τ 即缺陷
let am: Vec<bool> = err.iter().map(|&e| e > tau).collect();
```

真实输出：

```text
========== 路线 B：异常检测（自编码器只学正常纹理，重建误差=缺陷）==========
  epoch   1  重建 MSE = 0.00747
  epoch 120  重建 MSE = 0.00110
  正常验证集重建误差：均值 0.00104，阈值 τ = 均值 + 4σ = 0.00326（无需任何缺陷标注）
路线 B 结果：缺陷像素 IoU = 0.495，缺陷级检出率 = 100.0%（114/114），全测试集误报 = 36 个
```

**两条路线的对比就是本章的重头戏**：

```text
  监督分割 A：像素 IoU 0.512，检出率 99.1%   —— 需要缺陷标注，缺陷像素分得最准，几乎不误报
  异常检测 B：像素 IoU 0.495，检出率 100.0%  —— 【零缺陷标注】，只看正常样本，但更"吵"（36 个误报）
```

- **路线 A（监督）**：精准、几乎不误报，但**要缺陷标注**，且只认见过的缺陷类型。
- **路线 B（异常检测）**：**一个缺陷标注都不要**，检出率甚至更高（连没"见过"的都能抓），代价是**误报更多**（重建对高频纹理、边缘也会有点误差）。

程序还会存 `defectA_*.png` / `defectB_*.png`：灰度表面 + 缺陷着色 + **绿框（GT）/ 红框（检出连通域）**，肉眼可见两条路线都把缺陷框住了，异常检测的着色区域更"胖"一些（对应它更高的误报）。

> 💡 **提示**：现实里两者常**结合**：先用异常检测**海选**（不漏），再用监督分割/分类对报警区**复核**（降误报）——既不漏、又不吵。误报率和漏检率的平衡，靠调阈值 \\( k \\)（异常检测的 τ）和置信度实现，取决于产线"宁可错杀还是宁可放过"的成本。

## 常见坑与提示

> 🕳️ **坑**：**类别不平衡会让分割"躺平"。** 缺陷只占 7% 像素，普通交叉熵会把一切判成正常还拿高准确率。必须**加权**（本章缺陷像素权重 4×，检出率从 89.5% 提到 99.1%），或用 Dice/Focal 损失。**评估也别只看逐像素准确率或 IoU**，缺陷级**检出率 + 误报数**才是产线的决策指标。

> 🕳️ **坑**：**candle 0.11 的上采样反向只支持整数倍。** 自编码器解码器和 U-Net 解码器的上采样都严格用 **2× 整数**（`8→16→32`），别用任意比例 resize，否则训练反向会报 `backward not supported for non integer upscaling factors`（[第 50 章](../p10-segmentation/ch50-instance-seg.md) 详述）。

> ⚠️ **注意**：**异常检测的阈值要在"正常验证集"上定，不能偷看缺陷。** \\( \tau=\mu+k\sigma \\) 里的 \\( \mu,\sigma \\) 只能来自正常样本的重建误差分布。\\( k \\) 越大越保守（误报少、可能漏检），越小越灵敏（不漏、但吵）。这是异常检测唯一的"旋钮"，按产线成本调。

> ⚠️ **注意（诚实的工程边界）**：真实产线的缺陷检测远不止本章这点。**成像**是第一道坎——分辨率要够（细划痕可能只有几微米，需高分辨率相机 + 合适镜头）、**光照要受控**（同轴光、暗场、多角度打光能让缺陷"跳出来"，见 [第 82 章](../p17-industrial/ch82-imaging-hardware.md)）；测量常要**亚像素**精度；产线对**误报极其敏感**（每个误报都意味着停机复检的成本）。本章纯 Rust CPU 教学版够讲清算法骨架，但落地要和光学、机械、节拍一起设计。

> 💡 **提示**：**要跑更强的现成缺陷/分割模型**（如在真实数据上训练的大 U-Net、PatchCore 这类异常检测），务实路线是**下载导出的 ONNX**，用纯 Rust 的 `tract` 加载推理（[第 94 章](../p19-deploy/ch94-onnx.md)）——和跑真实 YOLO / SAM 是同一条思路：**结构与预处理讲透，权重靠下载**。

## 本章小结

- **工业缺陷检测 = 分割 + 后处理**：分割出缺陷掩码 → 阈值 → **连通域** → 缺陷框 + 严重度（面积）。这条流水线复用了逐像素分割（[第 49 章](../p10-segmentation/ch49-semantic-seg.md)）、自编码器（[第 69 章](../p15-generative/ch69-autoencoder.md)）、连通域（[第 18 章](../p03-classic/ch18-contours.md)）。
- **路线 A 监督分割**：有标注时最精准（本章 IoU **0.512**、检出率 **99.1%**、**0 误报**）。缺陷像素稀少（7.3%）→ 必须**类别加权**交叉熵，否则会"躺平"漏检。
- **路线 B 异常检测**：**只用正常样本**训自编码器，重建误差 \\( >\mu+k\sigma \\) 即缺陷。**零缺陷标注**、检出率 **100%**，但误报更多（36 个）。这是工业界应对"缺陷稀少、形态未知"的主流思路。
- **诚实边界**：真产线要高分辨率、亚像素、受控光照、极低误报（[第 80 章](../p17-industrial/ch80-defect.md)、[第 82 章](../p17-industrial/ch82-imaging-hardware.md)）；要上更强模型走 ONNX + tract（[第 94 章](../p19-deploy/ch94-onnx.md)）。

## 动手练习

1. **调异常检测的旋钮**：把 \\( k \\) 从 4 改成 2、3、6，重跑路线 B，记录检出率和误报数怎么此消彼长——亲手画出这条"漏检 vs 误报"权衡曲线。
2. **调缺陷权重**：把路线 A 的缺陷权重从 4 改成 1（等价普通交叉熵）、2、8，看检出率和像素 IoU 怎么变，体会类别不平衡的杀伤力。
3. **加一种新缺陷**：给测试集加一种**训练时没有**的缺陷（比如"裂纹"）。观察路线 A（监督，可能漏）和路线 B（异常检测，应该照样抓到）的差别——这正是异常检测的核心优势。
4. **严重度分级**：给连通域按面积分"轻/中/重"三级，只对"重"级报警，模拟产线的分级处理。
5. **两路线融合（进阶）**：用路线 B 海选候选区，再用路线 A 复核，输出"既不漏又少误报"的结果，报融合后的检出率与误报数。

## 结语

这一章把前面学的分割、自编码器、连通域拼成了一个**能落地的缺陷检测项目**，也让你看清了工业视觉里最重要的一个选型直觉：**当缺陷稀少且形态未知时，"只学正常"的异常检测，往往比"死磕缺陷标注"的监督学习更务实**。把算法骨架吃透，再配上对的相机与打光，你就握住了工业质检的钥匙。👉 更强的模型部署见 [第 94 章](../p19-deploy/ch94-onnx.md)。
