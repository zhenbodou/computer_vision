机器视觉工程实战：用 Rust 看懂图像与模型

第 8 章 · 边缘、形态学与轮廓

本章导读：上一章（第 7 章）我们学会了给图像降噪、模糊、锐化——那更像是给图像“美颜“。本章要更进一步：从像素里提取结构。我们会先找出物体的边缘（Sobel、Canny），再把灰度图二值化（阈值、Otsu），然后用形态学（腐蚀、膨胀、开、闭）把二值图修干净，最后用连通域和轮廓把散落的白色像素聚成一个个“物体“，量出它的外接框（BBox）和面积。读完你能亲手搭出一条不需要训练、每一步都看得见的传统目标检测流水线——这正是第 1 章提到的“传统算法“那一派的看家本领。

8.1 边缘是什么

先问一个问题：你怎么一眼看出照片里“物体的轮廓“？

答案是亮度突变。一只黑猫趴在白墙前，猫身和墙交界的地方，亮度从“很亮“骤降到“很暗“——这条“骤变线“就是边缘（edge）。图像里绝大多数有意义的结构（物体外形、文字笔画、零件棱角）都出现在亮度剧烈变化的地方。

怎么量化“变化剧烈“？用梯度（gradient）。

打个比方：把灰度图想象成一片高低起伏的地形，像素越亮地势越高。梯度就是地面的陡峭程度——平地梯度为 0（走一步高度不变），悬崖梯度巨大（走一步掉下去几十米）。图像里，平坦的墙面梯度接近 0，物体边缘就是那道“悬崖“，梯度很大。

先看最简单的一维例子。取一行像素，从左到右扫过一条边缘：

像素值：  10   10   10   90   90   90
相邻差：     0    0   80    0    0        ← 相邻像素相减 = 一维"梯度"
                    ↑
                这里有一条边缘（值突然从 10 跳到 90）

相邻相减，平坦处得 0，突变处得 80——梯度大的地方就是边缘。二维图像无非是把这件事沿水平和垂直两个方向各做一遍，再合起来。至于“相减“背后的滑窗卷积机制，第 7 章已经讲透，本章直接拿来用。

8.2 Sobel 算子：两个方向的探针

一维只有“左右“一个方向，二维要同时看“水平变化“和“垂直变化“。Sobel 算子用两个 3×3 卷积核分别探测这两个方向：

Gx（水平方向梯度，检测竖直边缘）：   Gy（垂直方向梯度，检测水平边缘）：

  -1   0  +1                          -1  -2  -1
  -2   0  +2                           0   0   0
  -1   0  +1                          +1  +2  +1

直觉：Gx 核左边是负、右边是正，它算的是“右边一列减左边一列“——左右差得越多，Gx 越大，说明这里有一条竖直边缘。Gy 同理，上下相减，管水平边缘。中间一行/一列权重加倍（是 2 不是 1），因为正对着中心的邻居比斜角更值得信任（这和第 7 章高斯核“中心权重大“是一个道理）。

手算一个像素的 Gx、Gy 和幅值

想象图像上一小块区域，亮度从左上往右下平滑变亮（一个倾斜的亮度斜坡），中心像素周围的 3×3 是这样：

 20   35   50
 40   55   70
 60   75   90

先算 Gx（每个像素 × Gx 核对应位置，再全部相加）：

Gx = (-1)·20 + 0·35 + (+1)·50      → 第一行：-20 + 0 + 50 = 30
   + (-2)·40 + 0·55 + (+2)·70      → 第二行：-80 + 0 +140 = 60
   + (-1)·60 + 0·75 + (+1)·90      → 第三行：-60 + 0 + 90 = 30
   = 30 + 60 + 30 = 120

再算 Gy（同一块像素，换成 Gy 核）：

Gy = (-1)·20 + (-2)·35 + (-1)·50   → 第一行：-20 -70 -50 = -140
   +   0·40 +   0·55 +   0·70      → 第二行：0
   + (+1)·60 + (+2)·75 + (+1)·90   → 第三行：+60 +150 +90 = +300
   = -140 + 0 + 300 = 160

Gx = 120、Gy = 160：这一点水平和垂直方向都在快速变亮。合成梯度幅值（把两个方向像勾股定理一样合起来）：

$$G = \sqrt{G_x^2 + G_y^2} = \sqrt{120^2 + 160^2} = \sqrt{14400 + 25600} = \sqrt{40000} = 200$$

幅值 200（接近 255 上限）说明这是一条很强的边缘。工程上开方较慢，实时场景常用近似 $|G_x| + |G_y| = 120 + 160 = 280$ 代替（快，略微偏大，够用）。

梯度还有个方向 $\theta = \arctan(G_y / G_x)$，指向“变化最快的方向“（垂直于边缘走向），Canny 的第 3 步要用到它。

提一下 Scharr

Sobel 的 3×3 核在斜方向不够精确。Scharr 是它的加强版，系数放大、比例更优，对细弱边缘更敏感：

Scharr Gx：             Scharr Gy：
 -3   0  +3            -3  -10  -3
-10   0 +10             0    0   0
 -3   0  +3            +3  +10  +3

用法和 Sobel 一样，只是换了核里的数字——记住第 7 章那句话：设计一个算子，就是设计核里的那几个数。

用 imageproc 求 Sobel

use image::{GrayImage, Luma};
use imageproc::gradients::{horizontal_sobel, vertical_sobel, sobel_gradients};

fn main() -> anyhow::Result<()> {
    let gray = image::open("test.jpg")?.to_luma8();

    // Gx、Gy 可能为负，所以每个像素用 i16 存（不是 u8）
    let gx = horizontal_sobel(&gray); // Image<Luma<i16>>
    let gy = vertical_sobel(&gray);   // Image<Luma<i16>>

    // imageproc 直接给合成好的幅值图；幅值可能 >255，故用 u16
    let _mag = sobel_gradients(&gray); // Image<Luma<u16>>

    // 手动合成一遍，和上面等价，方便存成能看的灰度图
    let (w, h) = gray.dimensions();
    let mut edge = GrayImage::new(w, h);
    for y in 0..h {
        for x in 0..w {
            let dx = gx.get_pixel(x, y)[0] as f32;
            let dy = gy.get_pixel(x, y)[0] as f32;
            let m = (dx * dx + dy * dy).sqrt(); // 就是本节手算的那个幅值
            edge.put_pixel(x, y, Luma([m.min(255.0) as u8]));
        }
    }
    edge.save("sobel.png")?;
    Ok(())
}

跑出来的 sobel.png 里，物体轮廓是亮线，平坦区域是黑的——但你会发现边缘又粗又毛糙。把它变成干净的单像素线，就是下面 Canny 要干的事。

8.3 Canny：业界标准的边缘提取

实际项目里说“提边缘“，九成指的是 Canny 边缘检测。它不是一个新算子，而是把前面的思想串成一条四步流水线，产出又细又连续、噪声又少的边缘：

① 高斯降噪      先把噪点抹平，免得把噪声也当成边缘（详见第 7 章）
② 求梯度        对降噪后的图跑 Sobel，得到每个像素的幅值 G 和方向 θ
③ 非极大值抑制   沿梯度方向只保留"最陡的那一个"像素，把粗边细化成单像素线
④ 双阈值 + 滞后连接  用高低两条阈值分出强/弱边缘，再把弱边缘"择优录取"

**第 ③ 步（非极大值抑制，NMS）**是 Canny 精髓。Sobel 算出来的边缘往往有好几像素宽（像一道斜坡），但真正的边缘只有斜坡最陡处那一像素。这一步沿着梯度方向左右比一比：“我是不是这一小段里梯度最大的？“不是就归零。于是一条“胖边“被削成“一根线”。

第 ④ 步先用两条阈值给每个边缘像素分类：

  • 幅值 > 高阈值：强边缘，铁定是真边缘，直接保留。
  • 幅值 < 低阈值：直接扔掉，是噪声。
  • 介于两者之间：弱边缘，暂时存疑。

然后滞后连接（hysteresis）：弱边缘如果和某个强边缘连在一起，就“沾光“晋升为真边缘（它多半是真轮廓被噪点打断的一截）；孤零零、谁也不挨着的弱边缘则丢弃。这样既能接上断续的真实轮廓，又不放过孤立噪点。

高低阈值怎么影响结果（这是项目里对着样图调参的地方）：

调法效果场景
两个都调高边缘稀疏但可靠，只留最强的轮廓只想要主体大轮廓
两个都调低边缘密密麻麻，噪声也混进来怕漏细节，但要忍受杂线
高低差距大（如 1:3）主干可靠 + 尽量把断线接上通用推荐起点

经验比值：高阈值 ≈ 低阈值的 2~3 倍。

use imageproc::edges::canny;

fn main() -> anyhow::Result<()> {
    let gray = image::open("test.jpg")?.to_luma8();
    // canny(图, 低阈值, 高阈值)；内部已含高斯降噪，无需自己先模糊
    let edges = canny(&gray, 50.0, 150.0); // 输出：单像素宽的黑白边缘图
    edges.save("canny.png")?;
    Ok(())
}

8.4 阈值化：从灰度到黑白

边缘检测把“轮廓“抠了出来，但很多传统流水线更需要的是把整个物体区域变成一整块白色，好让后面数它、量它。这一步叫阈值化（threshold），也叫二值化：给一条分界线，比它亮的像素涂白（255），比它暗的涂黑（0）。

灰度值：  30   90   130   200        阈值 = 128
         ↓    ↓     ↓     ↓
二值化：   0    0    255   255        （> 128 变白，否则变黑）

结果只剩黑白两色，图像被“抽象“成了“前景 vs 背景“。难点只有一个：阈值定多少？ 定高了物体被啃掉，定低了背景混进来。手动试很累，于是有了 Otsu 自动阈值。

Otsu 原理一句话：把整张图的灰度直方图看成两堆（前景堆 + 背景堆），自动挑一条分界线，让分出来的两堆各自最“抱团“（组内方差最小、等价于组间方差最大）。它替你把最费劲的调参自动化了，光照稳定的场景一用一个准。

use imageproc::contrast::{threshold, otsu_level, ThresholdType};

fn main() -> anyhow::Result<()> {
    let gray = image::open("test.jpg")?.to_luma8();

    // 固定阈值：亮度 > 128 变白，其余变黑
    let bin = threshold(&gray, 128, ThresholdType::Binary);
    bin.save("bin_fixed.png")?;

    // Otsu 自动阈值：让算法自己找那条最佳分界线
    let level = otsu_level(&gray);
    println!("Otsu 选出的阈值 = {level}");
    let bin_auto = threshold(&gray, level, ThresholdType::Binary);
    bin_auto.save("bin_otsu.png")?;
    Ok(())
}

ThresholdType 还有 BinaryInverted（反过来：暗的变白）等变体。若目标比背景暗（白纸上的黑字、亮传送带上的深色零件），就用 BinaryInverted，让目标变成白色——因为后面形态学和轮廓都默认“白色是前景“。

8.5 形态学：二值图的“整形手术“

二值化出来的图很少是完美的：物体边上挂着毛刺、背景里散着零星白点、主体里破着小黑洞。形态学（morphology）就是对黑白图做的“整形手术“，工具是一个小小的结构元素（kernel，也叫结构元）——通常是 3×3 的方块或十字，你可以理解成一枚“印章“，拿它在图上盖来盖去。两个最基本的操作：

腐蚀（erode，缩）：印章扫过每个白点，只有当印章盖住的范围全是白时，中心才保留白，否则变黑。效果是白色区域从边界往里缩一圈。打比方：拿橡皮沿着白块边缘啃一圈——细毛刺被啃没了，主体变瘦。

腐蚀（3×3 方块结构元，白块被啃掉最外一圈）：

   原图                   腐蚀后
 . . . . . .            . . . . . .
 . # # # # .            . . . . . .
 . # # # # .    ──▶     . . # # . .
 . # # # # .            . . # # . .
 . # # # # .            . . . . . .
 . . . . . .            . . . . . .
   （4×4 白块）           （缩成 2×2）

膨胀（dilate，胀）：反过来，印章盖住的范围只要有一个白，中心就变白。效果是白色区域向外长一圈。打比方：拿记号笔沿边缘描粗——白块长胖了，小黑洞被填掉。

膨胀（3×3 方块结构元，白块向外长一圈）：

   原图                   膨胀后
 . . . . . .            . . . . . .
 . . . . . .            . # # # # .
 . . # # . .    ──▶     . # # # # .
 . . # # . .            . # # # # .
 . . . . . .            . # # # # .
 . . . . . .            . . . . . .
   （2×2 白块）           （胀成 4×4）

单独用“缩“或“胀“会改变物体大小，实用的是把它们组合起来——先缩后胀、或先胀后缩，物体大小基本还原，但噪声被清掉了：

开运算（open）= 先腐蚀，后膨胀  → 去掉小白点（噪声毛刺），主体保持
闭运算（close）= 先膨胀，后腐蚀  → 填掉小黑洞（缝隙裂纹），主体保持

为什么开运算能去小白点？孤立的小白点在腐蚀那一步就被啃光了（它太小，撑不过一圈啃），后面膨胀无从恢复；而大主体啃掉一圈后还在，膨胀又长回原样。闭运算反过来：膨胀先把小黑洞填平，腐蚀再把主体缩回原大小。看图：

开运算去小白点：                        闭运算填小黑洞：

  原二值图        开运算后               原二值图        闭运算后
. . . . . . .   . . . . . . .          . . . . . .    . . . . . .
. # # # # . .   . # # # # . .          . # # # # .    . # # # # .
. # # # # . #   . # # # # . .   ←孤立   . # . # # .    . # # # # .  ←黑洞
. # # # # . .   . # # # # . .   白点消失 . # # # # .    . # # # # .   被填上
. . . # . . .   . . . . . . .   ←噪点    . . . . . .    . . . . . .
. . . . . . .   . . . . . . .   消失

工程上“二值化 + 开运算去噪“几乎是绑定出现的固定套路。imageproc 的调用：

#![allow(unused)]
fn main() {
use imageproc::morphology::{erode, dilate, open, close};
use imageproc::distance_transform::Norm;

// 参数 k = "啃/长几圈"的距离；Norm 决定结构元形状：
//   Norm::LInf → 3×3 方块，   Norm::L1 → 3×3 十字（只算上下左右）
let eroded  = erode(&bin,  Norm::LInf, 1); // 缩 1 圈
let dilated = dilate(&bin, Norm::LInf, 1); // 胀 1 圈
let opened  = open(&bin,   Norm::LInf, 1); // 开：先腐后胀，去小白点
let closed  = close(&bin,  Norm::LInf, 1); // 闭：先胀后腐，填小黑洞
}

8.6 连通域与轮廓：把白块变成“物体“

形态学修干净后，图上剩几坨白色区域。但对程序来说这还只是一堆 255，它并不知道“哪些白像素属于同一个物体“。把连成一片的白色像素认定为一个整体，就是连通域（connected components）。

打比方：一张地图上几块不相连的陆地，我们给每块岛屿编个号——1 号岛、2 号岛……连通域标记就是给图上每一坨白色区域染上一个编号（0 号留给背景）。

#![allow(unused)]
fn main() {
use image::Luma;
use imageproc::region_labelling::{connected_components, Connectivity};

// 返回一张"标签图"：每个像素的值 = 它所属连通域的编号（0 = 背景）
// Connectivity::Eight 表示斜对角也算相连；Four 只算上下左右
let labels = connected_components(&bin, Connectivity::Eight, Luma([0u8]));

// 最大编号 = 连通域个数（编号从 1 连续排到 N）
let count = labels.pixels().map(|p| p[0]).max().unwrap_or(0);
println!("找到 {count} 个连通域");
}

知道“有几个物体“还不够，我们通常想要每个物体的外轮廓（contour）——沿着白块的边界描一圈得到的点序列，以及由它派生的外接矩形（bounding box）和面积。find_contours 用经典的 Suzuki 边界跟踪算法把每条边界描出来：

#![allow(unused)]
fn main() {
use imageproc::contours::{find_contours, Contour, BorderType};

// 每条 Contour 有三样东西：
//   points: Vec<Point<i32>>   边界上的像素坐标序列
//   border_type: BorderType   Outer（物体外轮廓）还是 Hole（内部空洞的边）
//   parent: Option<usize>     父轮廓编号（用于表达"洞在谁里面"）
let contours: Vec<Contour<i32>> = find_contours(&bin);
println!("描出 {} 条轮廓", contours.len());
}

有了轮廓上的点，外接矩形就是这些点的 x、y 最小/最大值围成的框。我们用全书统一的 BBox 类型（见写作规范，左上-右下像素坐标）来表达它：

#![allow(unused)]
fn main() {
use imageproc::contours::Contour;

/// 边界框：左上-右下像素坐标（全书统一类型，后续检测章节复用）
#[derive(Clone, Copy, Debug, PartialEq)]
pub struct BBox {
    pub x1: f32,
    pub y1: f32,
    pub x2: f32,
    pub y2: f32,
}

impl BBox {
    pub fn width(&self) -> f32 { self.x2 - self.x1 }
    pub fn height(&self) -> f32 { self.y2 - self.y1 }
    pub fn area(&self) -> f32 { self.width() * self.height() } // 外接矩形面积
}

/// 从一条轮廓的边界点算出外接矩形
fn bbox_of_contour(c: &Contour<i32>) -> BBox {
    let (mut x1, mut y1) = (i32::MAX, i32::MAX);
    let (mut x2, mut y2) = (i32::MIN, i32::MIN);
    for p in &c.points {           // 扫一遍所有边界点，取 x/y 的极值
        x1 = x1.min(p.x); y1 = y1.min(p.y);
        x2 = x2.max(p.x); y2 = y2.max(p.y);
    }
    BBox { x1: x1 as f32, y1: y1 as f32, x2: x2 as f32, y2: y2 as f32 }
}
}

小提醒：BBox::area() 算的是外接矩形面积。物体真实像素面积（形状占了多少个白点）要去数连通域里该编号的像素个数，二者对细长或弯曲的物体差别很大——筛选时按需选用。

8.7 一条完整的传统检测流水线

把本章零件串起来，就是一条不用训练、每步可视、可解释的目标检测流水线——正好呼应第 1 章讲的“传统算法“那一派。任务举例：一条传送带上散落着零件，我们要框出每一个。

灰度  →  阈值(Otsu)  →  形态学去噪(开运算)  →  找轮廓  →  按面积/长宽比筛选  →  目标框 BBox
─────    ───────────    ──────────────────     ────────    ──────────────────    ──────────
去颜色    分前景/背景      清掉零星噪点            描出每块      淘汰噪声块和奇形怪状     输出结果

use image::{GrayImage, Luma};
use imageproc::contrast::{otsu_level, threshold, ThresholdType};
use imageproc::morphology::open;
use imageproc::distance_transform::Norm;
use imageproc::contours::{find_contours, Contour, BorderType};

// BBox / bbox_of_contour 沿用 8.6 节的定义，这里省略

/// 传统检测流水线：输入灰度图，输出一组目标框
fn detect_blobs(gray: &GrayImage) -> Vec<BBox> {
    // ① 阈值化：Otsu 自动定阈值，灰度图 → 黑白（目标比背景亮时用 Binary）
    let level = otsu_level(gray);
    let bin = threshold(gray, level, ThresholdType::Binary);

    // ② 形态学去噪：开运算干掉零星白点（先腐后胀），保住主体
    let clean = open(&bin, Norm::LInf, 1);

    // ③ 找轮廓：把每一块连通白色区域的边界描出来
    let contours: Vec<Contour<i32>> = find_contours(&clean);

    // ④ 按规则筛选，转成目标框
    let mut boxes = Vec::new();
    for c in &contours {
        // 只要物体外轮廓，内部空洞的边(Hole)不算一个目标
        if c.border_type != BorderType::Outer { continue; }

        let b = bbox_of_contour(c);
        let area = b.area();
        let aspect = b.width() / b.height().max(1.0); // 长宽比，防除 0

        if area < 100.0 { continue; }                 // 太小 → 残留噪声，丢
        if aspect < 0.2 || aspect > 5.0 { continue; }  // 太细太长 → 不是目标，丢
        boxes.push(b);
    }
    boxes
}

fn main() -> anyhow::Result<()> {
    let gray = image::open("parts.jpg")?.to_luma8();
    let boxes = detect_blobs(&gray);
    println!("检测到 {} 个目标：", boxes.len());
    for (i, b) in boxes.iter().enumerate() {
        println!(
            "  #{i}: ({:.0},{:.0})-({:.0},{:.0}) 面积={:.0}",
            b.x1, b.y1, b.x2, b.y2, b.area()
        );
    }
    Ok(())
}

这套流水线的每一个中间产物——二值图、去噪图、轮廓图——都能存成图片肉眼检查。哪一步出了错，逐张看过去就能定位，不用对着神经网络黑盒抓瞎。这就是传统算法的工程优势：快、省、可解释、零训练成本。它的软肋是“规则写死“：换个光照、目标外观一变，阈值和筛选条件就得重调。所以它最适合固定场景——工业质检、传送带计数、稳定光照下的定位测量。

一旦场景变得开放多变（大街上认车认人、任意角度任意光照），手写规则就撑不住了，得请出深度学习检测器（YOLO 家族、NMS 后处理，详见第 16 章）。工业界的常态是两者混用：传统算法做预处理、粗定位、ROI 裁剪，深度模型做最终识别。而框的表达方式——本章的 BBox——从传统流水线到深度模型输出，全书自始至终是同一个。

8.8 小结

  • 边缘 = 亮度突变 = 梯度大。梯度是“地形陡峭程度“，平地为 0，物体轮廓这道“悬崖“梯度最大。
  • Sobel 用两个 3×3 核分别求水平/垂直梯度 Gx、Gy，合成幅值 $\sqrt{G_x^2+G_y^2}$；本章手算得 Gx=120, Gy=160, 幅值=200。Scharr 是它的加强版。
  • Canny 四步：高斯降噪 → 求梯度 → 非极大值抑制（削成单像素线）→ 双阈值 + 滞后连接。高阈值管“边缘多可靠“，低阈值管“边缘多密“。
  • 阈值化把灰度图二值化；Otsu 自动挑分界线让前景/背景两堆各自最抱团。
  • 形态学：腐蚀（啃边、缩）、膨胀（长胖、胀）；开运算（先腐后胀）去小白点，闭运算（先胀后腐）填小黑洞。
  • 连通域给每坨白块编号，轮廓描出边界，进而得到外接框 BBox 和面积；串成“灰度→阈值→形态学→轮廓→筛选“就是一条零训练、可解释的传统检测流水线。
