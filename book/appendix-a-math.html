机器视觉工程实战：用 Rust 看懂图像与模型

附录 A · 数学补漏：矩阵、均值方差与 Softmax

本附录集中补齐全书用到的数学，不需要任何高数基础，只要会加减乘除就能读懂。每节都会先打个生活比喻、用一组小数字手算一遍，再给公式；节里还标注了“出现在第几章“，方便你回头查。

A.1 向量与矩阵

向量就是“一队排好队的数字“。一张灰度图的每一行，都可以看成一个向量：

第 y 行 = [ 128, 130, 135, 140, ... ]   ← 一行 W 个数字

矩阵就是“向量叠起来的表格“，有行有列。一张 W×H 的灰度图就是一个 H 行 W 列的矩阵（第 2 章）。彩色图可以看成 3 个矩阵叠在一起（R 一个、G 一个、B 一个，第 4 章会细讲通道与内存布局）。

Rust 里用什么表示？ndarray 的 Array2<f32> 就是矩阵，Array3/Array4 就是更高维的“叠起来的矩阵“（第 3 章叫它们张量）。

访问元素用索引：矩阵 a 的第 i 行第 j 列写作 $a_{ij}$（数学）或 a[[i, j]]（ndarray）。所有索引从 0 开始。

A.2 点积、模长与余弦相似度

这一节是人脸识别比对（第 20 章）的数学地基。

点积：两个向量“对应位置相乘再全部加起来“，结果是一个数：

$$\vec{a} \cdot \vec{b} = a_1 b_1 + a_2 b_2 + \dots + a_n b_n$$

模长（向量的长度）：就是勾股定理推广到多维——每个分量平方求和再开根号：

$$|\vec{a}| = \sqrt{a_1^2 + a_2^2 + \dots + a_n^2}$$

余弦相似度衡量两个向量“方向有多接近“，与长度无关，范围 $[-1, 1]$，越接近 1 越同向：

$$\cos\theta = \frac{\vec{a} \cdot \vec{b}}{|\vec{a}|,|\vec{b}|}$$

手算例子：$\vec{a} = [1, 2, 2]$，$\vec{b} = [2, 0, 1]$：

点积   = 1×2 + 2×0 + 2×1 = 4
‖a‖   = √(1+4+4) = √9 = 3
‖b‖   = √(4+0+1) = √5 ≈ 2.236
cosθ  = 4 / (3 × 2.236) ≈ 0.596

第 20 章把每张脸压成一个特征向量（embedding），比对两张脸时就算它们的余弦相似度：越接近 1，越可能是同一个人。

A.3 向量的 L2 归一化

把一个向量按自己的模长缩放，让长度变成 1、方向不变，这叫 L2 归一化（单位化）：

$$\hat{v} = \frac{\vec{v}}{|\vec{v}|}$$

手算例子：$\vec{v} = [3, 4]$，$|\vec{v}| = \sqrt{9+16} = 5$，所以 $\hat{v} = [0.6, 0.8]$。验证：$0.6^2 + 0.8^2 = 0.36 + 0.64 = 1$，长度确实是 1。

好处：第 20 章存人脸特征时，通常先把每个 embedding 都 L2 归一化成单位长度。这样所有向量模长都是 1，余弦相似度的分母恒等于 1，比对就退化成一次简单的点积——又快又稳。

A.4 叉积（2D）：判断点在线的哪一侧

二维叉积把两个向量变成一个数，符号告诉你它们的转向关系：

$$\text{cross}(\vec{a}, \vec{b}) = a_x b_y - a_y b_x$$

拌线检测（第 23 章）就靠它。一条有向拌线从 $P_1$ 指向 $P_2$，方向向量 $\vec{d} = P_2 - P_1$。要判断点 $Q$ 在线的哪一侧，就算 $\text{cross}(\vec{d},; Q - P_1)$：结果为正在一侧，为负在另一侧，为 0 说明正好落在线上。

手算例子：拌线 $P_1=(0,0) \to P_2=(4,0)$（沿 x 轴向右），$\vec{d}=(4,0)$：

Q = (2,  3)（上方）: cross = 4×3 − 0×2 = 12 > 0  → 一侧
Q = (2, −1)（下方）: cross = 4×(−1) − 0×2 = −4 < 0 → 另一侧

一个目标从上一帧到这一帧，中心点的叉积符号如果由负翻正（或由正翻负），就说明它穿过了拌线——这正是第 23 章计数与方向判断的核心判据。

A.5 求和、平均、加权平均

求和（Σ 符号）：$\sum_{i=1}^{n} x_i$ 读作“把 $x_1$ 一直加到 $x_n$“，就是 x.iter().sum()。

平均：所有数加起来除以个数。全班平均分就是总分 ÷ 人数。

$$\bar{x} = \frac{1}{n}\sum_{i=1}^{n} x_i$$

加权平均：每个数先乘一个“权重“再求和，最后除以权重之和。第 2 章、第 4 章的灰度转换公式就是加权平均：

$$\text{gray} = 0.299R + 0.587G + 0.114B$$

权重之和 $0.299 + 0.587 + 0.114 = 1.000$，所以不需要再除。绿色权重最大，是因为人眼对绿色最敏感。

第 7 章的卷积本质也是加权平均：中心像素和周围像素各乘一个权重（卷积核），加起来作为新值——高斯模糊就是一组“中间大、四周小“的权重。

A.6 方差与标准差

方差衡量一组数字“离平均值有多远“。波动大的数据方差大，平稳的数据方差小：

$$s^2 = \frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2$$

（每个数减平均，平方，再求平均。平方是为了让正负偏差都变成正的。）

标准差就是方差开平方：$s = \sqrt{s^2}$，单位和原数据一致，更好理解。

应用（第 3 章看直方图、第 7 章做对比度增强都用到类似思想）：如果一张图的像素值标准差很小，说明对比度低，画面灰蒙蒙的。

A.7 归一化（Min-Max 与标准化）

把数据按比例缩放到一个标准范围，最常见的两种：

Min-Max 归一化（缩放到 [0,1]）：

$$x’ = \frac{x - x_{min}}{x_{max} - x_{min}}$$

模型预处理里的 /255.0 就是它的特例：像素范围已知是 0~255，即 $x_{min}=0,\ x_{max}=255$（第 10 章）。

标准化（缩放到均值 0、标准差 1）：

$$x’ = \frac{x - \mu}{\sigma}$$

ImageNet 预处理就是逐通道做这个，$\mu$ 和 $\sigma$ 用的是训练数据集（ImageNet）的统计值（第 10 章）。

为什么要归一化？神经网络对数值范围敏感，输入保持在小范围内，推理数值更稳定、结果更可靠。

A.8 指数加权移动平均

想估算“最近的平均通勤时间“：今天花的时间要算进去，但越久远的越不重要。**指数加权移动平均（EWMA）**就是这个思路——用一个系数 $\alpha$（0~1）把“新值“和“旧的估计“融合：

$$\text{new} = \alpha \cdot x + (1-\alpha)\cdot \text{old}$$

$\alpha$ 大（如 0.5）跟着最新值跑得快、但抖动大；$\alpha$ 小（如 0.01）平滑、但反应慢。

手算例子：初始 old = 10，$\alpha = 0.1$：

来了 x=20: new = 0.1×20 + 0.9×10 = 11.0
再来 x=20: new = 0.1×20 + 0.9×11 = 11.9   ← 慢慢往 20 爬

应用：第 19 章背景建模把每个像素的“背景值“用滑动平均慢慢更新，突然闯入的物体只出现一两帧，来不及改变背景，于是被判为前景。第 21 章跟踪里平滑目标框的位置也用同样的融合思路。

顺带一提，卡尔曼滤波的直觉也是“预测值和观测值的加权融合“（权重叫卡尔曼增益，会自动判断谁更可信），完整细节见第 21 章。

A.9 Sigmoid

把一个任意实数“压“进 (0, 1) 区间，形状是 S 形曲线：

$$\sigma(x) = \frac{1}{1 + e^{-x}}$$

关键取值：$\sigma(0) = 0.5$；$x$ 很大时接近 1；$x$ 很小时接近 0。

应用：把模型输出解释成“概率“。第 15 章的二分类、第 16 章 YOLOv8 的类别分数，都要过 sigmoid 才变成 0~1 的可信度。

A.10 Softmax

Sigmoid 的“多分类版“。把 K 个数变成 K 个和为 1 的数，可以解释为“属于每个类别的概率“：

$$\text{softmax}(x_i) = \frac{e^{x_i}}{\sum_{j=1}^{K} e^{x_j}}$$

手算例子：输入 [1, 2, 3]：

e^1 ≈ 2.72,  e^2 ≈ 7.39,  e^3 ≈ 20.09
总和 = 2.72 + 7.39 + 20.09 = 30.20
softmax = [2.72/30.20, 7.39/30.20, 20.09/30.20]
        ≈ [0.090, 0.245, 0.665]     ← 和为 1

最大的数 3 拿到的概率最大（0.665），且优势被指数放大。

数值稳定问题：如果输入里有 100，e^100 会溢出（大到 float 装不下）。工程上的标准解法：先减去最大值再算，结果不变：

#![allow(unused)]
fn main() {
let max = logits.iter().cloned().fold(f32::NEG_INFINITY, f32::max);
let exps: Vec<f32> = logits.iter().map(|x| (x - max).exp()).collect();
let sum: f32 = exps.iter().sum();
let probs: Vec<f32> = exps.iter().map(|e| e / sum).collect();
}

这就是第 15 章分类模型里“为什么先减 max“的原因。

A.11 面积与 IoU

矩形面积 = 宽 × 高。两个矩形的交集：重叠部分的宽和高分别是

$$\text{inter_w} = \min(x_2^a, x_2^b) - \max(x_1^a, x_1^b)$$ $$\text{inter_h} = \min(y_2^a, y_2^b) - \max(y_1^a, y_1^b)$$

如果算出来是负数，说明没重叠，交集面积记为 0。然后：

$$\text{IoU} = \frac{\text{交集面积}}{\text{面积}_a + \text{面积}_b - \text{交集面积}}$$

分母是并集面积（两面积相加会把交集算两遍，要减一次）。第 16 章 NMS 的完整推导和数值例子都在那里。

A.12 导数与梯度（了解即可）

导数衡量“一个量变化时，另一个量变化多快“。车速就是位移对时间的导数。

梯度是多元函数的导数向量，指向函数上升最快的方向。深度学习训练时，沿着梯度的反方向走（梯度下降），就能逐步减小损失函数——就像下山时每次都朝最陡的下坡方向迈一步（第 11 章会讲到网络是怎么训出来的）。

好消息：推理工程师不需要算梯度，那是训练阶段的事。你只需要知道：训练 = 反复算梯度、更新权重（用 GPU 花几小时到几天）；推理 = 权重固定不动，只做前向计算（用任何设备花几毫秒）。本书讲的是后者。
